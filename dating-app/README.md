# 🌟 神秘邂逅 - Mystery Dating App

一个融合AI伴侣聊天和线下活动匹配的创新单身交友平台

## ✨ 核心特色

### 🤖 AI伴侣功能
- **智能聊天机器人**：提供情绪价值和聊天指导
- **AI化身人设**：为每个用户创建神秘的AI形象
- **情感分析**：实时分析用户情绪，提供个性化支持
- **聊天助手**：在真人交友时提供智能话题建议

### 💑 交友匹配系统
- **多维度标签**：兴趣、特长、年龄、情绪、性格等
- **智能匹配算法**：基于用户画像的精准匹配
- **神秘模式**：初始阶段隐藏部分信息，增加神秘感

### 🎮 互动游戏
- **破冰游戏**：帮助用户打开话题
- **性格测试**：深度了解彼此
- **情侣小游戏**：增进感情的趣味互动

### 🎯 线下活动匹配
- **主题活动**：野营、探店、美术馆、剧本杀、团建
- **随机匹配**：增加惊喜和新鲜感
- **活动打卡**：记录美好瞬间

## 🛠 技术栈

### 后端
- Node.js + Express
- MongoDB + Mongoose
- Socket.io (实时聊天)
- JWT 认证
- Claude AI API (智能对话)

### 前端
- React 18 + Vite
- TailwindCSS (神秘优雅的UI)
- Framer Motion (流畅动画)
- Socket.io Client
- Zustand (状态管理)

## 🚀 快速开始

### 安装依赖

```bash
# 安装后端依赖
cd backend
npm install

# 安装前端依赖
cd ../frontend
npm install
```

### 环境配置

1. 在 `backend` 目录创建 `.env` 文件：

```env
PORT=5000
MONGODB_URI=mongodb://localhost:27017/dating-app
JWT_SECRET=your-secret-key-change-this
ANTHROPIC_API_KEY=your-claude-api-key
CLIENT_URL=http://localhost:5173
```

2. 启动 MongoDB 数据库

### 运行项目

```bash
# 启动后端 (端口 5000)
cd backend
npm run dev

# 启动前端 (端口 5173)
cd frontend
npm run dev
```

访问 http://localhost:5173 开始体验
