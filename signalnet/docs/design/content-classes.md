# 机制推演：金子总会发光 + 原创 / 衍生 / 追随 / 搬运 四分类隔离

- 状态：提议（REQ-EV-001 已实现；REQ-EV-002~005、REQ-MT-001~006 为 P1）
- 日期：2026-11-09
- 关联：[cold-start.md](cold-start.md)、[originality.md](originality.md)

## 1. 两条设计原则

1. **金子总会发光**：质量是内容的固有属性，不随时间衰减。时间只能决定“新鲜度加成”，不能把好内容的基础分清零。
2. **追随不是原创**：一个玩法火了以后，大量复刻会挤占分发、拉低整体质量、制造垃圾信息。
   复刻者不是小偷，但也不是开创者——要**隔离**，而不是惩罚。

---

## 2. 不被时间埋没

### 2.1 M1 的问题

M1 的排序是 `质量 × 置信度 × 0.5^(age/48h)`：一条 0.9 分的作品一个月后得分约为 0，
任何一条新发的 0.3 分内容都能排在它前面。这等于说“好内容的寿命只有两天”，和投流平台一样。

### 2.2 新公式（REQ-EV-001，已实现）

```
排序分 = 质量 × 置信度 × (1 + 新鲜度加成 × 0.5^(age/半衰期))      # 新鲜度加成默认 0.5
```

- 质量部分**永不衰减**；新内容获得最多 +50% 的临时加成，48h 半衰。
- 效果：新的 0.7 分作品可以暂时排在老的 0.9 分作品前面（0.7×1.5=1.05 > 0.9），
  但新的 0.5 分作品不行（0.75 < 0.9）。一周后加成基本消失，排序回归质量本身。

### 2.3 时效型 vs 常青型（REQ-EV-002）

| 类型 | 例子 | 时间规则 |
|---|---|---|
| 时效型 | 新闻、热点评论、活动通知 | 质量 × 衰减（旧新闻确实应该退场） |
| 常青型 | 教程、深度分析、纪录、艺术作品 | 质量不衰减，只有新鲜度加成 |

由作者申报、陪审确认（申报与陪审结论不一致时以陪审为准）。

### 2.4 让被埋没的作品重新被看见

| 机制 | 解决什么 | 做法 |
|---|---|---|
| **曝光欠账复兴**（REQ-EV-003） | 质量高但当初运气差、曝光远低于应得水平的作品 | 欠账 = 同质量档位的中位曝光 − 实际曝光；推荐流固定拿出一部分位置（默认 5%）给欠账最高的作品 |
| **二次机会**（REQ-EV-005） | 发布时没凑够评审、没能晋级的作品 | 定期重新进入探索池抽取新陪审，每条最多 2 次，避免无限重试 |
| **时间检验复审**（REQ-EV-004） | 区分“当时火”和“真的好” | 发布后 30 天、180 天随机复审；共识保持 → 标记为“经典”、置信度提升；信息过时 → 降级 |

这三项一起实现：**一部作品的命运不由发布那 48 小时决定。**

## 3. 四分类：原创 / 衍生 / 追随 / 搬运

### 3.1 定义与判定问题

陪审按下面的顺序回答问题，第一个“是”就是分类结果：

| # | 判定问题 | 是 → 分类 |
|---|---|---|
| 1 | 是否复制了**某一部具体作品**的表达（画面、文案、剪辑），且没有实质增量？ | **搬运** |
| 2 | 是否基于**特定作品**（声明了引用），并且带来了实质增量？ | **衍生**（二创、评论、翻译、解析） |
| 3 | 是否复刻了一种**正在流行的范式**（玩法、模板、梗、挑战），且没有实质增量？ | **追随** |
| 4 | 以上都不是 | **原创** |

**什么算“实质增量”**：新信息/数据、新技法/方法、新观点/论证、实质性的新创意表达。
**不算**：换人、换场景、换道具、换滤镜、换背景音乐、换角度拍同一件事。

> 例：所有人都用脚开瓶盖——换了一个人、换了一种瓶子，是**追随**；
> 第一个用脚开瓶盖的人是**原创**；
> 有人分析“脚开瓶盖的发力原理”并演示新技巧，是**衍生**（甚至可能是新的原创）。

### 3.2 范式（母题 / Motif）对象（REQ-MT-002）

“追随”的参照物不是某条作品，而是一个**范式**。系统需要把范式显式建模：

- **识别**（已实现，见 REQ-MT-002）：两种信号，都要求“时间爆发”——
  ① 一个**新**标签（如 #脚开瓶盖挑战）7 天内被 ≥5 个不同作者使用；
  ② 宽松文本相似的内容 7 天内来自 ≥5 个不同作者。
  老标签（如 #做菜）首次出现早于窗口，视为常态品类，不形成母题。
  实测发现：真正各自改写的文案彼此 SimHash 距离接近随机，仅靠文本识别不到追随，因此标签爆发是主信号，
  语义 embedding 列入 M3。
- **开创者**：簇内最早签名、且被陪审判为原创的那条内容。日志的先后顺序不可篡改，开创者身份可验证。
- **机器预判，陪审裁定**：落入母题簇的新内容被预判为“追随”，由陪审确认或改判。

### 3.3 隔离规则

| 分类 | 推荐流 | 探索池 | 收益 | 声誉 |
|---|---|---|---|---|
| 原创 | 独立参与排序 | 独立 L0 配额 | 正常分账 | 正常 |
| 衍生 | 独立参与排序 | 独立 L0 配额 | 创作者份额 30% 给被引用作者（REQ-OR-003） | 正常 |
| **追随** | **按母题聚合，整个母题只占 1 个推荐位**（开创者 + 至多 3 条最佳追随） | **母题共享配额，第 n 条按 1/n 递减** | 创作者份额 **10%** 给母题开创者 | 不罚、不奖原创分 |
| 搬运 | 不进推荐流 | 不进 | 托管收益转给原作者（REQ-OR-004） | 罚没 |

要点：

- **隔离 ≠ 封禁**：追随内容照样可以发，照样出现在母题合集页和作者的关注者订阅流里，照样有广告收益——只是不能用复刻去挤占推荐流。
- **1000 条追随只占 1 个位置**：推荐流不会被“脚开瓶盖”刷屏，读者看到的是开创者原作 + 母题里质量最高的几条。
- **开创者长期受益**：母题每次被追随，开创者都获得分成和曝光；母题再次流行时，原作会作为合集头部重新被看见（与 §2 的“金子总会发光”一致）。
- **升级通道**（REQ-MT-006）：追随作品被陪审判定有实质增量 → 升级为衍生或原创，脱离聚合、独立排序。真正的创新不会被埋没在母题里。

### 3.4 “脚开瓶盖”的完整推演

| 时间 | 事件 | 系统行为 |
|---|---|---|
| D0 | A 首发用脚开瓶盖 | 陪审判为原创，经波次放量火起来 |
| D2 | 出现 300 条相似内容 | 语义相似 + 时间爆发 → 生成母题 M，开创者 = A |
| D2~D5 | 新增 3000 条 | 预判为追随，进入 M 的共享探索配额：第 1000 条的配额只有第 1 条的 1/1000 |
| D3 | 推荐流 | M 只占 1 个推荐位：A 的原作 + 母题内质量最高的 3 条 |
| D4 | B 蒙眼完成，并讲解发力技巧 | 陪审判为实质增量 → 升级为衍生，独立排序；B 的版本可能成为子母题 |
| 持续 | 追随作品的广告收益 | 创作者份额的 10% 自动分给 A |
| D180 | 时间检验复审 | A 的原作共识保持 → 标记“经典”，母题再火时作为合集头部重新出现 |

### 3.5 母题饱和与垃圾信息

AI 让复刻的成本趋近于零。母题共享配额按 1/n 递减（REQ-MT-005）意味着：

- 第 1~10 条追随还能获得一些探索曝光（读者确实想看几个不同版本）；
- 第 1000 条追随几乎拿不到推荐曝光，**批量生成追随内容的期望收益趋近于零**；
- 这把“蹭热点”从流量套利变回了普通的兴趣表达。

## 4. 与评审维度的关系

原创性维度（REQ-OR-002）由四分类结果映射：

| 分类 | 原创性分（参考） | 后果 |
|---|---|---|
| 原创 | 0.8 ~ 1.0 | — |
| 衍生 | 0.5 ~ 0.8 | — |
| 追随 | 0.2 ~ 0.4 | 走隔离通道，**不触发**一票否决 |
| 搬运 | 0 ~ 0.2 | 一票否决 + 罚没 |

分类结果由陪审按质押加权多数投票得出，并写进结算结果，任何节点都能复算。

## 5. 风险与未决问题

1. **范式边界**：“一种玩法”到底多宽？太宽会误伤一个领域里的正常创作（例如“所有做菜视频”），太窄又挡不住追随。
   母题识别需要“时间爆发”这一条件，常态化的品类不会被识别为母题。
2. **开创者认定**：开创者可能来自外部平台 → 走原创申诉流程（REQ-OR-004/007）。
3. **陪审分歧**：追随 vs 衍生的边界主观 → 发布公开的判例库，作为陪审指南，并纳入治理。
4. **欠账复兴会被利用吗**：故意压低曝光来制造“欠账”？欠账只对质量达标且置信度足够的作品计算，而且复兴位置有总量上限。
