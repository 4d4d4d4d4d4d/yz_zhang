# 机制推演：原创性判定与反搬运、反同质化

- 状态：提议（对应 SPEC REQ-OR-001 ~ 007）
- 日期：2026-11-09
- 关联：[cold-start.md](cold-start.md)（探索池上线前必须先有查重，否则会被搬运内容淹没）

## 1. 问题拆分

“不原创”实际上是三类问题，难度和手段都不同：

| 类型 | 例子 | 难度 | 主要手段 |
|---|---|---|---|
| A. 直接搬运 | 下载别人的视频重新上传、加水印、裁边、变速 | 低 | 指纹查重 + 先签名者优先 |
| B. 洗稿 / 换皮 | 换配音、换字幕、AI 改写文案，信息内容不变 | 中 | 语义相似候选 + 人工陪审裁定 |
| C. 同质化低质 | 不抄具体某一条，但 AI 批量生产的模板化内容，没有信息增量 | 高 | 原创性/信息增量评审维度 + 相似簇多样性限制 |

原则：**机器负责“找出可疑的”，人（随机陪审）负责“裁定是不是”，经济机制负责“让抄袭不划算”。**
机器不直接定罪，因为洗稿和合理引用、二创的边界是主观的。

## 2. 第一道：指纹与先签名优先（REQ-OR-001）

每条内容发布时计算指纹，作为签名 payload 的一部分写进日志：

| 媒体 | 指纹 | 能抵抗 |
|---|---|---|
| 文本 | SimHash / MinHash（规范化后） | 改字、调序、同义替换的一部分 |
| 图像 / 视频关键帧 | 感知哈希（pHash/dHash），每秒 1 帧 | 重编码、缩放、加水印、轻度裁剪 |
| 音频 | 声纹指纹（类 Chromaprint） | 重编码、混入背景音 |

- **先签名者优先**：日志是哈希链，每条内容都有不可篡改的先后顺序。新内容和已有内容近似重复（距离低于阈值）时，较早签名的一方默认被认定为原作。
- **近重复不进探索池**：判定为近重复的内容不能获得 L0 免费曝光，同时自动通知原作者（原作者可选择发起申诉）。
- **可复算**：指纹算法和版本写进协议，任何节点都能重新计算并验证“A 和 B 的距离是多少”。
  视频抽帧、算指纹这类重计算可以交给枢纽节点做（效率），但结果是公开、可验证的，枢纽节点没有裁量权。

已知局限：攻击者可以通过翻转画面、重新剪辑顺序、大幅裁剪等方式绕过感知哈希——这正是第二道防线存在的原因。

## 3. 第二道：语义相似候选 + 陪审裁定（REQ-OR-002）

- 用固定版本的开源 embedding 模型（文本、视频-文本多模态）建相似索引，给每条新内容找出 Top-K 相似的已有内容。
- **相似候选只作为证据，不做判决**：陪审评审时，界面上会并排展示“与本内容最相似的 3 条更早内容”。
- 评审维度从三个增加到四个：

  | 维度 | 权重（提议） |
  |---|---|
  | 准确性 | 0.3 |
  | 质量 | 0.3 |
  | 有用性 | 0.2 |
  | **原创性（信息增量）** | **0.2** |

- **原创性门槛**：如果原创性维度的共识 < 0.3（被认定为抄袭/洗稿），则无论其他维度多高，综合分都封顶到 0.3 以下 → 无法晋级、不进推荐流。
  这是“一票否决”，避免“抄得很精致”的内容靠质量分混过去。

## 4. 第三道：经济机制让抄袭不划算

### 4.1 衍生声明与自动分账（REQ-OR-003）

二创、评论、翻译、混剪是正当的，应该被鼓励而不是被误杀：

- 内容可以声明 `derived_from: [原内容 ID, ...]`。
- 声明了衍生关系的内容**不会被判抄袭**，但广告收益中创作者份额的 **30%（默认）自动分给原作者**（多个来源按比例均分）。
- 这会形成一条“引用链”：原作者因被引用而持续获得收入 → 原创的长期回报高于搬运。

### 4.2 收益托管期 + 原创申诉（REQ-OR-004）

- 新内容的广告收益先进入 **7 天托管期**，之后才能提现。
- 托管期内任何人（通常是原作者）可以发起“原创申诉”，提交证据（更早的日志记录、原始工程文件、外部平台的先发链接、C2PA 凭证）。
- 申诉由一组新的随机陪审裁定（申诉人、被申诉人都不能挑选陪审）：
  - **成立**：托管收益全部转给原作者；被申诉人的发布质押罚没，并额外扣罚声誉；该内容下架推荐流。
  - **不成立**：申诉人押上的声誉被罚没一部分（防止恶意申诉）。

### 4.3 举报赏金（REQ-OR-005）

- 任何人都可以举报搬运，并质押少量声誉。
- 举报经陪审成立后，举报人获得被罚没质押的一部分 + 声誉奖励。
- 这把“查重”变成了一种分布式的、有回报的劳动——原作者不需要自己全网巡查。

### 4.4 搬运者的账本

搬运一条内容的期望收益和成本：

| 项 | 结果 |
|---|---|
| 免费曝光 | ❌ 近重复不进探索池 |
| 陪审结论 | 原创性一票否决 → 不晋级 |
| 广告收益 | 托管 7 天，申诉成立即转给原作者 |
| 声誉 | 发布质押罚没 + 额外扣罚；声誉低于门槛后无法发布到探索池 |

**期望收益 ≈ 0，期望损失 > 0**。抄袭在这个系统里是一笔亏本买卖。

## 5. 应对同质化（C 类）：信息增量与相似簇多样性（REQ-OR-006）

AI 批量生产的模板内容不一定是“抄某一条”，但会让推荐流变得千篇一律：

- **原创性维度评的是“信息增量”**：相对已有内容，它是否提供了新数据、新观点、新方法、新体验。陪审能看到相似候选，自然会给“又一条一样的”打低分。
- **相似簇多样性**：推荐流中，同一语义簇（相似度高于阈值的内容集合）最多出现 k 条（默认 2），第 k+1 条起按 0.5^k 衰减——这是对 REQ-RK-004“同作者多样性”的推广，变成“同内容多样性”。
- **AI 不是原罪**：`ai_generated` 只是披露，AI 生成的内容可以是高度原创的（原创的选题、数据、脚本）。我们评判的是贡献，而不是工具。

## 6. 与冷启动机制的衔接

```
发布 ──► 指纹查重（OR-001）
          │ 近重复 → 不进探索池，通知原作者
          ▼
        L0 探索池 + 随机陪审（含原创性维度 + 相似候选，OR-002）
          │ 原创性 < 0.3 → 一票否决
          ▼
        波次放量 …… 收益进入 7 天托管（OR-004）
```

顺序很重要：**查重必须在探索池之前上线**。否则探索池给每条新内容的免费曝光，会成为搬运者的最佳套利目标。

## 7. 风险与未决问题

1. **外部平台先发**：原作者先发在其他平台、后来才进入本网络，日志里没有先发记录 → 依靠申诉证据（外部链接、原始文件、C2PA）。P2 考虑接入公开的内容溯源服务。
2. **合理使用的边界**：评论、新闻引用、戏仿等合理使用，由陪审按公开的判例指南裁定，指南本身需要治理（REQ-GV-001）。
3. **embedding 模型可被对抗**：只作为候选，最终由人裁定；模型版本升级要走治理流程，并对历史内容重算。
4. **误伤热门题材的新人**：同一热门话题本身就会相似 → 相似簇限制只影响同一推荐流里的密度，不影响进入探索池；只有近重复（第一道）才会阻止进入探索池。
5. **陪审负担**：原创性评审要看对比材料，单次评审耗时更长 → 陪审参与奖励需要相应提高，并在容量推演中重新计算。
