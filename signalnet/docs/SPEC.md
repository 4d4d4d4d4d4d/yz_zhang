# SignalNet 规格说明（SPEC）

Version: 0.3.0
Last-Reviewed: 2026-11-09
Owner: 项目维护者 · 评审周期：每 14 天（超期会被 `harness/iterate.py` 标记为 🟠）

> 本文件是**唯一的需求真相源**。代码与测试通过需求 ID（`REQ-XX-000`）追溯到这里。
> 需求表格式被 `harness/gate.py` 解析，请保持 `| ID | 优先级 | 描述 | 验收标准 |` 四列格式。
>
> 优先级：**P0** = 当前里程碑必须实现，且必须有测试引用（门禁强制）；
> **P1** = 下一里程碑；**P2** = 远期。

---

## 1. 范围

当前：**完整机制内核 + 单节点服务**——身份与密钥恢复、内容与修订、随机陪审 commit-reveal、波次放量、PoS 共识、四分类与母题、原创保护与申诉、不被时间埋没的排序、广告分账/托管/防作弊、治理、HTTP API、SQLite 持久化、gossip 同步。`python -m signalnet demo [--production]` 端到端运行。

两种配置：`NodeConfig()` 宽松/仿真模式（开放评审，便于实验）；`NodeConfig.production()` 生产模式（邀请注册、随机陪审 + commit-reveal、签名回执、发布质押与配额、7 天托管、新号权重渐进）。

不在当前范围（P2）：客户端、真实支付通道对接、媒体存储与解码、合规审核流程、多写者联邦合并。

## 2. 术语

| 术语 | 定义 |
|---|---|
| DID | `did:sn:<ed25519 公钥 hex>`，自证明身份 |
| 内容（Content） | 作者签名的数据对象，ID 为规范化 JSON 的 SHA-256 |
| 评审（Attestation） | 评审者签名的三维评分 + 声誉质押 |
| 声誉（Reputation） | 绑定 DID 的整数积分，不可转让，不是代币 |
| 共识分（consensus） | 评审分数按 √质押 加权的中位数，∈[0,1] |
| 置信度（confidence） | 评审量饱和度 × (1 − 2 × 加权离散度)，∈[0,1] |
| 结算（Settlement） | 对一条内容的评审进行奖惩、并锁定共识分 |
| 枢纽节点（hub） | 提供加速能力的高性能节点，受份额上限约束 |
| micros | 金额单位，1 货币单位 = 1,000,000 micros |

| REQ-PS-008 | P0 | 桥接共识：关注图上做确定性标签传播得到群体；评审者分属 ≥2 个群体且各群体加权中位数相差 ≤ 2×容差才算 bridged，否则置信度减半；从 L1 晋级 L2 及以上必须 bridged（无关注图时不要求） | 跨群体一致 bridged=True；单一群体 bridged=False 且置信度更低 |
| REQ-PS-009 | P0 | 女巫抵抗：生产模式下注册需邀请（创世身份除外），每人每日邀请 ≤3、声誉需 ≥ 初始值一半；新身份评审权重乘数 = max(0.25, (一致评审次数+1)/4)；注册满 7 天才能被抽为陪审；被邀请人因搬运/作弊被处罚时邀请人连带承担 50% | 无邀请不能注册；超出邀请上限被拒；连带处罚精确；8 个新号无法压过 3 个老评审 |
| REQ-PS-010 | P0 | 声誉衰减：每跨一天，30 天不活跃账户超出初始值部分衰减 2%，注入新人扶持池；新注册者从池中获得最多 20 点 | 不活跃者衰减、活跃者不变；新人获得扶持且池余额相应减少 |
| REQ-PS-011 | P0 | 分品类评分权重（general/news/tutorial/entertainment/art），每类四维权重和为 1；原创性缺省时按其余维度重新归一化 | news 重准确性、art 重质量与原创；权重和为 1 |

### 3.6.1 冷启动与新人曝光（CS）

> 设计推演见 [design/cold-start.md](design/cold-start.md)。原 REQ-RK-007 并入 REQ-CS-001（ID 作废不复用）。

| ID | 优先级 | 描述 | 验收标准 |
|---|---|---|---|
| REQ-CS-001 | P0 | 探索池：推荐流至少 ⌈limit×比例⌉ 个位置（默认 10%）留给“未结算且具备探索资格”的新内容；自然内容不足时空位由探索内容补齐。分配按“已获探索曝光最少者优先”均分，同数时以 sha256(viewer+content_id) 打散；与作者声誉、粉丝无关。探索位标注“新作探索”，与广告位分开计数 | 多次刷新后每条新内容曝光次数相差 ≤1；高声誉与零声誉作者曝光相同；近重复与已结算内容不进探索池；比例为 0 时无探索位 |
| REQ-CS-002 | P0 | 随机陪审：每轮从“声誉 ≥20、注册满 7 天（创世除外）、未评审过该内容、未在本内容前几轮当过陪审、且不是作者本人/邀请人/被邀请人/同一邀请人的兄弟账号”的候选中，按 √声誉 × 新号乘数（标签内有可靠记录 ×2）加权无放回抽签；种子 = sha256(内容ID|轮次|开轮时日志 head)。生产模式首轮在发布后的下一次 tick 才抽签，作者无法通过反复修改内容刷陪审；非抽中者的评审被拒 | 任意节点重放可复算抽签；作者与新号不会入选；非抽中者被拒 |
| REQ-CS-003 | P0 | 波次放量：L0~L4 曝光上限 (100, 1000, 10000, 100000, ∞)，每级放大 ≤10 倍；每轮结算共识 ≥0.7 晋一级，下一次 tick 开下一轮并抽新陪审；共识使用全部轮次评审，但奖惩只针对本轮评审；推荐流不展示已达本级曝光上限的内容 | 连续 4 轮每轮只晋一级；0.5 分不晋级；超过上限后不再出现在推荐流 |
| REQ-CS-004 | P0 | 排序去规模偏置：质量项 = 贝叶斯收缩后验 (E×共识 + n0×先验)/(E+n0) + β/√(E+n0)，再乘一致度 (1−2×离散度)；E 为评审权重和，默认 n0=5、先验 0.5、β=0.2。评审人数只影响不确定性，不再直接给分打折 | 3 人评审的 0.9 分新作排在 12 人评审的 0.7 分作品之前；评审意见分歧大的内容排在一致的同分内容之后 |
| REQ-CS-005 | P0 | commit-reveal：开轮后 48h 内只接受承诺 sha256(评审+盐)，48h~72h 揭示，揭示内容必须与承诺一致；发现者奖励：策展分成权重 = 质押 × 波次权重（首轮 ×3、第二轮 ×2、其后 ×1，复审 ×1） | 承诺不泄露分数；揭示期前、盐错、改分均被拒；首轮/次轮权重 30/20（质押 10） |
| REQ-CS-006 | P0 | 发布质押与配额（生产模式）：发布锁定 5 点声誉（锁不住则不进探索池），首轮共识 <0.3 或被判搬运则罚没，否则解锁；每 DID 每日进入探索池 ≤3 条 | 第 4 条不进探索池；低质发布掉声誉且解除锁定 |
| REQ-CS-007 | P0 | 读者信号：签名 `reader_signal`（完播/收藏/值得看），每读者每内容一次，按 √声誉 加权，分 = 0.7×值得看 + 0.2×完播 + 0.1×收藏；≥5 条且与陪审共识相差 >0.3 时不晋级，下一次 tick 开“复审”轮 | 背离时 level 不变并开 review 轮；重复信号被拒 |

### 3.6.2 原创性与反搬运（OR）

### 3.6.4 四分类与范式隔离（MT）

> 设计推演见 [design/content-classes.md](design/content-classes.md) §3。

| ID | 优先级 | 描述 | 验收标准 |
|---|---|---|---|
| REQ-MT-001 | P0 | 四分类：搬运/衍生/追随/原创。机器预判（近重复→搬运；声明衍生→衍生；母题成员→追随；否则原创），陪审 `klass` 票按 √质押×新号乘数 加权多数裁定，平票按判定顺序 copy > derivative > follower > original；分类每轮重算 | 无票时等于预判；陪审可推翻预判；平票顺序固定 |
| REQ-MT-002 | P0 | 母题识别（两种信号，均要求时间爆发）：① 新标签（首次出现在 7 天窗口内）被 ≥5 个不同作者使用；② 宽松文本相似（距离 ≤20）的内容在窗口内来自 ≥5 个不同作者。已有母题优先吸收新成员；开创者 = 成员中日志顺序最早者 | #挑战 类新标签形成母题且开创者为首发；老标签（常态品类）与扩散缓慢的标签不形成母题；文案相同画面不同的追随不被判搬运 |

| REQ-MT-004 | P0 | 追随分账：追随作品创作者份额的 10% 给母题开创者（开创者是本人时不分） | 开创者获得创作者份额的 10%；分账守恒 |
| REQ-MT-005 | P0 | 母题饱和：探索池排序键 = (已获探索曝光 + 1) × 母题序号（开创者为 1），第 n 条追随获得约 1/n 的探索曝光 | 越晚的追随获得越少探索曝光 |

### 3.7 广告与收益（AD）

| ID | 优先级 | 描述 | 验收标准 |
|---|---|---|---|
| REQ-AD-001 | P0 | 读者观看广告，内容创作者获得收益；默认分账 创作者60/策展人15/节点15/公共池10（bps），创作者 ≥ 50% | 分账金额精确；非法比例被拒 |
| REQ-AD-002 | P0 | 有效曝光：停留 ≥ 2000ms、同读者同广告同日去重、创作者自刷无效、预算不足不计费 | 每条规则一个断言 |
| REQ-AD-003 | P0 | 分账守恒：所有份额之和 == 计费金额，舍入余数进公共池 | 任意金额守恒；累计收益 == 累计扣费 |
| REQ-AD-004 | P0 | 策展人份额按质押分给“与共识一致”的评审者；无策展人则进公共池 | 偏离者不分钱 |
| REQ-AD-005 | P0 | 广告位强制标注“广告”，间隔 ≥ 3 条自然内容（默认 5） | 间隔 < 3 拒绝配置；feed 中位置正确 |
| REQ-AD-006 | P0 | 曝光防作弊：生产模式下曝光必须是读者签名的 `view_receipt`（伪造签名被拒）；单读者每小时有效曝光 ≤60，超出计为服务节点的可疑流量；节点可疑占比 >20%（≥10 次）时 tick 没收其托管中的节点份额到公共池 | 未签名/伪造回执被拒；刷量节点的托管份额被没收且对账仍平 |
| REQ-AD-007 | P0 | 对账与提现：`statement(start,end)` 汇总期间应得收益（含托管）；DID 以签名 `withdraw` 记录提现，经可插拔的支付通道执行；恒有 已入账 + 托管中 + 已提现 == 广告扣费总额 | 对账单金额正确；超额提现被拒；任何时刻 reconciles() 为真 |
| REQ-AD-008 | P0 | 上下文定向：广告定向字段只允许 tags/categories，出现年龄、性别、位置、用户 ID、画像等字段即拒绝创建；曝光对象中没有任何个人画像字段 | 非法定向字段被拒 |

## 4. 不变量（任何改动都不得破坏）

1. **INV-1 无币**：系统中不存在可转让的价值单位；声誉不可转让。
2. **INV-2 买不到流量**：自然排序的输入中没有任何来自广告/支付的数据。
3. **INV-3 守恒**：广告扣费总额 == 各方收益总额。
4. **INV-4 可复算**：共识与排序是确定性纯函数；机制层不读取系统时间与随机数。
5. **INV-5 无垄断**：单节点流量份额有硬上限。
6. **INV-6 不被时间埋没**：内容的质量分不随时间衰减（时效型内容除外）。
