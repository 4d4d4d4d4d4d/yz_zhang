# SignalNet 愿景文档

> 让好内容靠质量而不是靠投流被看见。
> Version 0.1 · 2026-11-09

---

## 1. 背景：技术进步了，分发机制没跟上

### 1.1 一笔账

以当下的 AI 短视频生产为例，一条作品的总开支大致可以拆成三块（行业经验的量级估计，后续需要用真实数据校准，见 ROADMAP 的 M0-研究）：

| 开支项 | 占比（量级） | 说明 |
|---|---|---|
| **投流 / 买量**（抖音 DOU+、千川、小红书薯条、TikTok Promote 等） | **80% ~ 90%** | 不投流就几乎没有初始曝光 |
| 人力（策划、剪辑、运营） | 5% ~ 15% | |
| **模型与算力**（文生视频、配音、数字人等） | **约 3%** | 模型即使涨价 50%，总成本也只多 1~2 个百分点 |

结论很反直觉：**AI 把“生产”成本压到了几乎可以忽略，但“被看见”的成本没有下降，反而因为供给暴增而变得更贵。**
节省下来的生产成本，最后几乎全部以投流费用的形式交给了平台。

### 1.2 这说明了什么

1. **AI 没有真正提升整个链条的效率。** 生产端效率提升 10 倍，分发端是零和竞价，钱只是换了个口袋。
2. **质量没有成为分发的主变量。** 在“付费买初始流量 → 算法看数据 → 再决定是否放量”的机制下，预算决定起跑线，质量只能在买到的流量里证明自己。
3. **高质量信息没有走分布式网络。** 本该靠口碑、靠可信推荐层层扩散的内容，被压缩到一个中心化竞价黑盒里。
4. **AI 内容泛滥加剧了信任危机。** 生成成本趋近于零，标题党、伪信息的边际成本也趋近于零；平台的过滤靠的是商业利益，而不是信息的可靠性。

### 1.3 根因：技术与生产关系的错配

生产力（AI 生成）已经变成了“人人可用、近乎免费”的分布式能力；
生产关系（流量分配）仍然是“少数平台集中控制、按出价分配”。

> 生产力是分布式的，分配权却是集中式的——这就是错配。

要解决的不是“再做一个更好的推荐算法”，而是**流量分配权本身的归属问题**。

## 2. 愿景

**SignalNet 是一个去中心化的内容社区：内容被看见的程度，由社区用声誉为它的可靠性和质量做出的“可验证背书”决定，而不是由谁出价更高决定。**

三句话：

1. **质量决定分发**：分发权重来自 Proof of Signal（PoS）——评审者用自己不可转让的声誉为内容质量做质押背书，说对了涨声誉，说错了被罚没。
2. **广告养活创作者，但买不到流量**：商业模式仍然是广告——读者看了广告，发布者获得收益；但广告只能出现在明确标注的广告位里，**在架构上**无法影响自然排序。
3. **允许中心化节点提效，但不允许它垄断**：可以有高性能“枢纽节点”做索引、转码、分发加速，但它们的流量份额有硬上限，算法公开可复算，用户数据可带走。

## 3. 什么是 PoS（在本项目中的定义）

这里的 PoS **不是** Proof of Stake 加密货币，**不发币、不炒币、不做金融化**（见 ADR-0001）。

**PoS = Proof of Signal（信号证明）**：用“声誉质押”来表征一条信息的

- **可靠性**（accuracy）：事实是否准确，来源是否可查；
- **质量性**（quality）：制作、论证、表达的水准；
- **有效性**（usefulness）：对读者是否真的有用。

机制概要：

```
创作者发布(签名) ──► 评审者质押声誉并打分(签名)
                         │
                         ▼
             加权中位数 → 共识质量分 + 置信度
                         │
          ┌──────────────┼───────────────┐
          ▼              ▼               ▼
   与共识一致：+声誉   偏离共识：-声誉   作者：声誉随内容质量涨跌
                         │
                         ▼
          共识分 × 置信度 × (1+新鲜度加成) × 多样性 → 自然分发权重（质量不随时间衰减）
```

关键性质：

| 性质 | 做法 |
|---|---|
| 声誉不可买卖 | 声誉绑定身份（DID），系统中不存在转账接口 |
| 抗刷分 / 抗合谋 | 加权**中位数**而非平均数；权重 = √质押；单人权重占比封顶 |
| 说错有代价 | 偏离共识被罚没，长期瞎打分的人会失去评审能力 |
| 可验证 | 所有评审都是签名对象，共识计算是纯函数，任何节点都能复算 |
| 不让富者愈富 | √权重、单人上限、声誉衰减（P1）、新人扶持池（公共池资金） |

## 4. 商业模式：广告分账

```
广告主预算 ──► 有效曝光（停留≥2s、去重、非自刷）──► 按 CPM 计费
                                                     │
          ┌──────────────┬───────────────┬───────────┴──────┐
          ▼              ▼               ▼                  ▼
     创作者 60%     策展人 15%       服务节点 15%        公共池 10%
                (与共识一致的评审者)  (提供带宽/算力)  (协议维护、审核基金、新人扶持)
```

- **法币记账**，以 micros（百万分之一货币单位）为整数单位，分账**分毫守恒**。
- 创作者分成硬下限 50%（参考 YouTube 合作伙伴计划 55% 的长视频分成）。
- 策展人分成让“发现好内容”本身成为可获得收益的劳动——这是对投流的直接替代：**以前把钱交给平台买曝光，现在把钱分给真正帮你发现和验证好内容的人。**
- 广告位与自然内容分离，强制标注“广告”，比例上限 1/3（默认 1/5）。

## 5. 去中心化，但务实

完全去中心化往往意味着体验差、效率低，最终没人用。我们的取舍：

| 层次 | 立场 |
|---|---|
| 身份 | **必须去中心化**：自证明 DID，私钥在用户手里 |
| 内容与评审数据 | **必须可验证**：哈希寻址 + 签名 + 哈希链日志，任何节点可重放 |
| 共识与排序算法 | **必须公开可复算**：纯函数，无隐藏参数，无出价输入 |
| 存储、索引、转码、CDN | **允许中心化节点提效**，但受份额上限约束，可被替换 |
| 收付款通道 | 现阶段使用合规的法币支付通道（中心化），结算数据上链可审计 |

**反垄断三原则（硬约束）**：

1. **份额上限**：单个枢纽节点在一个结算周期内承担的流量 ≤ 20%（可治理调整，但有公示期）。
2. **无特权**：枢纽节点不能修改共识、不能插入未标注的推广、不能私有化排序算法。
3. **可退出**：用户的身份、内容、声誉、关注关系可以完整导出并迁移到任意节点。

## 6. 综合百家之长：已有项目的借鉴与教训

| 项目 | 借鉴 | 教训 / 我们的不同 |
|---|---|---|
| **Steemit / Hive**（Proof of Brain） | 用社区投票给内容定价、给策展人分成 | 代币化导致投机、鲸鱼操控投票、刷票互投；**我们不发币，权重开平方并封顶** |
| **Brave / BAT** | 用户看广告获得收益、隐私优先的广告投放 | 仍依赖代币；**我们用法币结算，收益给创作者与策展人** |
| **YouTube 合作伙伴计划** | 成熟的广告分账（长视频 55% 给创作者） | 分发由平台算法独占；**我们的排序开放可复算** |
| **X/Twitter Community Notes** | “桥接算法”：只有跨立场人群都认可的注释才会显示 | 只用于纠错；**我们把桥接共识引入质量评分（REQ-PS-008）** |
| **Bluesky / AT Protocol** | 可移植身份、可插拔的自定义 Feed、可组合的标注服务（Labeler） | **我们借鉴“用户可选排序算法”（REQ-RK-006）和数据可迁移** |
| **Mastodon / ActivityPub** | 联邦化、实例自治 | 发现困难、实例大小两极分化；**我们允许枢纽节点提效并给它设份额上限** |
| **Nostr** | 极简：签名事件 + 中继 | 缺少质量机制、垃圾信息多；**我们以 PoS 作为质量层** |
| **Farcaster / Lens** | 链上身份 + 链下数据的混合架构 | 用户门槛高；**我们避免强制钱包** |
| **EigenTrust / PageRank** | 信任可以在网络中传播 | 易被女巫攻击；**作为 P1 冷启动与女巫抵抗的参考** |
| **Wikipedia** | 声誉来自长期可信贡献，公共物品可持续 | **我们设立公共池资助审核与新人** |

## 7. 我们要避免成为的样子

- ❌ 又一个“发币 + 质押挖矿”的 Web3 项目
- ❌ 一个换了名字的中心化平台（某个枢纽节点事实上控制流量）
- ❌ 只有理念没有体验的“技术极客玩具”
- ❌ 放任违法违规内容的“无人区”（合规与审核是 P2 必做项，REQ-MO-001）

## 8. 成功的样子（北极星指标）

| 指标 | 含义 | 目标方向 |
|---|---|---|
| **创作者获客成本占比** | 投流/推广支出 ÷ 总开支 | 从 80~90% 降到 **< 30%** |
| **质量-曝光相关性** | 共识质量分与实际曝光量的秩相关系数 | 越高越好（> 0.6） |
| **最大节点流量份额** | 单个节点承担的流量占比 | 恒定 ≤ 20% |
| **创作者收入占广告收入比** | | ≥ 60% |
| **评审一致率** | 与共识一致的评审占比 | 健康区间 70~90%（太高说明没人敢提出异议） |

## 9. 开放问题（需要后续 SPEC 迭代回答）

1. 冷启动：新内容没有评审时如何获得第一批曝光？（候选：随机探索流量池 + 订阅关系）
2. 女巫攻击：如何以低门槛方式证明“一个人一个身份”？（候选：邀请链、人格证明、声誉渐进解锁）
3. 主观内容（娱乐、艺术）如何评“质量”？（候选：分品类评分维度、桥接共识）
4. 视频等大文件的去中心化存储成本谁承担？（候选：节点分成覆盖 + 内容寻址存储）
5. 法规：内容审核责任主体、广告法合规、税务。
