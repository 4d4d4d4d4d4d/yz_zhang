## 1. 用户想要的平台

一个人与人之间的窗口。每个人拥有独立门面及虚拟身份，整合不同平台的文章、视频、小店、直播，让人了解其能力与价值。AI 支持跨专业问题，必要时组织专家；人、人机、机机通过可信约定协作；经验经授权积累为平台和 Agent 的能力。范围覆盖遛狗/外卖/社交、机器人/工业品的跨模块组织、长期经营以及复杂公司活动，兼容公司、合伙和股权等现有关系。UI 应极简、有代入感、有克制而高质量的动效。

## 3. 前后端实现和迁移

前端：新增发现页、公开空间、空间编辑器、合作入口；原广场保留在 `/opportunities`；导航聚焦四入口；登录支持安全站内返回地址；空间私聊打开真实会话；登录和新页面使用克制的窗口视觉。未伪造人物、成交量或作品。

后端：新增 spaces 模块与 `b0a120260004` 迁移。保存只针对当前用户；发布是显式操作；列表/详情应用同一隐私过滤；分页受限，搜索转义；无服务器外链请求；版本冲突 409；账号注销清除空间，个人数据导出包含空间。

原生 App：本轮新增能力已进入共享 SDK，但 App 还没有空间 UI。已有 Expo 界面、钱包网页入口与原测试保留。移动 Web 的响应式实现不能写成原生 App 已完成。
