# 电子签约交付状态（2026-10-05）

平台签署已绑定可复算快照：合同编号、版本、双方、金额、奖金、服务费、条款、里程碑。首次签署后锁定分期；旧版仅条款签名继续按原格式验签。历史记录按原供应商校验，未知供应商不得回退为平台签名。Web/App 可在合同内查看验签结果。

`server/app/vendors/esign_v3.py` 是 e签宝 SaaS API V3 的对接适配器，包含请求鉴权、PDF 上传、人工签署草稿、开启流程、查询状态和获取登录签署链接。默认沙箱、存储上传域名明确允许列表、不自动重试结果未知的写请求、不在异常中输出服务方敏感响应。适配器通过模拟 HTTP 测试；没有真实账户验收。该适配器尚未接入平台业务签署状态机，未注册为 qualified 签名供应商，现有“签署合约”仍是平台见证。

仍需开发及验收的闭环：双方对外传输授权、合同 PDF 模板与版本绑定、持久化发起请求/不确定结果人工对账、实名签署页面、认证查询后的幂等入账、签后 PDF/证书/时间戳归档及验证、撤销与超时处理。必须在合同明确对应且全部必要签署完成后推进业务状态；不能根据浏览器跳转参数或未验签回调置为已签。

外部条件：运营主体的签约服务账户、API 套餐、应用凭证、实名/企业印章授权、正式回调域名、相关合同模板审核。不能仅提供一个密钥就宣称已达到商用签约条件。
