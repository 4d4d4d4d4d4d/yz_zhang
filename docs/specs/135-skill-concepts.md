
# 135 技能的语义匹配：技能概念表（撮合、认技能、个人空间、知识库检索）

> 状态：本批实现（V155）。编号 SKL-100~110；一并做完 SPACE-023b（作品与技能的语义匹配）、PROF-110（语义技能识别）、KB-110（知识库语义检索）的「概念层」。
> 来源：BACKLOG V155「『品牌设计』与『VI 设计』现在认不出是一回事」；台账 SPACE-023b / PROF-110 / KB-110；VISION V-5b「作品语义匹配未做」。
> 只增不减：原来字面相同的照旧匹配，只是**多认出**同一概念的不同写法；撮合的四项权重、加分项、阈值都不变。
> 写明的行为变化：要求「品牌设计」、本人写「VI设计」的人，技能分从 0 变成匹配——这是本批的目的。

## 0. 要解决的问题

发布方写「品牌设计」，接单的人写「VI 设计」「logo 设计」「标志设计」——撮合认不出、说明里认不出、能力画像标成「自述」、个人空间不算擅长、知识库搜不到。
平台上同一件事有很多叫法，这在中文里尤其常见（全半角、空格、中英混写）。

## 1. 业界怎么做（带来源链接）

- **技能本体 / 同义词表**：LinkedIn Skills Graph、欧盟 ESCO 技能分类（<https://esco.ec.europa.eu/en/classification/skill_main>）都是「一个规范技能 + 多个别名（alternative labels）」，匹配先归一到规范技能。
- **检索的同义词扩展**：搜索引擎的 synonym filter（例如 Elasticsearch synonym token filter，<https://www.elastic.co/guide/en/elasticsearch/reference/current/analysis-synonym-tokenfilter.html>）在查询时把词展开成同义词再检索。
- **向量相似兜底**：用语义向量找没收录的近义词——这里**这一批不做**：撮合在请求事务里，按 CONC-067 不能挂着事务调外部模型（见「没做的」SKL-110）。

| 编号 | 内容 |

## 4. 两端

- **Web 个人资料 → 技能**：边写边提示「『VI设计』按『品牌设计』匹配；『剪纸』平台还不认识，只按原样匹配」；「平台认得的技能」点一下加进去。
- **App**：之前**没有编辑技能的地方**，这批补上「我的 → 我的技能」：同样的提示与快捷选择、保存。
- **后台**：「技能概念表」一块：查、改别名、保存、下线。

## 5. 隐私与边界

概念表是公开的平台资产，不含个人数据。认不出的就当不同，不猜。

## 7. 没做的

- **SKL-110 向量相似兜底**：概念表没收录的近义词，用语义向量判断。要先离线算好平台技能词的向量（定时任务，不在请求里调模型），再在撮合时查表；需要接入语义向量服务（`PLATFORM_EMBEDDING_*`），记作「外」。
- 作品（个人空间作品描述）与任务说明的整段语义相似：同样依赖 SKL-110。
