
# 313 第十五轮场景发掘：老人上门助浴、上门理发

> 状态：本批实现（V340）。编号 SCN-186（老人上门助浴）、SCN-187（上门理发）。
> 来源：skill `scenario-discovery` 按方法每轮补充；上一轮是 V337（310 号）。BACKLOG V340。
> 只增不减：两个种子文件、两个新类目，「老人助浴」沿用持证类目准入（健康证明，一年一检）；已有包、类目、资质规则都不变。

## 0. 找信号

- 失能、半失能老人「洗澡难」是居家养老里最常被提到的一件事：家属不敢扶、卫生间滑、怕洗出事。民政部已有助浴的行业标准，地方在推，长护险在部分城市可抵扣——需求真实、做法有依据。
- 「理发难」是同一群人的另一件小事：下不了楼、卧床，几个月没剪过头发；现在多靠社区志愿者，供给零散。两件事常常是同一个子女在替父母找人（V202 替别人发单正好接住）。

## 1. 场景卡

### SCN-186 老人上门助浴

| 项 | 内容 |
|---|---|
| 人群 | 接上门助浴单的养老护理员；发单的是失能半失能老人的子女 |
| 要办的事 | 洗前量血压体温、不合适不洗；水温室温有数；两人一组防滑防跌；头晕胸闷马上停；遮挡、先问、不拍身体；按次托管 |
| 现在怎么办 | 家属自己洗或不洗；少数城市有政府购买的助浴车 |
| 痛点 | 频率 3（每周或每两周）；严重度 4（跌倒、心脑血管意外、尊严） |
| AI 能做几成 | 0.3：评估清单、意外处置提醒、回报写法；照护在人 |
| 商业价值 | 3：按次抽佣，复购高 |
| 交付成本 | 1：数据 + 一个持证类目（健康证明的有效期规则已有） |
| 风险关口 | 不做医疗：先评估、异常停、紧急 120；防跌倒（两人一组）；隐私与尊严（不拍身体）；健康证明 |
| 证据 | 民政部 2023 年 11 月公布《老年人助浴服务规范》行业标准，规范助浴人员、流程与意外事件处置；江苏为失能半失能老人提供专业助浴（[人民日报 2024-04-17](https://paper.people.com.cn/rmrb/html/2024-04/17/nw.D110000renmrb_20240417_1-13.htm)） |

分数 = 4 × 3 × 4 × 0.3 × 3 ÷ 1 = **43.2**。

### SCN-187 上门理发

| 项 | 内容 |
|---|---|
| 人群 | 接上门理发的理发师；发单的是高龄、卧床老人的子女，病人家属 |
| 要办的事 | 问清能不能坐、头皮情况、想剪成什么样；工具一人一消毒；卧床怎么剪；价格事先说清不加价；慢、多问 |
| 现在怎么办 | 社区志愿者义剪，或等家人有空带下楼 |
| 痛点 | 频率 3（每月）；严重度 3（卫生、尊严） |
| AI 能做几成 | 0.4：问清单、卧床剪法、计价写法 |
| 商业价值 | 2：单价低 |
| 交付成本 | 1：只写数据 + 一个类目 |
| 风险关口 | 工具消毒；头皮伤口避开；价格事先说清；不经同意不拍照 |
| 证据 | 社区理发师带工具上门给高龄、腿脚不便的老人理发（[中国日报网 2023-06-04](https://cn.chinadaily.com.cn/a/202306/04/WS647c6a57a310dbde06d21d74.html)）；苏州社区推出「居民点单—社区派单—合伙人接单」的上门服务（[扬子晚报网 2026-01-24](https://www.yzwb.net/news/jiangsu/suzhou/202601/t20260124_314764.html)） |

分数 = 3 × 3 × 3 × 0.4 × 2 ÷ 1 = **21.6**。

## 2. 做了什么

- `server/app/modules/packs/seeds/elder-bathing.json`：「老人助浴接单顾问」，两个方法（上门前问清五件事；备、评、洗、擦、收）、五条知识（洗前评估与不能洗的情况、头晕胸闷马上停、水温室温、两人一组防跌、尊严与隐私）、一个模板（按次、回报四次，清单含量血压体温）。新类目「老人助浴」，要审核通过的「健康证明」。
- `server/app/modules/packs/seeds/home-haircut.json`：「上门理发接单顾问」，两个方法、五条知识（工具一人一消毒、卧床怎么剪、头皮伤口避开、价格事先说清、慢一点多问）、一个模板。新类目「上门理发」。

## 5. 隐私、授权与边界

两个助手都只出草稿；钱、发布、分享个人信息都是人工关口；不建议血压过高或有伤口时照样洗、一个人搬老人、头晕继续洗、拍老人身体、工具不消毒、剪完加价；不做医疗诊断。
