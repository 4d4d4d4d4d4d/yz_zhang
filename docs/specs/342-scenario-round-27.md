
# 342 第二十七轮场景发掘：宠物洗护、代办年检，拦下年检包过

> 状态：本批实现（V369）。编号 SCN-229（宠物洗护美容）、SCN-230（代办年检）、SCN-231（发单拦下年检「包过」「不上线」）。
> 来源：skill `scenario-discovery` 按方法每轮补充；上一轮是 V368（341 号）。BACKLOG V369。
> 只增不减：新增两个种子文件、两个新类目（代办年检复用陪驾、代驾的驾驶证资质），发单拦截多一类；之前几类拦截的用例照过。

## 0. 找信号

- **宠物洗护美容**：宠物照护包（V200）只管喂食遛狗，不管洗护美容。洗护的风险集中在：
  - 猫应激；
  - 热风烘干箱闷出事；
  - 剪伤瞒着；
  - 不问就剃光；
  - 有人私下给宠物用镇静药（那是兽医的诊疗行为）。
- **代办年检**：每辆车都要，代办很常见。坑集中在：
  - 不用上线的年份也收「上线代办费」（2022 年起非营运小客车 10 年内只在第 6、10 年上线）；
  - 承诺「包过」「不上线」；
  - 违章没处理检不了；
  - 车况争议。
  「包过」「不上线」意味着虚假检验，平台不能接，应在发单时拦下，与 V358、V362 的做法一致。

## 2. 做了什么

- `server/app/modules/packs/seeds/pet-grooming.json`：「宠物洗护接单顾问」。
  - 五条知识：洗前看状况、不用镇静药、吹干不离人、剪伤马上告诉主人、按体型毛量报价。
  - 新类目「宠物美容」，不要资质。
- `server/app/modules/packs/seeds/vehicle-inspection-runner.json`：「代办年检接单顾问」。
  - 五条知识：先查今年要不要上线（政策条目，有效期到 2027-12-31）、不包过、违章先处理、拍车况、费用分开。
  - 新类目「代办年检」，要审核通过的「驾驶证（三年以上驾龄）」。
- `server/app/modules/task/errand.py` **SCN-231**（`fake_inspection`）：
  - 「年检 / 车检 / 验车 / 检车 / 上线检测」与「包过 / 保过 / 不上线 / 不用上线 / 不验车 / 不用验车 / 花钱过 / 走关系 / 搞定检测」同时出现时拦下，否定说法不算。
  - 「免上线」不算：新规本来有 10 年内免上线的说法。
  - 提示写明可以发「代办年检」单、或在「交管 12123」申领。
  - 这一类也能申请人工复核：复核类别名进了 `KIND_LABEL`，SDK 的 `ERRAND_REVIEW_CODES` 也加了它。
  - 新错误码进 i18n。
