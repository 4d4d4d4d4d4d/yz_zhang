
# 406 第五十八轮场景发掘：展台搭建、外卖店铺代运营

> 状态：本批实现（V433）。编号 SCN-296（展台搭建）、SCN-297（外卖店铺代运营）。
> 来源：按 skill `scenario-discovery` 的方法，每轮补一批场景；上一轮是 V430（403 号）。BACKLOG V433。
> 只增不减：只新增两个种子文件和两个新类目。已有的包（包括陪同口译、自媒体代运营、直播助手、网店客服）、类目、资质规则和发单拦截都不变。

## 0. 找信号

- **展台搭建**：会展是小团队、小工长常接的 B 端活，平台还没有。陪同口译包只提到「展会」场景。常见问题：
  - 不报图被叫停；
  - 背板没加固；
  - 私拉电线跳闸；
  - 布料不阻燃被要求整改；
  - 撤展超时押金被扣。
- **外卖店铺代运营**：小餐馆把外卖店铺托给别人打理，很常见。自媒体代运营和直播助手都写过「不刷单」，没人管外卖店铺这一块。常见问题：
  - 刷单被降权；
  - 图片与实物不符；
  - 代运营自己上满减倒贴；
  - 交出主账号密码后登不上；
  - 服务费不知道花在哪。

## 2. 做了什么

- `server/app/modules/packs/seeds/exhibition-booth.json`：「展台搭建接单顾问」。五条知识：
  - 报图审图；
  - 结构搭稳、高处作业持证；
  - 持证电工从指定电箱接电；
  - 材料阻燃、通道不堵；
  - 按时撤场、押金和加班费说清。
- `server/app/modules/packs/seeds/food-delivery-ops.json`：「外卖代运营接单顾问」。五条知识：
  - 不刷单不返现，也不帮店主做；
  - 菜品如实；
  - 改价和活动先算账、经店主确认；
  - 子账号、不要主账号密码和提现权限；
  - 每周报数据、数据不外传。
- 新类目「展台搭建」「外卖店铺代运营」，都不要资质。
