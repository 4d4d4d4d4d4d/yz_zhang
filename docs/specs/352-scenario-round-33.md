
# 352 第三十三轮场景发掘：宠物训犬、地陪导游

> 状态：本批实现（V379）。编号 SCN-244（宠物训犬）、SCN-245（地陪导游）。
> 来源：skill `scenario-discovery` 按方法每轮补充；上一轮是 V376（349 号）。BACKLOG V379。
> 只增不减：新增两个种子文件、两个新类目、一个资质名（「导游证」）。已有包、类目、资质规则、发单拦截都不变。

## 0. 找信号

- **宠物训犬**：养狗的家庭越来越多，扑人、拉扯、乱叫、护食是常见烦恼。纠纷集中在：
  - 寄训回来狗被打得胆小；
  - 「十天包会」回家全忘；
  - 寄训期间生病没报告；
  - 训犬师被咬说不清责任。
  宠物照护（V200）、宠物洗护（V369）不管训练。
- **地陪导游**：城市游、亲子游的散客想要一个懂行的本地人。坑集中在：
  - 「免费导游」带进购物店；
  - 导游开私家车接送收费（非法营运，出事保险不赔）；
  - 门票餐费代付加价；
  - 户外线路没讲路况。
  导游执业要导游证，平台在准入上把住。
