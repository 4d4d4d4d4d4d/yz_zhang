
# 291 缴库草稿等确认超过 3 天提醒财务

> 状态：本批实现（V318）。编号 PAY-042f。
> 来源：287 号 spec「没做的」——「缴库草稿等确认超过 3 天提醒财务（与申报期限对齐）」；BACKLOG V318。
> 只增不减：生成草稿时通知一次、确认、驳回都不变；草稿行多一个 `waited_days` 字段，多一个提醒 job。

## 0. 要解决的问题

V314 的缴库草稿只在生成时通知财务一次。没人点就一直挂着，而代扣的税款要按期申报缴纳，拖过期限是平台作为扣缴义务人的责任。

## 1. 业界怎么做

审批类待办超过时限按天催办，是平台已有做法（提额申请 247 号、大额出款 V108）。（本批没有另找外部来源。）

## 2. 规则

- 新 job `POST /finance/jobs/remind-tax-remits`（调度表 `tax_remit_reminders`，每小时跑一次）：等确认、生成超过 **3 天**的草稿，通知所有财务角色的管理员，写明编号、金额、已等几天、去哪里处理；**每笔一天最多催一次**；确认或驳回后不再催。没有 job 密钥 403。
- 草稿行多 `waited_days`：等确认的算到现在，处理过的算到处理时。
- Web「待确认的缴库」里，等了 3 天以上的标「已等 N 天，请尽快核对」。

## 3. 数据 / 接口

`tax_remit_requests.reminded_at`（迁移 `c1d220260072`）；`TaxRemitRequestRow.waited_days`；新 job 进调度表。

## 4. 两端

- **Web 后台「平台收支 → 待确认的缴库」**：如上。
- **App**：后台只在 Web，不涉及。

## 5. 隐私、授权与边界

只通知财务角色；提醒里只有草稿编号与金额，没有用户信息。
