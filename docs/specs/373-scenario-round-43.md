
# 373 第四十三轮场景发掘：上门汽车小保养、阳台绿植养护

> 只增不减：新增两个种子文件和两个新类目，都不要资质。已有的包（包括上门洗车）、类目、资质规则、发单拦截都不变。

## 0. 找信号

- **上门汽车小保养**：换机油、机滤、空调滤这类小保养，越来越多人想在自家车位做，不想去店里排队。常见问题：
  - 机油标号和手册对不上；
  - 说换了其实没换；
  - 废机油倒进下水道；
  - 顺手推销用不上的项目；
  - 地库干活被物业赶。

  已有的上门洗车包不碰机油和举升。
- **阳台绿植养护**：城市家庭养花多，出差、换季时常托人照看。常见问题：
  - 喷药后猫舔了叶子；
  - 出差回来花全干死；
  - 说好来三次只来一次；
  - 换盆伤根；
  - 探身到护栏外修花架。

## 1. 场景卡

### SCN-265 上门汽车小保养

| 项 | 内容 |
|---|---|
| 人群 | 上门保养师傅；发单的是有固定车位的车主 |
| 要办的事 | 机油照手册；换前换后给车主看；废机油带走交有资质的回收；安全支架再钻车底；只做说好的 |
| 现在怎么办 | 4S 店、路边快修店 |
| 痛点 | 频率 2：半年到一年一次；严重度 3：加错油伤车、污染、多花钱 |
| AI 能做几成 | 0.4：问清单、选油说法、换件清单；动手由人 |
| 商业价值 | 3 |
| 交付成本 | 1：只写数据，加一个类目 |
| 风险关口 | 钱和发布是人工关口；废矿物油属危险废物（《固体废物污染环境防治法》与《国家危险废物名录》） |
| 证据 | 法律条文；本轮没有引用外部报道链接 |

分数 = 3 × 2 × 3 × 0.4 × 3 ÷ 1 = **21.6**。

### SCN-266 阳台绿植养护

## 2. 做了什么

- `server/app/modules/packs/seeds/mobile-car-service.json`：「上门汽车保养接单顾问」。
  - 五条知识：照手册选油、换件给车主看、废机油是危险废物、安全支架、只做说好的。

  - 五条知识：先看光和水、有孩子宠物用药先说清、护栏外不探身、代浇按次拍照、换盆不伤根不打包票。
  - 新类目「绿植养护」，不要资质。高处作业不在这个类目里，知识条目里写明了。
