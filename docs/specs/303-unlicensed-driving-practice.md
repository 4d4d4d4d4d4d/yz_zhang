
# 303 发单时拦下没驾照找人陪练学车

> 状态：本批实现（V330）。编号 SCN-177。
> 来源：302 号 spec「没做的」——「发单时拦下『没驾照找人陪练学车』」；BACKLOG V330。
> 只增不减：发单与发布草稿多一种不承接的情形（与 294 号拦代开处方药同一处、同一种写法）；已有能发的单照常能发——拿了驾照找人陪练、陪着去驾校报名、请人开车送一程都不受影响。

## 0. 要解决的问题

V329 的「陪驾」类目只管**接单的人**要有审核通过的驾驶证（三年以上驾龄）。可发单的人如果自己还没驾照，想找个私人陪练在路上学车，那是无证驾驶——接单的人有证也不行，出了事平台与双方都说不清。

## 1. 业界怎么做

- 没有驾驶证在道路上驾驶机动车属于无证驾驶（道路交通安全法）；学员学车要在驾校的教练车上、由有资格的教练随车指导（《机动车驾驶证申领和使用规定》）。
- 同类平台的做法是在发布环节按关键词拦下明显违法的需求，说清原因与正路，拿不准的交人工复核。（本批没有另找外部来源，依据同 302 号。）

## 2. 规则

- `app/modules/task/errand.py` 的 `restricted_errand` 多一种 `learner`：同时出现「没驾照 / 没有驾驶证 / 驾照还没下来 / 无证学车」这类说法与「陪练 / 练车 / 学车 / 教我开 / 上路练」，且**没有提到驾校**（或者提到的是「不去驾校、比驾校便宜」这种绕开驾校的说法）。
- 命中时发单与发布草稿都返回 400 `unlicensed_driving_practice`：「平台不承接给没有驾照的人陪练学车：没有驾驶证在道路上开车属于无证驾驶，学车只能在驾校的教练车上、由有资格的教练随车指导。请先到驾校报名学车；已经拿到驾照、想找人陪着练胆或实习期上高速的，可以照常发『陪驾』单。」
- 不看类目：发到「其他」「跑腿」里也拦。纯文本规则，不调模型；漏掉的由运营人工复核。

## 3. 数据 / 接口

不新增表与接口。新错误码 `unlicensed_driving_practice` 进 `packages/core/src/i18n.ts`。

## 4. 两端

Web 与 App 发单页原样显示服务端的错误信息（与 `errand_restricted`、`k12_subject_tutoring` 一样，没有新界面）。

## 5. 隐私、授权与边界

只在发单那一刻看标题与描述，不存、不上报命中的内容。
