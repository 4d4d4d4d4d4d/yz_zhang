> 来源：skill `scenario-discovery`；BACKLOG V286（第十三轮排期：待办见底前主动发掘新场景，不只做台账里的边角）。

## 0. 场景卡

### SCN-150 孩子的兴趣陪练（钢琴、游泳、球类、画画；不含学科辅导）

| 项 | 内容 |
|---|---|
| 人群 | 有中小学孩子的家长（发单方，buyer） |
| 要办的事 | 找人陪孩子练琴、练球、学游泳，按次上门或在公开场馆 |
| 现在怎么办 | 熟人介绍、家长群、培训机构；单独私下约，没有回报、没有记录 |
| 痛点 | 分不清陪练与学科辅导的边界（怕踩线）；陌生人和孩子单独相处不放心；每次练了什么说不清；价格没数。频率：周（4）；严重度 4 |
| AI 能做到 | 分清能不能发、把单写清楚、讲清监护人在场 / 公开场所与按次回报、给同类成交价（约五成）；发单、付款、选人必须本人 |
| 商业价值 | 高频复购（按次 / 按月）、托管抽佣 |
| 交付成本 | 只写数据：212~216 号已把四道关口（不接学科类有偿家教、监护人声明、陪练看护类目要无犯罪记录证明、按次回报）做进平台，一直缺面向家长的包 |
| 风险关口 | 未成年人：发布与付款本人确认、不存孩子任何信息、不安排单独相处、助手不帮人把学科辅导换说法 |

### SCN-151 自由译者（文档翻译、字幕、本地化）

| 项 | 内容 |
|---|---|
| 人群 | 接翻译单的自由译者（creator） |
| 要办的事 | 接文档 / 字幕翻译单：问清需求、报价、交付、改稿 |
| 现在怎么办 | 熟人和中介转单；需求靠聊天记录，改稿和计价口径常扯皮 |
| 痛点 | 字数格式术语没问清就报价；证件翻译要机构盖章，个人译稿白做；客户资料保密；改稿没完。频率：周（4）；严重度 4 |
| AI 能做到 | 需求单体检（复用 `creator.brief`）、报价与改稿范围写法、同类成交价、保密与著作权常识（约六成）；报价成交、收款、签授权本人确认 |
| 商业价值 | 按千字 / 分钟计价、托管抽佣；与创作者包同一套交付验收 |
| 交付成本 | 数据 + 一个新类目「翻译」（一行代码，只补一次） |
| 风险关口 | 钱与签署本人确认；不冒充翻译机构盖章；不把客户资料传到不受控的在线工具 |

## 1. 业界与信号

- 翻译行业规模：《2024 中国翻译行业发展报告》称我国翻译人才 642 万、从业人员同比增长 6.8%（[人民日报 2024-04-01](https://paper.people.com.cn/rmrb/html/2024-04/01/nw.D110000renmrb_20240401_5-11.htm)）；《2026 中国翻译行业发展报告》称 2025 年行业总产值 701.2 亿元、从业人员 686.7 万（[科技日报 2026-04-26](https://www.stdaily.com/web/gdxw/2026-04/26/content_508436.html)）。
- 兴趣陪练：国家对义务教育阶段学科类校外培训严格管控（2021 年《关于进一步减轻义务教育阶段学生作业负担和校外培训负担的意见》），非学科类的体育、艺术陪练不在此列；平台 213 号已能拦下学科类有偿家教。
- 打分（`覆盖 × 频率 × 痛感 × AI × 价值 ÷ 成本`）：兴趣陪练 4×4×4×0.5×3÷1 = 96；自由译者 3×4×4×0.6×3÷1 = 86.4。
