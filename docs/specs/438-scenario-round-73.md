## 0. 找信号

- **签证材料准备**：证件照包只管照片尺寸，没有人管材料本身。这一块需求大，也是假材料、个人信息泄露的高发处。常见问题：
  - 照着网上模板准备，少了两样白跑一趟；
  - 中介帮着「做」流水，被拒还留了记录；
  - 护照照片被拿去注册账号；
  - 交了「包过」的钱不退；
  - 临时加翻译费、加急费。
- **门窗五金维修**：纱窗包只管纱网，淋浴房包只管淋浴房。推拉窗滑轮、平开窗合页执手、密封条这些小修很常见，但没人接。常见问题：
  - 配件不对，约第二次；
  - 拆推拉门磕了玻璃；
  - 换合页时窗扇掉到楼下；
  - 窗台积水、漏风；
  - 旧件不给看。

  在室内操作的不用证；要到室外高处干的，要高处作业证，用上 407 号的「发单人加选资质」。

## 1. 场景卡

### SCN-327 签证材料准备

| 项 | 内容 |
|---|---|
| 人群 | 材料整理顾问；发单的是自由行、探亲、商务出差的人 |
| 要办的事 | 按官网最新清单逐项列；只用真实材料、本人签名；证件信息用完即删；预约递交由本人、不承诺出签；按件报价、签证费另付 |
| 现在怎么办 | 旅行社、签证中介、照网上的帖子自己弄 |
| 痛点 | 频率 1；严重度 4：白跑、拒签留记录、个人信息被盗用 |
| AI 能做几成 | 0.6：清单、核对单、报价单的草稿；材料由银行和单位出具，签名递交由本人 |
| 商业价值 | 2 |
| 交付成本 | 1 |
| 风险关口 | 钱、发布、分享个人信息是人工关口；不做假材料、不代签（《刑法》第二百八十条，发单拦截 437 号同一条线）；个人信息只用于这次申请（《个人信息保护法》第六条）；不虚假宣传「包过」（《消费者权益保护法》第二十条） |
| 证据 | 法律条文；本轮没有引用外部报道链接 |

分数 = 2 × 1 × 4 × 0.6 × 2 ÷ 1 = **9.6**。

## 2. 做了什么

- `server/app/modules/packs/seeds/visa-docs-helper.json`：「签证材料整理顾问」。五条知识：
  - 官网清单；
  - 只用真实材料；
  - 证件信息用完即删；
  - 本人递交不承诺出签；
  - 报价写清签证费另付。
- `server/app/modules/packs/seeds/door-window-repair.json`：「门窗维修接单顾问」。五条知识：
  - 认窗型带配件；
  - 两人抬扇；
  - 外开扇防坠；
  - 密封条与排水孔；
  - 旧件与试开关。
- 新类目：
  - 「签证材料准备」，不要资质；
  - 「门窗五金维修」，可加选高处作业证。
