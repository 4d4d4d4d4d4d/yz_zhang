# 248 主管看全体客服的状态并替人恢复接单

> 状态：本批实现（V275）。编号 ESCA-066。
> 来源：240 号 spec「没做的」——「主管看全体客服的状态（谁暂停到几点、手上几个）并替人恢复」；BACKLOG V275（第十二轮排期 12 分）。
> 只增不减：客服自己的「我负责」、暂停与恢复（234 / 237 / 240 号）都不变；新增两个主管接口。
> 写明的行为变化：新增 `GET /admin/support/agents`、`DELETE /admin/support/agents/{user_id}/pause`（超级管理员）。

## 0. 要解决的问题

240 号让客服可以暂停接单，但主管看不到谁在、谁不在、谁手上压了几张；有人请假回来忘了恢复，新工单就一直绕开他，别人越分越多。

## 1. 业界怎么做

客服系统的主管视图通常列出每位坐席的在线状态、负责的队列与当前负载，主管可以替坐席切换状态。（本批没有另找外部来源。）

## 2. 规则

- 主管（超级管理员）在工单台点「看客服状态」：每位能处理工单的人（含超级管理员）一行——负责哪几类（没选写「都管」）、自动分配开没开、在岗还是暂停到几点（过期的暂停算在岗）、手上未结工单数（已结的不算）。
- 暂停中的人可以「替他恢复」：提前结束暂停，进审计，通知本人；没在暂停中的回 409。
- 普通客服看不到全体，也不能替别人恢复。

## 3. 数据

不新增表：读 `support_agent_scopes`（类别、自动分配、暂停到）与 `tickets`（未结且指派给他的数量）；一次查询取全部类别、一次分组查询取负载。

## 4. 接口

| 接口 | 说明 |
|---|---|
| `GET /admin/support/agents` | 超级管理员；每人 `{user_id, nickname, categories, declared, auto_assign, paused_until, open_tickets}` |
| `DELETE /admin/support/agents/{user_id}/pause` | 超级管理员；返回 `{user_id, paused_until: null}` |

错误码：`support_agent_not_paused`（进 `i18n.ts`）。SDK：`supportAgents`、`resumeSupportAgent`、`SupportAgentStatus`。登记：后台角色表、后台端点覆盖表、功能面清单。

## 5. 两端

- **Web 后台工单台**：主管多「看客服状态」（点开才加载），表格逐人一行，暂停的人旁边「替他恢复」。
- **App**：后台只在 Web，不涉及。

## 6. 隐私、授权与边界

只有超级管理员；只显示昵称与工作状态，不显示联系方式。
