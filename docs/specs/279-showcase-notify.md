
# 279 展示授权变化时通知接单人

> 状态：本批实现（V306）。编号 SCN-158。
> 来源：278 号 spec「没做的」——「授权撤回时通知接单人」；BACKLOG V306。
> 只增不减：授权 / 撤回接口的请求与响应不变，只多发站内信。

## 0. 要解决的问题

V305 撤回授权后，接单人空间里的作品静默消失，他不知道为什么；授权了也不知道可以去关联了。

## 1. 规则

- 发单人第一次授权时，通知接单人「可以展示这一单了」，写明任务编号（照着填进空间编辑）。重复授权不重复通知。
- 发单人撤回已有的授权时，通知接单人「展示授权已撤回」，写明作品已不再公开、编辑页里还在。没有授权时的撤回不通知。
- 走站内信的「任务」类（用户可在通知偏好里关掉）。

不新增；两端的通知中心原样显示。
