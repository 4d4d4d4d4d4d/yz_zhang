
# 275 子类参考价按发布方去重

> 状态：本批实现（V303）。编号 KB-097。
> 来源：271 号 spec「没做的」——「子类（cluster）参考价的去重（`cluster_id` 那条路）」；BACKLOG V303。
> 只增不减：子类参考价原有的 `sample_size / p50_cents / p90_cents / 时间范围` 不变，样本太少不出价的规则不变；只多 266 号那几个字段。

## 0. 要解决的问题

V293 只改了按类目取价那条路。按子类取价（KB-075，`/knowledge/price-reference?cluster_id=`）同样会被一家反复发同类单的发布方带偏。

## 1. 业界怎么做

同 266 号。（本批没有另找外部来源。）

## 2. 规则

- 与 266 号同一套口径（复用同一个函数）：只算子类里**已完成、有价**的样本（与 p50 同一口径，经过纠纷的、取消的不算行情）；发布方经来源任务查（一条查询取齐）；找不到来源的各算一位；一位占一半以上且至少 3 单才提示。
- 子类参考价多 `publishers / p50_by_publisher_cents / top_publisher_share / concentrated / note`。
- 顺带：子类参考价一直返回的 `cluster_id / p90_cents / first_sample_at / last_sample_at` 此前没在 SDK 的 `PriceReference` 里声明，本批补上（可选字段）。

## 3. 数据 / 接口

不新增。

## 4. 两端

两端「查参考价」的那句话（267 号的共享函数）对子类参考价同样适用；子类页的展示不变。
