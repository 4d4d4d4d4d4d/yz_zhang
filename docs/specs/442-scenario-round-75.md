# 442 第七十五轮场景发掘：健身器材安装维修、木地板维修

> 状态：本批实现（V469）。编号 SCN-331（健身器材安装维修）、SCN-332（木地板维修）。
> 来源：按 skill `scenario-discovery` 的方法，每轮补一批场景；上一轮是 V467（440 号）。BACKLOG V469。
> 只增不减：只新增两个种子文件和两个新类目。已有的包（家具安装、上门私教、地暖清洗、瓷砖美缝、石材养护）、类目、资质规则和发单拦截都不变。

## 0. 找信号

- **健身器材安装维修**：已有的包都没有提到跑步机、健身器材（关键词一个都查不到）。家用跑步机多，坏了厂家上门慢。常见问题：
  - 没断电就拆，电机突然转起来；
  - 一个人搬，砸了脚；
  - 跑带越调越偏；
  - 加机油打滑有味；
  - 孩子把手伸进跑带。
- **木地板维修**：石材养护、瓷砖美缝、地暖清洗只顺带提到「地板」，没人管木地板本身。常见问题：
  - 起拱修平又鼓；
  - 换板两个颜色；
  - 打钉打穿地暖管；
  - 一踩就响；
  - 拖地太湿没人提醒。

两类都不用强制资质。
