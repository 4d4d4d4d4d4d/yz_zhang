
# 131 AI 编排两端界面；编排按授权调用经验工具；助手只读检索经验；每月助手成本上限

> 状态：本批实现（V154）。编号 AGT-084~090；一并做完 ORC-066（编排没有用户侧界面）与 REL-110（助手成本记账与上限）。
> 来源：109 号 spec「这两个调用方今天都还不存在（编排器调用是 AGT-084）」；111 号 spec 4.5 节的设计；130 号「没做的」REL-110；台账 ORC-066；BACKLOG V154。
> 只增不减：编排循环（17 号 spec）、经验工具按钮（109 号）的行为一行不改——人点按钮仍走原来的关口与错误码（关口抽成共用函数，检查顺序不变）；
> 经验工具**默认不用**：编排的 `allow_tools` 默认关，接口不传就和原来一样。

## 0. 要解决的问题

- 编排循环（目标 → 规划 → 发任务 → 观测 → 评审 → 整改）只有接口，两端都没有界面：用户用不了平台最「AI」的能力。
- 经验工具（把历史闭环的做法变成一键生成的草稿）唯一的调用方是任务详情里的按钮；编排分发任务时不会用，助手回答问题时也不会引用。
- 助手花多少钱没有账，也没有上限。

## 1. 业界怎么做（带来源链接）

- **OWASP LLM06 Excessive Agency**（<https://genai.owasp.org/llmrisk/llm062025-excessive-agency/>）：给 agent 的工具要最小化、区分只读与写、写和花钱的动作要人确认、审计记下 agent 身份 + 用户身份 + 工具 + 动作 + 结果。
  这里：编排只用「只出草稿」的经验工具；要发起人显式授权；草稿挂在步骤上等「采用 / 丢弃」；调用记录写明 agent 身份（编排 #id 第几步）、授权人、工具与版本。
- **成本护栏**：主流 agent 平台都给自动运行设预算上限（本仓库的编排早有 AIO-024/025 的任务预算护栏）；这里补上**模型 / 工具的月度成本上限**，超了就不调用并写进时间线。

## 3. 规则与接口

| 编号 | 内容 |
|---|---|
| AGT-084 | 编排分发一步（真的建了任务）后，若发起人授权了：找适用于这一单的经验工具（最多 2 个），过**与人点按钮同一道关口**（可用、非退化态、单次成本、适用范围），再看本月助手成本，生成草稿挂在这一步上；任何一个没用上都写一条时间线，不影响这一步本身 |
| AGT-085 | `PUT /missions/{id}/tools`：授权 / 收回（只有发起人；管理员能看不能替人授权）；只影响之后分发的步骤 |
| AGT-086 | `POST /missions/{id}/steps/{step}/drafts/{inv}/adopt` / `discard`：采用只是标记，**不会替你发给任何人**；处理过的再处理说清楚（`draft_already_decided`） |
| AGT-087 | 审计：调用记录 `agent = orchestrator:mission#id:step#id`、`caller_id` = 授权人、`version` = 工具版本、`adopted` / `discarded` = 结果 |
| AGT-088 | 场景包助手的新工具 `experience.search`（只读）：按问题检索可复用、在用的经验单元，引用时写明「平台经验（第 N 版，已验证 / 未验证）」；只引用，不算一次调用；种子包「平台协作入门」的协作顾问已加上 |
| REL-110 | `GET /users/me/assistant-costs`：本月（北京时间自然月）agent 代调用的经验工具成本 + 例行任务的模型成本、上限、剩余、调用次数；编排调用前先看上限。人自己点按钮的不计入 agent 上限 |
| ORC-066 | 编排的用户侧界面（见下）；`finalReport` 仍未接（见「没做的」） |

## 4. 两端

- **Web `/missions`（工作台「助手」里有入口）**：我的编排列表；新建（目标、说明、类目、预算上限、最多几轮、验收要点、是否交给平台 AI 助理、是否用经验工具——**默认勾上，并写明只出草稿**；按钮叫「建好，先不花钱」）；
  详情：状态、轮次、完成度、评审分、预算（已付 / 占用 / 上限）、推进一轮、取消（先确认）、授权开关、每一步（状态、预算、评审、任务链接）与经验工具草稿（采用 / 丢弃）、时间线。
- **App「我的 → AI 编排」**：同样的列表、新建、详情、草稿采用 / 丢弃、推进、取消。
- **两端工作台「助手」**：本月助手成本与上限一行。

## 5. 隐私、授权与边界

- 编排的对象级授权：只有发起人（与管理员只读）能看；授权与确认草稿只有发起人。
- 经验工具只出草稿（109 号的 AST 闸门不变：工具与单元代码不得引用钱、合约、权益模块）。
- 退化态（经验检索不是语义模型）下编排照常分发，只是不用工具，时间线写明原因。
