
# 365 第三十九轮场景发掘：智能门锁安装、家用充电桩安装

> 状态：本批实现（V391）。编号 SCN-257（智能门锁安装）、SCN-258（充电桩安装）。
> 来源：skill `scenario-discovery` 按方法每轮补充；上一轮是 V389（362 号）。BACKLOG V391。
> 只增不减：新增两个种子文件、两个新类目；充电桩复用已有的「低压电工作业操作证」（`ELECTRICIAN_CERT`，已在高风险全抽名单里），不新增资质名。已有包、类目、资质规则、发单拦截都不变。

## 0. 找信号

- **智能门锁安装**：老房换锁、新房装锁越来越多。已有的监控安装包、组网包各提过一句「改默认密码」，但装锁本身的风险没人管：
  - 师傅录了自己的指纹没删；
  - 扩孔弄坏防盗门锁体；
  - 默认密码一直没改；
  - 机械钥匙少给一把；
  - 反锁不灵。
  门锁是进家门的凭证，指纹是敏感个人信息。
- **家用充电桩安装**：新能源车车主几乎都要装。风险集中在：
  - 从楼道插座私拉飞线（消防明令禁止）；
  - 物业不同意、报装没办，装完被拆；
  - 线径不够发烫；
  - 没有漏电保护；
  - 无证电工。

## 1. 场景卡

### SCN-257 智能门锁安装

| 项 | 内容 |
|---|---|
| 人群 | 门锁安装师傅；发单的是换锁、新装锁的住户 |
| 要办的事 | 先量门看锁体；指纹密码由主人自己录；机械钥匙全部交还；默认密码清掉；装完逐项试 |
| 现在怎么办 | 电商送装、开锁店 |
| 痛点 | 频率 2；严重度 3（进门凭证外泄、锁坏门坏） |
| AI 能做几成 | 0.4：问清单、匹配与扩孔的说法、交付试用清单 |
| 商业价值 | 2 |
| 交付成本 | 1：只写数据加一个类目 |
| 风险关口 | 生物识别信息单独同意（《个人信息保护法》第二十八条、第二十九条）；进门凭证不留存；分享个人信息是人工关口 |
| 证据 | 法律条文；本轮没有引用外部报道链接 |

分数 = 3 × 2 × 3 × 0.4 × 2 ÷ 1 = **14.4**。

### SCN-258 家用充电桩安装

| 项 | 内容 |
|---|---|
| 人群 | 持证电工；发单的是新能源车车主 |
| 要办的事 | 持电工证；物业同意、供电报装先办；专用回路加漏电保护；不私拉飞线；装完测接地试充 |
| 现在怎么办 | 车企指定安装商、物业推荐的电工 |
| 痛点 | 频率 1；严重度 4（火灾、触电、被拆） |
| AI 能做几成 | 0.3：问清单、报装与走线写法、验收提醒；动电必须由人 |
| 商业价值 | 3 |
| 交付成本 | 1：数据加一个类目（复用电工证） |
| 风险关口 | 低压电工特种作业操作证（准入审核、全抽）；严禁私拉电线充电；报装与物业手续由车主办 |
| 证据 | 法规名称；本轮没有引用外部报道链接 |

分数 = 3 × 1 × 4 × 0.3 × 3 ÷ 1 = **10.8**。

## 2. 做了什么

- `server/app/modules/packs/seeds/smart-lock-install.json`：「智能门锁安装接单顾问」。
  - 五条知识：先量门看锁体、主人自己录指纹密码、机械钥匙全部交还、默认密码清掉、装完逐项试。
  - 人工关口：钱、发布、分享个人信息。
  - 新类目「智能门锁安装」，不要资质（不是开锁，开锁是「上门开锁」类目，要开锁备案证明）。
- `server/app/modules/packs/seeds/ev-charger-install.json`：「充电桩安装接单顾问」。
  - 五条知识：持电工证、物业与报装先办、专用回路加漏电保护、不私拉飞线、测接地试充。
  - 新类目「充电桩安装」，要审核通过的低压电工作业操作证。

## 5. 隐私、授权与边界

- 两个助手都只出草稿。
- 门锁包：师傅调试时录过的临时指纹密码，交付前当着主人删掉；App 用主人自己的手机号绑定。
- 充电桩包：物业与报装手续由车主自己办，助手只告诉他要准备什么。
