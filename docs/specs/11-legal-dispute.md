# 11 · 法律与纠纷解决

模块前缀：`DSP`（纠纷）/ `LAW`（法律服务）

## 定位

三层递进的纠纷解决体系：
1. **协商**（双方自行/AI 辅助）
2. **平台仲裁**（基于任务证据链的裁决，联动合约自动执行）
3. **法律通道**（法律信息 AI、文书生成、律师转介、诉讼/仲裁指引）

> 合规底线：平台 AI 提供"法律信息"而非"法律意见"；正式法律服务由持牌律师提供。

## A. 纠纷流程

```
发起纠纷（任一方，限任务相关）→ 资金冻结（SC-008）
 → 协商期（48h，AI 调解建议）→ 达成和解 → 按和解方案执行
 → 协商失败 → 平台仲裁（提交证据 → 仲裁员裁决）→ 合约自动执行裁决
 → 不服裁决 → 申诉复核（一次）→ 终局 / 引导法律通道
```

| 编号 | 功能点 | 优先级 | 说明 / AC |
|---|---|---|---|
| DSP-001 | 发起纠纷 | P0 | 入口：任务详情/验收驳回/客服转入；选择纠纷类型 + 诉求（退款/放款/部分比例） |
| DSP-002 | 资金自动冻结 | P0 | 发起即冻结争议款项（SC-008） |
| DSP-003 | 证据链自动归集 | P0 | 系统自动打包：合约版本、任务描述、聊天记录、交付物、打卡记录、变更单；双方可补充上传 |
| DSP-004 | 协商与和解方案 | P0 | 双方可发起和解方案（比例分割），双方确认即执行 |
| DSP-005 | AI 调解建议 | P1 | 基于合约条款+证据+知识库同类判例给出中立建议方案（明示仅供参考） |
| DSP-006 | 平台仲裁工作台 | P0 | 仲裁员查看证据、双方陈述，出具裁决（全额/比例分割）+ 裁决理由；SLA 时限 |
| DSP-007 | 裁决自动执行 | P0 | 裁决结果驱动合约引擎放款/退款/分割；信用分联动（CRED-004） |
| DSP-008 | 申诉复核 | P1 | 一次申诉机会，升级至高级仲裁员/小组 |
| DSP-009 | 纠纷案例入库 | P1 | 裁决结果脱敏入知识库（KB-004），沉淀"判例"提升一致性 |
| DSP-010 | 恶意纠纷识别 | P2 | 高频发起、敲诈模式识别，联动风控 |

## B. 法律服务

| 编号 | 功能点 | 优先级 | 说明 / AC |
|---|---|---|---|
| LAW-001 | 法律知识 AI 问答 | P1 | RAG：平台规则 + 通用法律常识库；每次回答附免责声明；拒答超范围问题 |
| LAW-002 | 文书模板与生成 | P2 | 催告函、和解协议、投诉信等模板，AI 按案情填充草稿 |
| LAW-003 | 律师入驻与转介 | P2 | 认证律师（ACC-022）入驻提供付费咨询；平台抽佣；咨询走任务流程（本身就是一种任务类型） |
| LAW-004 | 诉讼/仲裁指引 | P2 | 按地区提供管辖、流程、材料清单指引 |
| LAW-005 | 证据导出 | P1 | 一键导出经存证的证据包（PDF+哈希校验），供司法程序使用；联动 SC-011 存证 |

## C. 治理与合规要点

- 仲裁规则公开：《平台争议处理规则》版本化公示，裁决必须引用规则条款。
- 仲裁员回避机制与抽查复核（质量审计）。
- 用户协议中明确平台仲裁的性质与司法救济权利不受限。
- 法律 AI 输出强制审查层：高风险问题（刑事/人身安全）直接引导报警或专业机构。
