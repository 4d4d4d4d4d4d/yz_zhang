
# 351 发单拦下篡改里程表

> 状态：本批实现（V378）。编号 SCN-243。
> 来源：349 号 spec「没做的」；BACKLOG V378（分数 16）。
> 只增不减：发单拦截多一类 `odometer_fraud`；之前九类的词表、否定判断、错误码不变，用例照过。

## 0. 要解决的问题

V376 上了二手车陪验包，教接单的人识别调表。可是另一头，卖车的人可以直接发「帮我把车的里程调回五万公里」，平台会照样把单发出去、找人来调。调表卖车是欺诈，平台不能接。

## 1. 业界怎么做

- 经营者提供商品有欺诈行为的，按价款三倍赔偿（《消费者权益保护法》第五十五条）。
- 二手车卖方应当向买方如实提供车辆的使用、修理、事故等情况（《二手车流通管理办法》第十四条）。

本批没有另找外部来源。

## 2. 规则

- **直接算**：
  - 「调 / 改 / 修改 / 篡改 / 改小 / 调小 / 往回调」后面 3 个字以内出现「里程 / 公里数 / 码表」；
  - 「里程 / 公里数 / 码表」后面 4 个字以内出现「调回 / 改回 / 调小 / 改小 / 往回调 / 清零」。
- **俚语**：「调表 / 改表 / 调码表」只在说到车的时候算（文字里有「车 / 里程 / 公里 / 仪表 / 码表」），「帮我调表，手表慢了」不算。
- **放行**：
  - 识别说法：命中词前 6 个字内有「警惕 / 防止 / 识别 / 鉴别 / 查 / 看看 / 是否 / 有没有 / 有无 / 怀疑 / 检测」，中间没有句读断开。比如「帮我看二手车，警惕调表」「查一下这台车有没有调表」。
  - 否定说法：「不调表、不改里程」，沿用 V362 的否定判断。
- **提示**：说清为什么，以及可以发「二手车陪验」单请人帮忙核对里程、识别调表。
- **误拦**：可以申请人工复核（V363）。比如换了新仪表要恢复真实里程，写明情况由运营判断。类别名「篡改里程表」。
