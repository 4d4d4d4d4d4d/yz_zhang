# 213 不承接中小学学科类有偿家教

> 状态：本批实现（V241）。编号 SCN-143。
> 来源：212 号 spec 关口 G1；BACKLOG V241。
> 只增不减：其他任务的发布规则不变；金融红线（FIN-021）、内容机审的顺序不变，本条排在金融红线之后、机审之前。
> 写明的行为变化：标题与说明里同时出现「辅导类的词 + 学科 + 中小学或孩子的说法」的任务，建草稿与发布都被拒绝。

## 0. 要解决的问题

家长在平台上发「给孩子找数学家教」很自然，但这正是国家管控的学科类校外培训，借「家政」「私教」「众筹」等名义变相开展的在查处之列（依据见 212 号第 1 节）。平台不能做这门生意，就要在发单那一刻说清楚，而不是等到有人接了单、上了门。

## 1. 业界怎么做

「双减」之后，主流家政、众包、二手平台都下架或拦截了中小学学科类家教信息，保留艺术、体育等非学科类。本平台照此执行，并把拒绝理由与能走的路写在错误信息里（与金融红线的做法一致：说清为什么，而不是只说「含违禁词」）。

## 2. 数据

不加表、不加字段。规则写在 `server/app/modules/task/k12.py`：

- 辅导类：家教、补课、补习、培优、辅导，以及「补 + 学科」（如「补数学」）；
- 学科：语文、数学、英语、物理、化学、生物、历史、地理、政治、道德与法治、奥数、作文；
- 中小学或孩子：小学、初中、高中、初一到初三、高一到高三、一到九年级、小升初、中考、孩子、儿子、女儿（高中学科类培训参照义务教育阶段管理）。

三样同时出现才拦。钢琴 / 游泳这类非学科（缺学科）、成人与大学生的辅导（缺中小学或孩子）、给小学生做教具设计（缺辅导类）都不拦。

## 3. 接口

| 接口 | 变化 |
|---|---|
| `POST /tasks`（建草稿或直接发布） | 命中时 400 `k12_subject_tutoring`：「平台不承接中小学学科类有偿家教……需要学科辅导的，请找有办学资质的培训机构；钢琴、游泳、运动这类非学科陪练可以照常发单。」 |
| 发布（`validate_publishable`，含草稿发布、编排发布等所有发布路径） | 同上：草稿里后来改成学科家教的，发不出去 |

新错误码进 `i18n.ts`。

## 4. 两端

不改界面：两端发布页原样显示服务端的拒绝说明（错误码在 `i18n.ts` 里有中文）。

## 5. 隐私与边界

- 纯文本规则，不调模型、不记录被拦的文字。
- 规则是关键词组合，可能有漏网或误拦：误拦的照说明改写（非学科类照常发）；漏网的由运营按举报下架。规则不判断谁是谁，只看任务文字。

## 6. 闸门与红验

`server/tests/test_k12_tutoring.py` 16 条（7 条认得出、7 条不误拦、建草稿与直接发布都拒绝并说明、草稿改成学科家教后发不出去）。

7 处变异（`scratchpad/mut241.py`）6 处首轮变红；「不看学科」首轮存活（反例里没有「孩子 + 辅导但不是学科」的），补了「孩子游泳辅导」后变红。
