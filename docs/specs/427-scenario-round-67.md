# 427 第六十七轮场景发掘：民宿退房保洁、露营搭建

> 状态：本批实现（V454）。编号 SCN-314（民宿退房保洁）、SCN-315（露营搭建）。
> 来源：按 skill `scenario-discovery` 的方法，每轮补一批场景；上一轮是 V452（425 号）。BACKLOG V454。
> 只增不减：只新增两个种子文件和两个新类目。已有的包（包括家务保洁、装修后开荒保洁、户外徒步领队、团建活动执行）、类目、资质规则和发单拦截都不变。

## 0. 找信号

- **民宿退房保洁**：家务保洁包管的是住户自己的家，没有短租房两拨客人之间的「翻房」。民宿、短租房东每天都要叫人，时间卡得紧，常见问题：
  - 下一位客人到了还没收拾完；
  - 床单没换；
  - 客人落下的东西说不清；
  - 损坏没报，下一位客人投诉；
  - 门锁密码外传。
- **露营搭建**：徒步领队管的是走路线，团建管的是公司活动，都没有「到营地替人把帐篷天幕炉具搭好」这一块。周末家庭露营多，常见问题：
  - 帐篷搭在河滩被涨水冲；
  - 大风掀翻天幕砸到孩子；
  - 帐篷里烧炭取暖中毒；
  - 退装备扣押金；
  - 走后满地垃圾被罚。

## 2. 做了什么

- `server/app/modules/packs/seeds/homestay-turnover.json`：「民宿保洁接单顾问」。五条知识：
  - 先查损坏和遗留物；
  - 布草一客一换；
  - 按清单打扫拍照；
  - 赶在下一位入住前；
  - 遗留物与门锁密码。
- `server/app/modules/packs/seeds/camping-setup.json`：「露营搭建接单顾问」。五条知识：
  - 选允许、安全的营地；
  - 地钉风绳与大风；
  - 炭火与一氧化碳；
  - 装备押金；
  - 撤场不留痕。
- 新类目「民宿退房保洁」「露营搭建」，都不要资质。

## 5. 隐私、授权与边界

- 两个助手都只出草稿；报价、收款、发布都由人确认。
- 民宿助手：
  - 不翻客人的东西、不拍私人物品；
  - 门锁密码只自己用，结束后请房东改；
  - 赔偿由房东和客人谈。
- 露营助手：炭火和燃气不进帐篷，夜里冷靠睡袋保暖。
