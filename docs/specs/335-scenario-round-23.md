
# 335 第二十三轮场景发掘：账号代运营、婚礼司仪，拦下刷粉刷量与买卖账号

> 状态：本批实现（V362）。编号 SCN-216（账号代运营）、SCN-217（婚礼司仪）、SCN-218（发单拦下刷粉刷量与买卖租借账号）。

> 只增不减：新增两个种子文件、两个新类目（都不要资质）、发单拦截多一类。否定判断放宽（见第 2 节），之前几轮拦截的全部用例照过。

## 0. 找信号

- **账号代运营**：小店、个人把短视频和图文账号交给工作室运营，单价高、按月付。最大的坑有三个：
  - 承诺「一个月涨一万粉」，靠刷；
  - 账号注册在代运营方名下，不合作了拿不回；
  - 刷量被限流封号。
  刷粉刷量、买卖租借账号是网信部门「清朗」系列行动持续整治的对象，平台不能接。这和 V358 拦刷单好评是同一类，应在发单时拦下。
- **婚礼司仪**：一年一次、时间点要紧。纠纷集中在：
  - 「定金」和「订金」没分清（违约时一个双倍返还，一个只退原数）；
  - 当天换人；
  - 台上念错名字；
  - 低俗婚闹。

## 2. 做了什么

- `server/app/modules/packs/seeds/account-operation.json`：「账号代运营接单顾问」（工作室人群，人工关口含签署）。
  - 五条知识：不刷粉刷量不买卖账号、账号在客户名下并交还权限、不承诺涨粉数、广告标明、每月运营报告。
  - 新类目「账号代运营」。
- `server/app/modules/packs/seeds/wedding-host.json`：「婚礼司仪接单顾问」。
  - 五条知识：定金与订金、本人上台、对流程与读音、不搞让人难堪的闹婚、加时加场写清。
  - 新类目「婚礼司仪」。
- `server/app/modules/task/errand.py`：
  - **SCN-218 刷粉刷量、买卖租借账号**（`fake_traffic`）：刷粉、刷量、刷播放、僵尸粉、买卖租借收购账号（「买 / 卖 / 收 / 租 + 几个字 + 账号」），「卖号码」不算。提示写明可以发内容策划、拍摄剪辑、账号代运营（账号在你名下）。
  - **否定判断放宽**：命中词前 6 个字以内有否定词（不 / 禁止 / 严禁 / 拒绝 / 非），且中间没有句号、逗号、分号、问号、感叹号断开，就不算。顿号、并列不算断开。
    - 不拦：模板里的「不刷粉刷量、不买卖租借账号」。
    - 照拦：「不想自己写，代写毕业论文」「我不懂，帮我刷粉」「不知道怎么做所以刷粉」。
