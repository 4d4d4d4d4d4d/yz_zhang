
# 314 App 发单页按城市查参考价

> 状态：本批实现（V341）。编号 KB-096。
> 来源：267 号 spec「没做的」——「App 发单页按城市查参考价（App 发单页还没有城市字段）」；BACKLOG V341。
> 只增不减：「查参考价」按钮与留空时查全国的那句话都不变；只在按钮上面多一个「按哪个城市查」的输入框。

## 0. 要解决的问题

同一类活各地价差很大（上海的保洁与三线城市的保洁不是一个价）。网页发布页按任务的城市查参考价，App 发单页只能查全国——在手机上发单的人报低了没人接、报高了多花钱。

排期时写的是「App 发单页还没有城市字段」。动手时看清：App 发的单目前都是线上单（线下单要定位，App 还没接），所以**这一批不给任务加城市**，只让查参考价时可以指定城市；App 发线下单另记一条（APP-097）。

## 1. 业界怎么做

服务撮合平台的参考价普遍按城市给（同城成交）。（本批没有另找外部来源。）

## 2. 规则

- App 发单页「查参考价」上面多一个输入框「按哪个城市查（留空查全国）」；填了就带 `city` 查（共享 SDK `priceReference(category, city)` 早就支持），结果前面标上城市（「杭州：同类闭环任务 3 单……」）；留空与以前一模一样。
- 前后空格去掉再查。

## 3. 数据 / 接口

不新增；沿用 `GET /knowledge/price-reference?category=&city=`。

## 4. 两端

- **App 发单页**：如上。
- **Web 发布页**：本来就按任务城市查，不变。

## 5. 隐私、授权与边界

只出聚合数（同 266 号）。

变异脚本：`scratchpad/mut341.py`。
