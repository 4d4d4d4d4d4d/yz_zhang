
# 362 第三十八轮场景发掘：燃气灶与热水器安装、成人外语口语陪练

> 状态：本批实现（V389）。编号 SCN-255（燃气具安装）、SCN-256（外语陪练）。
> 来源：skill `scenario-discovery` 按方法每轮补充；上一轮是 V387（360 号）。BACKLOG V389。
> 只增不减：新增两个种子文件、两个新类目、一个资质名（「燃气具安装维修从业资格证明」），这张证进高风险全抽名单（`high_risk_certs` 多一项）。已有包、类目、资质规则、发单拦截、K12 规则都不变。

## 0. 找信号

- **燃气灶与热水器安装**：换灶、换热水器、壁挂炉移位都很常见。已有的水电包（V346 前后）明确「燃气的活不碰」，家电维修包只管修不管装，这一块一直没有持证的类目。风险是不可挽回的：
  - 私改燃气管、燃气表；
  - 用打火机试漏；
  - 热水器装进浴室，一氧化碳中毒；
  - 软管过长、穿墙暗埋；
  - 无资质人员安装。
- **成人外语口语陪练**：职场面试、出差、出国旅游的成年人要练口语，线上就能做。坑集中在：
  - 承诺「保 7 分」「包过」；
  - 说好练面试结果一直闲聊；
  - 上了几次就要私下转账；
  - 上课被录像外传。
  中小学学科辅导受国家管控（213 号 spec 的 K12 规则），所以这个包只面向成年人；同一个类目里写成「给孩子补英语」照拦。

| 项 | 内容 |
|---|---|

## 2. 做了什么

- `server/app/modules/packs/seeds/gas-appliance-install.json`：「燃气具安装接单顾问」。
  - 五条知识：持资格上岗、只装不改管、合格软管、肥皂水检漏、烟管出户。
  - 新类目「燃气具安装」，要审核通过的「燃气具安装维修从业资格证明」（`GAS_CERT`），这张证进高风险全抽名单。
- `server/app/modules/packs/seeds/language-practice.json`：「外语陪练接单顾问」。
  - 五条知识：只陪成年人、不承诺提分保过、按场景定目标、在平台约课付款、录音先问同意。
  - 人工关口：钱、发布、分享个人信息。
  - 新类目「外语陪练」，不要资质。
