## 0. 找信号

- **证件照拍摄与修图**：人人都要，一年一两次（换证、签证、考试报名、求职）。最常见的纠纷是修得太狠：
  - 精修照考试报名被退回；
  - 用多年前的精修照换身份证，被要求重拍，起诉也没用。
  接单的人需要一条清楚的边界：办证用的只去瑕疵、不改五官、给原生版。
- **上门洗车**：频率高、单价低。纠纷集中在：
  - 洗完说多了划痕；
  - 物业不让洗；
  - 污水流一地被投诉；
  - 车里少了东西。
  平台的到岗打卡、上门回报拍照、发单人确认正好接得住「洗前拍车况」。

## 1. 场景卡

### SCN-214 证件照拍摄与修图

| 项 | 内容 |
|---|---|
| 人群 | 照相馆、上门拍照的摄影师、做修图的人；发单的是要办证、报名、求职的人 |
| 要办的事 | 问清用途与规格；办证报名的只去瑕疵、不改五官、给原生版；不用旧照不翻拍；电子版与冲印写清 |
| 现在怎么办 | 照相馆、证件照小程序，修图尺度全凭店家 |
| 痛点 | 频率 1；严重度 3（被退回、耽误报名办证） |
| AI 能做几成 | 0.5：问清单、按用途给修图边界、规格核对清单 |
| 商业价值 | 2 |
| 交付成本 | 1：只写数据加一个类目 |
| 风险关口 | 不伪造证件照、不换脸；制证用近期照片 |
| 证据 | 考研报名照片严禁修图，照相机构为考生提供「原生版」重拍（[新京报 2024-11](https://m.bjnews.com.cn/detail/1730812060129644.html)）；用多年前精修照换领身份证被要求重拍、起诉被驳回（[澎湃新闻](https://m.thepaper.cn/newsDetail_forward_29302830)，本轮从搜索摘要取得、原文页面在本环境打不开，没有逐字核对） |

分数 = 5 × 1 × 3 × 0.5 × 2 ÷ 1 = **15**。

### SCN-215 上门洗车

| 项 | 内容 |
|---|---|
| 人群 | 上门洗车、车内清洁的师傅；发单的是车主 |
| 要办的事 | 先问物业让不让洗；洗前绕车拍车况；免水洗或少水、污水收走；不占消防通道；车里的东西不动；分项报价 |
| 现在怎么办 | 洗车店、流动洗车 |
| 痛点 | 频率 3；严重度 2（划痕争议、被投诉） |
| AI 能做几成 | 0.4：问清单、报价写法、车况记录写法 |
| 商业价值 | 2 |
| 交付成本 | 1：只写数据加一个类目 |
| 风险关口 | 不占消防通道（《消防法》第二十八条）；遵守小区管理规约（《物业管理条例》） |
| 证据 | 本轮找到的中文材料多为商家推广，没有引用链接，只写法规依据 |

分数 = 4 × 3 × 2 × 0.4 × 2 ÷ 1 = **19.2**。
