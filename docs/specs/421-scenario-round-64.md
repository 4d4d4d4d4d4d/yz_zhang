# 421 第六十四轮场景发掘：门头招牌安装、活动音响灯光

> 状态：本批实现（V448）。编号 SCN-308（门头招牌安装）、SCN-309（活动音响灯光）。
> 来源：按 skill `scenario-discovery` 的方法，每轮补一批场景；上一轮是 V446（419 号）。BACKLOG V448。
> 只增不减：只新增两个种子文件和两个新类目。已有的包（包括展台搭建、婚礼策划、标志设计、团建活动执行）、类目、资质规则和发单拦截都不变。

## 0. 找信号

这一轮专门挑「要不要证取决于这一单」的活，正好用上 407 号的「发单人加选资质」。

- **门头招牌安装**：标志设计包只管设计稿，展台搭建只管展会里的展位。小店开张、换招牌常见的问题：
  - 装好被城管要求拆；
  - 没证的人站在梯子顶上接电；
  - 大风把招牌刮下来；
  - 下雨发光字漏电；
  - 满地边角料还占道。

  一楼一米五高、不接电的灯箱换面不用证；二楼外墙发光字既是高处又要接电。
- **活动音响灯光**：婚礼策划包只提到「音响话筒备份」。年会、发布会、生日会要单独请人搭声光，常见问题：
  - 话筒没电也没备用；
  - 插排串插排跳闸；
  - 宾客被线绊倒；
  - 灯架被风吹倒；
  - 晚上太吵被投诉。

  只带两只音箱、插现成插座的不用证；接配电箱的要电工证。

## 2. 做了什么

- `server/app/modules/packs/seeds/shop-sign.json`：「招牌安装接单顾问」。五条知识：
  - 先报批；
  - 高处、接电持证；
  - 支架打进结构抗风；
  - 防水加漏保；
  - 试亮清场。
- `server/app/modules/packs/seeds/event-av.json`：「音响灯光接单顾问」。五条知识：
  - 设备清单写备用；
  - 持证接电、独立回路；
  - 线缆贴地；
  - 灯架配重加安全绳；
  - 音量与结束时间。
- 新类目：
  - 「门头招牌安装」，可加选高处作业操作证、低压电工作业操作证；
  - 「活动音响灯光」，可加选低压电工作业操作证。
  - 两个都不强制资质。

## 5. 隐私、授权与边界

- 两个助手都只出草稿；报价、收款、发布都由人确认。
- 没有证的帮手只在地面配合，不上高处、不接电。
- 报批由店主自己去问，助手不替人办。
