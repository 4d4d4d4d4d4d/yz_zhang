# 02 · 账户、认证与信用体系

模块前缀：`ACC`（账户）/ `CRED`（信用）

## A. 注册与登录

| 编号 | 功能点 | 优先级 | 说明 / 验收点（AC） |
|---|---|---|---|
| ACC-001 | 手机号 + 验证码注册/登录 | P0 | 60s 防刷；同号多端登录可控 |
| ACC-002 | 密码登录与找回 | P0 | 密码强度校验；找回走短信/邮箱 |
| ACC-003 | 第三方登录（微信/Apple/Google） | P1 | App 端 Apple 登录为上架合规必需 |
| ACC-004 | 邮箱注册/绑定 | P1 | 海外用户与通知通道 |
| ACC-005 | 设备管理与异地登录提醒 | P1 | 可查看/踢出已登录设备 |
| ACC-006 | 账号注销 | P0 | 合规必需；有未结算合约/纠纷时阻断并提示 |

## B. 用户资料与技能档案

| 编号 | 功能点 | 优先级 | 说明 / AC |
|---|---|---|---|
| ACC-010 | 基础资料（头像/昵称/简介/所在地） | P0 | 所在地用于 LBS 默认城市 |
| ACC-011 | 技能标签（自选 + 平台标签库） | P0 | 标签库分级：大类→细分技能；供匹配引擎使用 |
| ACC-012 | 能力证明（作品集/证书/历史任务） | P1 | 闭环任务自动挂载到档案，可设可见性 |
| ACC-013 | 服务定价与可接单时间设置 | P1 | 时薪/次价参考；日历式可用时间 |
| ACC-014 | 角色视图切换（发布者/执行者） | P0 | 同一账号双角色，首页与工作台按角色切换 |
| ACC-015 | 兴趣标签 | P1 | 供圈层/内容推荐使用 |

## C. 实名与资质认证

| 编号 | 功能点 | 优先级 | 说明 / AC |
|---|---|---|---|
| ACC-020 | 个人实名认证（身份证 + 人脸） | P0 | 接第三方 eKYC；接单/提现前强制 |
| ACC-021 | 企业认证（营业执照 + 对公验证） | P1 | 企业发布者/服务商 |
| ACC-022 | 职业资质认证（如保洁、电工、律师执照） | P1 | 特定类目任务准入门槛 |
| ACC-023 | 认证徽章体系 | P1 | 实名/企业/资质徽章在名片、任务卡展示 |

## D. 信用体系

| 编号 | 功能点 | 优先级 | 说明 / AC |
|---|---|---|---|
| CRED-001 | 信用分模型 | P0 | 维度：履约率、准时率、评价分、纠纷率、认证等级；初始分 + 增减规则可配置 |
| CRED-002 | 双向评价（任务闭环后） | P0 | 星级 + 标签 + 文字；互评盲评（双方都评完或超时后公开） |
| CRED-003 | 信用等级与权益 | P1 | 等级影响：推荐权重、接单上限、提现速度、保证金减免 |
| CRED-004 | 违约记录与申诉 | P0 | 取消/超时/纠纷败诉记入；支持申诉复核 |
| CRED-005 | 保证金机制 | P2 | 高价值类目可要求执行者缴纳保证金 |
| CRED-006 | 信用分对外展示页 | P1 | 他人可见的信用摘要（脱敏） |

## E. 隐私与合规

| 编号 | 功能点 | 优先级 | 说明 / AC |
|---|---|---|---|
| ACC-030 | 隐私设置（资料/位置/朋友圈可见性） | P0 | 位置默认模糊到商圈级 |
| ACC-031 | 个人数据导出与删除 | P1 | PIPL/GDPR 合规 |
| ACC-032 | 未成年人限制 | P0 | 实名后未成年禁止接单与资金操作 |
| ACC-033 | 黑名单（用户互拉黑） | P1 | 拉黑后不再互相匹配/私聊 |

## 依赖
- eKYC 第三方服务、短信服务商、OAuth 提供方。
- 信用分依赖任务闭环数据（03）、纠纷结果（11）。
