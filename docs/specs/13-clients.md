# 13 · 客户端功能点（Web / App）

模块前缀：`WEB` / `APP`

## 端策略

- **App（iOS/Android）**：主端。LBS 任务、扫码打卡、推送、IM、短视频消费体验依赖移动端。建议跨端框架（Flutter / React Native）双端一套代码。
- **Web**：发布者与项目型任务主场景（母任务驾驶舱、长文创作、管理复杂表单效率更高）+ SEO 获客落地页。
- **管理后台 Web**：独立前端项目（见 12）。
- 两端共享同一 API/BFF 与设计系统 token。

## C. 客户端通用要求

- 组件库与设计系统统一（色彩/字体/间距 token 双端共享）。
- 全埋点规范：页面曝光、点击、转化漏斗（发布漏斗、接单漏斗为 P0）。
- 多语言框架预留；无障碍基础支持。
- App 上架合规：隐私弹窗、权限最小化申请（定位/相机/通知按需触发）。
