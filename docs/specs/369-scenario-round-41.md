
# 369 第四十一轮场景发掘：墙面刷漆翻新、宠物善终

> 状态：本批实现（V396）。编号 SCN-261（墙面刷漆）、SCN-262（宠物善终）。
> 来源：按 skill `scenario-discovery` 的方法，每轮补一批场景；上一轮是 V393（367 号）。BACKLOG V396。
> 只增不减：新增两个种子文件和两个新类目，都不要资质。已有的包、类目、资质规则、发单拦截都不变。

## 0. 找信号

- **墙面刷漆翻新**：旧房出租前、孩子房间换颜色、墙皮起了，都要刷墙。已有的验房、开荒保洁、除甲醛包都只提到「刷完要通风」，刷墙本身的毛病没人管：
  - 没铲旧墙皮直接刷，几个月又起皮；
  - 说好两遍面漆只刷一遍；
  - 漆点溅到地板家具；
  - 说是环保漆，进屋气味很大；
  - 颜色和小样差得多。
- **宠物善终**：养宠物的家庭越来越多，宠物走了以后，主人常常不知道怎么办。最常见的问题：
  - 遗体埋在小区或公园；
  - 说是单独火化，拿回来的骨灰不知道是谁的；
  - 借着主人难过推销高价套餐；
  - 宠物照片被拿去做广告。

## 2. 做了什么

- `server/app/modules/packs/seeds/wall-repaint.json`：「墙面刷漆接单顾问」。
  - 五条知识：先看墙况、漆由主人定、先保护、遍数照约定并拍照、通风几天再住。
  - 人工关口：钱、发布。
  - 新类目「墙面刷漆」，不要资质。上门前的清单里写明：外墙 2 米以上属高处作业，不在这个类目。
- `server/app/modules/packs/seeds/pet-aftercare.json`：「宠物善终接单顾问」。
  - 五条知识：轻声问清怎么走的、只送有资质的机构、单独与集体火化说清楚、骨灰遗物照清单交还、不推销不做宣传。
  - 人工关口：钱、发布、分享个人信息。
  - 新类目「宠物善终」，不要资质。

## 5. 隐私、授权与边界

- 两个助手都只出草稿；报价、收款、发布都由人确认。
- 善终包：
  - 主人发来的宠物照片、名字、家里情况只用来办这件事；
  - 想拿来当案例的，先单独问，主人同意了才用；
  - 疑似传染病的，提醒主人先问兽医。助手不判断死因。
