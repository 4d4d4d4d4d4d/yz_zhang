# 425 第六十六轮场景发掘：代祭扫、办公设备维修

> 状态：本批实现（V452）。编号 SCN-312（代祭扫）、SCN-313（办公设备维修）。
> 来源：按 skill `scenario-discovery` 的方法，每轮补一批场景；上一轮是 V451（424 号）。BACKLOG V452。
> 只增不减：只新增两个种子文件和两个新类目。已有的包（包括身后事办理、宠物身后事、手机电脑维修、数据恢复）、类目、资质规则和发单拦截都不变。

## 0. 找信号

- **代祭扫**：身后事办理包（`bereavement-affairs`）管丧事手续，没有每年清明、冬至替在外地的人去扫墓这一块。在外地工作的人多，每到节点集中出现。常见问题：
  - 扫错墓；
  - 到了现场加钱买贡品；
  - 在墓园烧纸引着草；
  - 拿去年的照片充数；
  - 照片拍进别人家的墓碑。
- **办公设备维修**：手机电脑维修、数据恢复都不管打印机复印机。小公司、工作室的打印机复印机坏了要上门修，常见问题：
  - 小毛病修完收八百；
  - 兼容硒鼓当原装；
  - 复印机拉走修，硬盘里的合同被人看过；
  - 废硒鼓扔楼道；
  - 修好第二天又坏，说不保修。

## 1. 场景卡

### SCN-312 代祭扫

| 项 | 内容 |
|---|---|
| 人群 | 代祭扫的人；发单的是在外地、走不开的家属 |
| 要办的事 | 核对墓位碑文；按约定项目不加钱；守防火规定不焚烧；带时间的连续照片如实回报；不拍别人家 |
| 现在怎么办 | 墓园自己的代祭服务、托老家亲戚 |
| 痛点 | 频率 1（一年一两次）；严重度 3：扫错、造假、引发火灾 |
| AI 能做几成 | 0.5：核对清单、项目报价、回报拍法的草稿；祭扫由人 |
| 商业价值 | 2 |
| 交付成本 | 1 |
| 风险关口 | 钱、发布、分享个人信息是人工关口；服务信息真实（《消费者权益保护法》第二十条）；墓园林区防火（《森林防火条例》） |
| 证据 | 法律法规；本轮没有引用外部报道链接 |

分数 = 3 × 1 × 3 × 0.5 × 2 ÷ 1 = **9**。频率低，但每年清明集中出现，交付成本只是一个文件，所以仍做。

### SCN-313 办公设备维修

| 项 | 内容 |
|---|---|
| 人群 | 上门修打印机复印机的师傅；发单的是小公司、工作室、学校办公室 |
| 要办的事 | 先检测报价旧件交回；配件写明原装兼容；设备硬盘里的文件不碰；废耗材回收；打测试页写保修 |
| 现在怎么办 | 卖设备的店包修、找路边维修 |
| 痛点 | 频率 2；严重度 3：乱收费、以次充好、文件泄露 |
| AI 能做几成 | 0.4：检测报价单、配件明细、保修说明的草稿；维修由人 |
| 商业价值 | 3：企业客户会复购 |
| 交付成本 | 1 |
| 风险关口 | 钱、发布、分享个人信息是人工关口；服务不合约定可重作或退款（《消费者权益保护法》第五十二条）；设备里的数据要保护（《数据安全法》第二十七条） |
| 证据 | 法律条文；本轮没有引用外部报道链接 |

分数 = 3 × 2 × 3 × 0.4 × 3 ÷ 1 = **21.6**。

## 2. 做了什么

- `server/app/modules/packs/seeds/proxy-tomb-sweeping.json`：「代祭扫接单顾问」。五条知识：
  - 核对墓位碑文；
  - 按约定项目；
  - 防火不焚烧；
  - 带时间的连续照片；
  - 不拍别人家。
- `server/app/modules/packs/seeds/office-equipment-repair.json`：「办公设备维修接单顾问」。五条知识：
  - 先检测报价、旧件交回；
  - 原装还是兼容；
  - 设备硬盘里的文件；
  - 废硒鼓回收；
  - 测试页与保修。
- 新类目「代祭扫」「办公设备维修」，都不要资质。

## 5. 隐私、授权与边界

- 两个助手都只出草稿；报价、收款、发布都由人确认。
- 代祭扫助手：照片只发委托人，不拍别人家的墓碑和祭扫的人。
- 维修助手：设备里的文件不拷不翻，拉回修之前请客户清除或拆下硬盘。
