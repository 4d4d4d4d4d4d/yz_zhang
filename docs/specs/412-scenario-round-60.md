# 412 第六十轮场景发掘：团建活动执行、寻宠服务

> 状态：本批实现（V439）。编号 SCN-300（团建活动执行）、SCN-301（寻宠服务）。
> 来源：按 skill `scenario-discovery` 的方法，每轮补一批场景；上一轮是 V436（409 号）。BACKLOG V439。
> 只增不减：只新增两个种子文件和两个新类目。已有的包（包括婚礼策划、宠物寄养、上门喂猫遛狗、接送孩子）、类目、资质规则和发单拦截都不变。

## 0. 找信号

- **团建活动执行**：没有一个包提到团建。婚礼策划包（V425）管的是一对新人的婚礼，不管公司几十人的出游。公司行政把团建外包给执行人是常见的活，常见问题：
  - 报价说人均三百，结束后又加场地费、服务费；
  - 户外爬山崴了脚，才发现谁都没买保险；
  - 下大雨活动泡汤，定金一分不退；
  - 返程大巴少点了一个人；
  - 晚宴一直劝酒，新同事很难堪。
- **寻宠服务**：宠物寄养（`pet-boarding`）和上门喂猫遛狗（`pet-home-care`）只写了「防走失」，走失之后怎么找没有人管。帮人找猫狗的人这一侧，常见问题：
  - 交了定金第二天就联系不上；
  - 说在找，一整天没有消息和照片；
  - 小区贴满寻宠广告，被物业罚款，主人被骚扰电话打爆；
  - 有人说捡到了，要先转钱才还；
  - 交回来的是只长得像的猫。

## 1. 场景卡

### SCN-300 团建活动执行

| 项 | 内容 |
|---|---|
| 人群 | 做团建执行的人；发单的是公司行政、团队负责人 |
| 要办的事 | 人均预算逐项列；户外看场地安全、买团体意外险；备雨天方案、写清改期规则；人数名单车辆逐一核对；活动自愿、不劝酒 |
| 现在怎么办 | 旅行社团建套餐、行政自己张罗 |
| 痛点 | 频率 2（一个季度一两次）；严重度 3：超支、有人受伤没保险、人掉队 |
| AI 能做几成 | 0.5：预算明细表、安全与保险清单、流程单与雨天备案的草稿；踩点与现场执行由人 |
| 商业价值 | 3：单价高，公司客户会复购 |
| 交付成本 | 1：只写数据、加一个类目 |
| 风险关口 | 钱、发布、分享个人信息是人工关口；群众性活动组织者的安全保障义务（《民法典》第一千一百九十八条）；报价真实全面（《消费者权益保护法》第二十条） |
| 证据 | 法律条文；本轮没有引用外部报道链接 |

分数 = 3 × 2 × 3 × 0.5 × 3 ÷ 1 = **27**。

### SCN-301 寻宠服务

| 项 | 内容 |
|---|---|
| 人群 | 帮人找走失猫狗的人；发单的是宠物主人 |
| 要办的事 | 分阶段收费、写清找不到怎么算；问清走失情况、按范围搜索、每天回报；启事贴在允许的地方、用虚拟号；不藏宠索钱、不诱捕别人的宠物；交接先核对特征和主人身份 |
| 现在怎么办 | 朋友圈和小区群转发、找「宠物侦探」私下交易 |
| 痛点 | 频率 1（一辈子碰上一两次）；严重度 4：主人着急时最容易被骗钱，找错、冒领也常见 |
| AI 能做几成 | 0.4：搜索计划、每日回报的写法、交接核对清单的草稿；搜索由人 |
| 商业价值 | 2 |
| 交付成本 | 1 |
| 风险关口 | 钱、发布、分享个人信息是人工关口；拾得遗失物应当返还，悬赏按承诺履行（《民法典》第三百一十四条、第三百一十七条）；服务不符合约定可以退款（《消费者权益保护法》第五十二条） |
| 证据 | 法律条文；本轮没有引用外部报道链接 |

分数 = 2 × 1 × 4 × 0.4 × 2 ÷ 1 = **6.4**。分数低是因为频率低：一个人很少碰上。但碰上的时候最急，私下交易最容易被骗，平台托管加分阶段收费正好接得住，交付成本又只是一个文件，所以仍做。

## 2. 做了什么

- `server/app/modules/packs/seeds/team-building.json`：「团建执行接单顾问」。五条知识：
  - 人均预算逐项列，不加隐形消费；
  - 户外看场地安全，买团体意外险，高风险项目不安排；
  - 提前看天气，备室内方案，写清改期取消规则；
  - 人数名单车辆逐一核对，返程再点一次名；
  - 活动自愿、不劝酒，不安排让人难堪的环节。
- `server/app/modules/packs/seeds/pet-finder.json`：「寻宠接单顾问」。五条知识：
  - 不先收全款，分阶段收，写清找不到怎么算；
  - 问清走失情况，按范围搜索，每天回报；
  - 启事贴在允许的地方，主人号码用虚拟号；
  - 不藏起宠物向主人要钱，不诱捕别人家的宠物；
  - 交接前核对特征和主人身份，受伤的先看。
- 新类目「团建活动执行」「寻宠服务」，都不要资质。

## 5. 隐私、授权与边界

- 两个助手都只出草稿；报价、收款、发布都由人确认。
- 团建助手：参加人名单只用于这一单的保险与点名。
- 寻宠助手：
  - 启事上不写主人的完整号码；
  - 查监控先征得物业或店家同意，不替主人去要别人的监控；
  - 诱捕笼只用来抓委托人家走失的那一只。
