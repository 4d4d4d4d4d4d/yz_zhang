
# 298 第十一轮场景发掘：情绪陪伴、上门私教

> 状态：本批实现（V325）。编号 SCN-170（情绪陪伴：线上倾听）、SCN-171（上门私教）。
> 来源：skill `scenario-discovery` 按方法每轮补充；上一轮是 V321（294 号）。BACKLOG V325。
> 只增不减：两个种子文件、两个新类目，外加一条全平台安全规则（见第 2 节）；已有包、类目与回答都不变，**只有一处改了措辞**：问题里有想伤害自己的说法时，法律问答与场景包助手以前回「请拨 110」，现在先给 12356 心理援助热线（110 / 120 仍在句子里）。

## 0. 找信号

- 情绪类付费服务近两年增长很快，倾听者门槛低、边界模糊（被当成心理咨询师、被要求见面、被教着推销时长），而最要紧的危机转介几乎没人讲。
- 上门私教、尤其上门给老人做居家健身指导在走红，最大的风险是身体状况没问清、出现不适还在练。
- 平台的助手在问题里碰到「自杀」只回「请拨 110」——对一个正想不开的人，这不是最合适的第一个号码。

## 1. 场景卡

### SCN-170 情绪陪伴：线上倾听

| 项 | 内容 |
|---|---|
| 人群 | 接线上倾听单的人（兼职为主）；发单的是深夜失眠、职场压力、独居的人 |
| 要办的事 | 守住边界：倾听不是治疗；碰到危机马上转介；不见面、不借钱、不推销时长；内容保密 |
| 现在怎么办 | 社交平台与陪聊软件私下接，规则全凭自觉 |
| 痛点 | 频率 3；严重度 4（危机处理不当可能危及生命；越界与诈骗） |
| AI 能做几成 | 0.4：边界与转介的提醒、计时写法；倾听本身在人 |
| 商业价值 | 2：单价低，但频次高 |
| 交付成本 | 1：数据 + 一条全平台规则（几行代码） |
| 风险关口 | 危机转介 12356 / 110 / 120；精神卫生法（心理咨询人员不得从事心理治疗或诊断）；钱只走托管 |
| 证据 | 2025 年 5 月 1 日起全国统一使用 12356 心理援助热线（[新华社 2025-05-08](https://www.news.cn/politics/20250508/b45e439c15bb4732858ad5c7640e9ba9/c.html)）；国务院办公厅 2026 年 1 月《加快培育服务消费新增长点工作方案》提出支持情绪式、体验式服务消费新场景 |

分数 = 4 × 3 × 4 × 0.4 × 2 ÷ 1 = **38.4**。

### SCN-171 上门私教

| 项 | 内容 |
|---|---|
| 人群 | 接上门健身指导的教练；发单的是想在家练的上班族、子女替老人发单 |
| 要办的事 | 首课前问清病史、体检、用药；练的时候盯住停下的信号；不做康复治疗；按次托管 |
| 现在怎么办 | 私下约，常一次收一大包课时费 |
| 痛点 | 频率 3（每周固定几次）；严重度 3（运动风险、预付课包难退） |
| AI 能做几成 | 0.4：评估清单、停下信号、计价写法；训练在人 |
| 商业价值 | 3：按次抽佣，复购高 |
| 交付成本 | 1：只写数据 + 一个类目 |
| 风险关口 | 身体状况先问医生；胸痛头晕立即停、必要时 120；不替代医生与康复治疗师；钱按次托管 |
| 证据 | 上门为老年人提供居家健身指导的「老年私教课」走红，单次 300 元至 400 多元，规范的教练首课前问病史、看体检报告、评估步态（工人日报，[光明网转载 2026-05-04](https://m.gmw.cn/2026-05/04/content_1304443182.htm)） |

分数 = 3 × 3 × 3 × 0.4 × 3 ÷ 1 = **32.4**。

## 2. 做了什么

- `server/app/modules/packs/seeds/emotional-listening.json`：「倾听接单顾问」，两个方法、五条知识（危机转介 12356、倾听不是心理咨询、只在线上、不推销时长、内容保密）、一个模板（线上倾听按单计时）。新类目「情绪陪伴」。
- `server/app/modules/packs/seeds/home-fitness-coach.json`：「上门私教接单顾问」，两个方法、五条知识（首课评估、停下信号、不做康复、证书上传、按次托管）、一个模板（按次上门、带回报清单）。新类目「上门私教」。
- **全平台安全规则** `app/core/crisis.py`：问题里有「自杀、轻生、不想活、活不下去、想死、自残、伤害自己」等说法时，场景包助手（任何一个包）与法律问答都直接回心理援助热线：「请马上拨打 12356……情况紧急请拨 110 或 120，并请身边可信任的人陪着你」。助手的回答多 `crisis: true`（只在这时出现）；法律问答的形状不变（`refused_reason: high_risk`）。其他人身安全问题照旧回 110。

## 3. 数据 / 接口

不新增表与接口。共享 SDK `PackAnswer.crisis?`。

## 4. 两端

服务包两端已接（V148），回答原样显示，热线就在回答的第一句。

## 5. 隐私、授权与边界

规则只看问题里的几种说法，不存、不上报这句话本身；两个助手都只出草稿，钱、发布、分享个人信息都是人工关口。
