
# 345 第二十九轮场景发掘：地推传单、汽车贴膜

> 状态：本批实现（V372）。编号 SCN-235（地推与发传单）、SCN-236（汽车贴膜）。
> 来源：skill `scenario-discovery` 按方法每轮补充；上一轮是 V370（343 号）。BACKLOG V372。
> 只增不减：新增两个种子文件、两个新类目（都不要资质）。已有包、类目、资质规则、发单拦截都不变。

## 0. 找信号

- **地推与发传单**：学生和零工最常接的兼职之一，量大、单价低。坑集中在：
  - 乱贴小广告被罚；
  - 拉新时替路人代填身份证、手机号；
  - 结算时被说「无效」；
  - 被要求刷单凑数（V358 的刷单拦截正好接住）；
  - 被场地方赶走。
- **汽车贴膜**：买车后的常见消费，单价中等。纠纷集中在：
  - 前挡贴太黑，年检过不了；
  - 贴牌膜冒充大牌；
  - 起泡翘边不认；
  - 施工划伤内饰。
  国家标准对前挡透光率有明确要求。

## 1. 场景卡

### SCN-235 地推与发传单

| 项 | 内容 |
|---|---|
| 人群 | 学生、零工；发单的是商家、推广公司 |
| 要办的事 | 只在允许的地方发、不乱贴；扫码注册让对方自己操作；不诱导老人小孩；结算口径写清、不刷单凑数 |
| 现在怎么办 | 兼职群接单，口头约定 |
| 痛点 | 频率 3；严重度 3（被罚、被克扣、被追责） |
| AI 能做几成 | 0.4：问清单、结算口径写法、话术自查 |
| 商业价值 | 2 |
| 交付成本 | 1：只写数据加一个类目 |
| 风险关口 | 张贴宣传品须经批准（《城市市容和环境卫生管理条例》第十七条）；个人信息须本人同意（《个人信息保护法》第十三条），不满十四周岁属敏感信息（第二十八条） |
| 证据 | 法规条文；本轮没有引用外部报道链接 |

分数 = 3 × 3 × 3 × 0.4 × 2 ÷ 1 = **21.6**。

### SCN-236 汽车贴膜

| 项 | 内容 |
|---|---|

| 要办的事 | 前挡与驾驶员视区透光率不低于 70%、不贴镜面膜；品牌型号如实写、亮膜卷；施工前后拍车况；返工与质保写清 |

| 交付成本 | 1：只写数据加一个类目 |
| 风险关口 | GB 7258《机动车运行安全技术条件》；虚假宣传（《消费者权益保护法》第二十条） |
