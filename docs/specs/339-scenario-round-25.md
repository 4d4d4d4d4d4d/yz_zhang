
# 339 第二十五轮场景发掘：派对布置、除甲醛治理

> 状态：本批实现（V366）。编号 SCN-225（派对与气球布置）、SCN-226（除甲醛治理）。
> 来源：skill `scenario-discovery` 按方法每轮补充；上一轮是 V364（337 号）。BACKLOG V366。
> 只增不减：新增两个种子文件、两个新类目（都不要资质）。已有包、类目、资质规则、发单拦截都不变。

## 0. 找信号

- **派对与气球布置**：生日宴、宝宝宴、求婚、开业，单价不高但量大。最要紧的风险是便宜的氢气球遇火爆燃。其他常见纠纷：
  - 酒店墙面被胶带撕坏；
  - 拱门挡了安全出口；
  - 数量对不上；
  - 撤场超时。
- **除甲醛治理**：新房、新家具，一年一次但单价高、焦虑强。监管部门把这一块列为整治重点：
  - 「零甲醛」「永久除醛」这类绝对化宣传；
  - 治理与检测利益捆绑；
  - 超资质出报告；
  - 拿试纸读数当结论。
  接单的人需要清楚的边界：只治理、不出报告、不指定检测机构、验收看国标。

## 1. 场景卡

### SCN-225 派对与气球布置

| 项 | 内容 |
|---|---|
| 人群 | 气球与场景布置师傅；发单的是办生日宴、求婚、开业的人 |
| 要办的事 | 只用氦气；先问场地规矩；不挡安全出口与消防通道、远离明火；分项报价；按时撤场带走垃圾 |
| 现在怎么办 | 花店、婚庆、气球店顺带做 |
| 痛点 | 频率 2；严重度 3（爆燃伤人、赔墙面） |
| AI 能做几成 | 0.4：问清单、分项报价写法、进场撤场清单 |
| 商业价值 | 2 |
| 交付成本 | 1：只写数据加一个类目 |
| 风险关口 | 禁用氢气充气球（国家有关部门 2006 年通知、多地禁令）；不得占用、堵塞疏散通道与安全出口（《消防法》第二十八条） |
| 证据 | 武汉警方 2024 年 12 月提示严禁民用轻气球使用氢气充装，并引用 2006 年通知（[中华网转载极目新闻 2024-12-04](https://news.china.com/socialgd/10000169/20241204/47703152.html)，本轮从搜索摘要取得，没有逐字核对） |

分数 = 3 × 2 × 3 × 0.4 × 2 ÷ 1 = **14.4**。

### SCN-226 除甲醛治理

## 2. 做了什么

- `server/app/modules/packs/seeds/party-decor.json`：「派对布置接单顾问」。
  - 五条知识：只用氦气、先问场地规矩、不挡安全出口远离明火、分项报价、撤场。
  - 模板回报清单含「进场先看安全出口与灭火器」。
  - 新类目「派对布置」。
- `server/app/modules/packs/seeds/formaldehyde-treatment.json`：「除甲醛接单顾问」。
  - 五条知识：不承诺零甲醛、不出报告不指定机构、按标准采样试纸只当参考、产品成分说清、国标限值 0.08 mg/m³。
  - 新类目「除甲醛治理」。
