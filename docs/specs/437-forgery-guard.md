# 437 发单拦下伪造证件、假流水与虚开发票

> 状态：本批实现（V464）。编号 SCN-326。
> 来源：准备第七十三轮场景发掘的「签证材料准备」包时试发单拦截，以下这些一条都不拦：
> - 「帮我做一份假的银行流水」
> - 「伪造在职证明」
> - 「帮我办个假证」
> - 「虚开增值税专用发票」
> - 「私刻一个公章」
>
> 平台会因此担责，排在场景发掘前面先补。
> 只增不减：在拦截里加一类，已有的十类与它们的放行边界都不变。

## 0. 要解决的问题

以下行为都可能触犯刑法：
- 伪造、变造、买卖国家机关公文、证件、印章；
- 伪造公司、企业印章；
- 伪造、变造身份证件（《刑法》第二百八十条）；
- 虚开增值税专用发票（第二百零五条）、虚开普通发票（第二百零五条之一）。

签证、贷款、租房最常见的是假银行流水、假收入证明、假在职证明。

## 1. 业界怎么做（带来源链接）

各家众包、跑腿平台的禁发清单都列有「办证刻章」「代开发票」（指虚开）这类；文字规则先拦，拿不准的人工复核。本轮没有引用外部报道链接。

## 2. 数据

不新增表。拦截类别 `forged_documents`，按 SCN-248 的登记表登记四处：
- `errand.KIND_CODES`；
- i18n；
- 复核类别名「伪造证件假流水假发票」；
- SDK 的 `ERRAND_REVIEW_CODES`。

## 3. 接口

不新增接口。发单、改单时的拦截（`assert_no_restricted_errand`）多一类。命中时：
- 返回 400 `forged_documents`；
- 告诉用户该怎么办：
  - 需要证明，向出具单位申请；
  - 个人开发票，到税务机关代开；
  - 材料的整理、翻译、核对可以照常发单；
- 附上「申请人工复核」的出路（V363）。

**拦什么**：
- 伪造、造假、做假、仿造、变造、假冒、P 图、PS，后面 8 个字以内跟着证件或证明，包括：
  - 身份证、证件（不含证件照）、学历、毕业证、驾照、护照、签证、户口本、结婚证、房产证；
  - 营业执照、公章、印章；
  - 银行流水、收入证明、在职证明；
  - 病历、诊断证明、体检报告；
  - 发票。
- 「假的 + 上述」。
- 办假证、假证（不含「假证明」）、做假账、私刻……章。
- 虚开……发票。
- 买 / 卖 / 收购发票。
- 倒装说法：「流水不够帮忙做假」「收入证明帮我做高一点」。

**放行**：
- 前面是否定说法，或者识别、鉴别、核验、辨别、举报；后面紧跟着举报、识别、被骗、报警。
- 证件照修图。
- 「APP」里的 P（只认单独的 P / PS）。
- 真的请假：「请假的诊断证明」「病假条」。
- 到税务局代开发票、去银行打印流水、买东西要发票、整理翻译真实材料。

## 4. 两端

两端早就接好了，不用改：
- 发单页按错误码显示文案；
- 码在 `ERRAND_REVIEW_CODES` 里，就显示「申请人工复核」（V363、V381）。

## 5. 隐私、授权与边界

只看发单文字，不调模型；误拦走人工复核。
