# 62 额度必须是累计的（TEAM-050~055）

> 探针实测，一个「单笔额度 ¥10」的普通成员，**零审批**从团队钱包划走了 ¥200：
>
> ```
> 团队余额: 80000   成员到手: 20000
> 成员单笔额度 1000，无需任何审批就划走了： 20000
> ```
>
> 做法很朴素：同一笔申请发 20 次，每次都在额度内，每次都自动批准并执行。
> 唯一拦住他的是团队钱包里还有多少钱。

## 0. 这个洞平台自己修过一次

V55 的提现风控：

> 改造前只判单笔，连提 5 笔 ¥9,999 可以 ¥49,995 零人审出账。

一模一样的形状，在**那之后**写的团队模块里又出现了一次。

原因也看得见：`spend_block()` 的注释写着「单笔额度」，
写的人**知道**它只管单笔——但没有人问「那累计谁管」。

> **一个只管单笔的额度不是额度，是一张可以无限刷的卡。**

## 1. TEAM-050 额度的语义：从「单笔」改成「月度累计」

两种补法：

| 方案 | 做法 | 取舍 |
|---|---|---|
| A 保留单笔，另加一个月度额度 | 两个数字 | 「单笔 ¥10 / 月度 ¥500」要解释两次；而且**单笔限额在有了月度累计之后是冗余的**——超过月额度的单笔天然过不去 |
| B **把既有字段的语义改成月度累计** | 一个数字 | 选它 |

**选 B。** 而且它更接近人对「额度」这个词的默认理解：
「我给他 500 的额度」，几乎没有人是在说「每笔 500，随便刷」。

既有数据不迁移数值，只换语义——**方向是变严的**（同一个数字，
从「每笔」变成「整月」）。变严的误判可以被 owner 一键调高，
变松的误判是钱没了。

## 2. TEAM-051 admin 不再无限额

```python
if member.role == "admin":
    return ""          # 改造前：管理员完全不受限
```

owner 豁免是**讲得通**的：他就是定额度的那个人，给他设限没有意义
（他随手把自己的额度调高即可，多一道手续不增加任何安全性）。

admin 豁免**讲不通**：admin 是被授予权限的人，不是授予权限的人。
现在 admin 与 member 走同一条月度额度，只是默认值可以设得高。

## 3. TEAM-052 团队月度预算池

按人设额度解决不了一件事：**每个人都在自己额度内，加起来仍然爆表**。

所以团队多一个 `monthly_budget_cents`（0 = 不设池）。它的性质与个人额度不同：

- 个人额度是**权限**：能不能自助花、要不要审批；
- 预算池是**总量**：这个月团队总共花多少。

因此预算池**在执行时判，对所有路径生效**——包括已经被 admin 批准的申请，
也包括 owner 自己。审批权限不能突破总量：要突破就去改池子，
那是一个**留痕的、显式的**动作，而不是审批时顺手放过去。

## 4. TEAM-053 只算「已执行」，但执行时要重新判

审批期间不预扣（TEAM-022 的既有判断，不改）。所以累计只能按**已执行**的算。

由此带来一个必须堵的缝：批准了 10 笔、逐个执行——如果只在申请时判池子，
这 10 笔会全部通过。所以 `execute_spend` 里**重新判一次池子**，
和它本来就在做的「余额是否仍然够」是同一类检查、同一个理由：
**审批到执行之间，世界会变。**

## 5. TEAM-054 月份按 UTC 切

平台内部全部是 UTC（V83 定的），也刻意不存用户时区（TZ-065）。
所以「本月」= UTC 自然月。

代价说清楚：东八区的团队，月度额度在每月 1 日 **08:00**（当地时间）重置，
不是 00:00。这个偏差对额度的意义不大（它不是一个需要卡零点的东西），
但**必须写出来**，而不是让人自己发现。

## 6. 验收点

| 编号 | 验收点 |
|---|---|
| TEAM-050 | 拆成多笔仍然受月度累计约束；超出部分转审批而不是自动执行 |
| TEAM-050 | 单笔超过月度额度直接转审批（不需要单独的单笔限额） |
| TEAM-051 | admin 同样受月度额度约束；owner 豁免 |
| TEAM-052 | 团队预算池对**已批准**的支出同样生效 |
| TEAM-052 | 预算池 0 表示不设池（既有团队行为不变） |
| TEAM-053 | 批准 N 笔后逐个执行，超池的那几笔在执行时被拒 |
| TEAM-054 | 上个月的支出不计入本月累计 |
| — | 额度用尽时的提示要说**还剩多少**，不是只说「超额」 |

## 7. 这一批没做的

- **TEAM-055**：没有「预算池快用完了」的预警通知。
- **TEAM-056**：池子按自然月重置，不支持自定义账期（很多公司的预算周期
  是财年季度）。加自定义账期要先有账期模型，不是改一个字段。
- **AGT-070/071**（原计划同批）：agent 代交付的定制通知、审核 `review`
  结论自动下核验单。它们与这条额度缺陷没有共同主题，单独成批更清楚。
