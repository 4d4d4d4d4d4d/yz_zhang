# 430 第七十轮场景发掘：淋浴房安装、智能马桶安装

> 状态：本批实现（V457）。编号 SCN-320（淋浴房安装）、SCN-321（智能马桶安装）。
> 来源：按 skill `scenario-discovery` 的方法，每轮补一批场景；上一轮是 V456（429 号）。BACKLOG V457。
> 只增不减：只新增两个种子文件和两个新类目。已有的包（包括水电小修、管道疏通、漏水维修、电视投影挂装）、类目、资质规则和发单拦截都不变。

## 0. 找信号

卫生间里两个装错了就出事的安装活，已有的包都没管：水电小修包明说「马桶以外的水路小修」，管道疏通只管堵。

- **淋浴房安装**，常见问题：
  - 玻璃半夜自爆碎一地；
  - 打孔打穿防水层，楼下渗水；
  - 洗完水流到外面；
  - 密封胶没干就用，发黑漏水；
  - 合页松了门往下掉。
- **智能马桶安装**，常见问题：
  - 坑距差十厘米装不上；
  - 用插排从客厅拖线，洗澡时跳闸；
  - 底下渗水，楼下天花板黄了；
  - 接口滋水；
  - 拆旧扔楼道还多收钱。

  有现成接地带漏保插座的不用证；要新拉插座的要电工证，用上 407 号的「发单人加选资质」。

## 1. 场景卡

### SCN-320 淋浴房安装

| 项 | 内容 |
|---|---|
| 人群 | 淋浴房安装师傅；发单的是装修、翻新卫生间的住户 |
| 要办的事 | 只装 3C 钢化玻璃并贴防爆膜；不打穿防水层；挡水坡向地漏；密封胶固化前不用水；五金拧紧装限位 |
| 现在怎么办 | 建材店派人、网店配送安装 |
| 痛点 | 频率 2；严重度 5：玻璃自爆伤人、渗水到楼下 |
| AI 能做几成 | 0.4：上门清单、报价、自检单的草稿；安装由人 |
| 商业价值 | 3 |
| 交付成本 | 1 |
| 风险关口 | 钱、发布、分享个人信息是人工关口；建筑安全玻璃强制认证（《强制性产品认证管理规定》）；不得破坏厕浴间防水层（《住宅室内装饰装修管理办法》第五条） |
| 证据 | 法规条文；本轮没有引用外部报道链接 |

分数 = 3 × 2 × 5 × 0.4 × 3 ÷ 1 = **36**。

### SCN-321 智能马桶安装

| 项 | 内容 |
|---|---|
| 人群 | 安装师傅；发单的是换智能马桶的住户 |
| 要办的事 | 先量坑距；插座接地带漏保、不拖插排；不伤防水层、换新密封圈；角阀过滤器、试水试电；拆旧写进报价 |
| 现在怎么办 | 卖家派的安装工、小区水电工 |
| 痛点 | 频率 2；严重度 4：卫生间触电、渗水 |
| AI 能做几成 | 0.4：上门要量的清单、报价、试验单的草稿；安装由人 |
| 商业价值 | 3 |
| 交付成本 | 1：写数据、加一个带「可加选资质」的类目 |
| 风险关口 | 钱、发布、分享个人信息是人工关口；新拉插座持电工证（《安全生产法》第三十条），由发单人加选；不破坏防水层 |
| 证据 | 法规条文；本轮没有引用外部报道链接 |

分数 = 3 × 2 × 4 × 0.4 × 3 ÷ 1 = **28.8**。

## 2. 做了什么

- `server/app/modules/packs/seeds/shower-enclosure.json`：「淋浴房安装接单顾问」。五条知识：
  - 3C 钢化玻璃与防爆膜；
  - 保护防水层；
  - 坡向地漏；
  - 密封胶固化；
  - 五金与交付。
- `server/app/modules/packs/seeds/smart-toilet-install.json`：「智能马桶安装接单顾问」。五条知识：
  - 量坑距；
  - 接地带漏保的插座；
  - 保护防水层、换密封圈；
  - 角阀过滤器与试验；
  - 拆旧写进报价。
- 新类目：
  - 「淋浴房安装」，不要资质；
  - 「智能马桶安装」，可加选电工证。

- 两个助手都只出草稿；报价、收款、发布都由人确认。
