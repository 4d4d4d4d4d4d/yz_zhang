
# 302 第十二轮场景发掘：数码维修与旧机回收、陪驾

> 状态：本批实现（V329）。编号 SCN-175（数码维修与旧机回收）、SCN-176（陪驾）。
> 来源：skill `scenario-discovery` 按方法每轮补充；上一轮是 V325（298 号）。BACKLOG V329。
> 只增不减：两个种子文件、两个新类目，「陪驾」沿用持证类目准入（要审核通过的驾驶证）；已有包、类目、资质规则都不变。

## 0. 找信号

- 手机电脑上门维修与旧机回收需求稳定，最大的顾虑不是价格而是数据：修的时候被翻相册、卖掉后数据被恢复。
- 拿到驾照的新手想有人陪着练胆、上高速，而「实习期上高速要三年以上驾龄的人陪同」是法规硬要求；同时有人想找「私下陪练学车」，那是无证驾驶。

## 1. 场景卡

### SCN-175 数码维修与旧机回收

| 项 | 内容 |
|---|---|
| 人群 | 接手机电脑上门维修、旧机回收的师傅；发单的是普通家庭、老人家属 |
| 要办的事 | 不看客户数据、换件透明旧件还人、回收前当面清数据、检测后报价 |
| 现在怎么办 | 街边店、私下回收，数据清没清全凭对方 |
| 痛点 | 频率 2；严重度 4（数据泄露后被诈骗） |
| AI 能做几成 | 0.5：问清单、数据清除步骤、报价写法；维修本身在人 |
| 商业价值 | 3：抽佣，维修与回收互相转化 |
| 交付成本 | 1：只写数据 + 一个类目 |
| 风险关口 | 个人信息保护法；消费者知情权与选择权（原装 / 第三方 / 翻新）；加价走变更单 |
| 证据 | 担心个人信息泄露，不少人宁肯闲置也不卖旧手机；仅删除或恢复出厂设置不足以彻底清除数据（[人民日报海外版 2022-08-29](https://paper.people.com.cn/hwbwap/html/2022-08/29/content_25936627.htm)） |

分数 = 4 × 2 × 4 × 0.5 × 3 ÷ 1 = **48**。

### SCN-176 陪驾

| 项 | 内容 |
|---|---|
| 人群 | 接陪驾单的老司机；发单的是刚拿驾照、实习期想上高速的新手 |
| 要办的事 | 确认对方有驾照与保险、由易到难练、上高速满足陪同条件、自己清醒 |
| 现在怎么办 | 找亲友，或社交平台私下约，条件全凭自觉 |
| 痛点 | 频率 2；严重度 4（交通安全） |
| AI 能做几成 | 0.4：问清单、路线安排、条件提醒；驾驶在人 |
| 商业价值 | 3：按次抽佣 |
| 交付成本 | 1：数据 + 一个持证类目 |
| 风险关口 | 实习期上高速须持相应驾驶证三年以上的驾驶人陪同（《机动车驾驶证申领和使用规定》）；无证学车只能在驾校教练车上（道路交通安全法）；饮酒、疲劳不得驾驶 |
| 证据 | 法规原文（同上）；平台已有持证类目准入可以直接接住 |

分数 = 3 × 2 × 4 × 0.4 × 3 ÷ 1 = **28.8**。

## 2. 做了什么

- `server/app/modules/packs/seeds/device-repair-recycle.json`：「数码维修回收顾问」，两个方法、五条知识（不看相册聊天、回收前清数据、换件说清旧件还人、检测后报价、旧机旧电池去向）、两个模板（上门维修、旧机回收——回收清单里逐项勾「已退出账号、已关闭查找、已恢复出厂」）。新类目「数码维修与回收」。
- `server/app/modules/packs/seeds/driving-companion.json`：「陪驾接单顾问」，两个方法、五条知识（实习期上高速陪同条件、没驾照不接、先确认保险、不酒驾不疲劳、由易到难）、一个模板。新类目「陪驾」，要审核通过的「驾驶证（三年以上驾龄）」（沿用持证类目准入：没有证报不了名）。

## 5. 隐私、授权与边界

两个助手都只出草稿；钱、发布、分享个人信息都是人工关口；不建议看客户数据、不清数据就转卖、给没驾照的人陪练、酒后或疲劳陪驾。
