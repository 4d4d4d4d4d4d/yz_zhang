# 15 · 阶段规划（MVP → V1 → V2）

## 北极星指标

**任务闭环率**（发布 → 完成并结算的比例）与 **闭环任务数/周**。
辅助：发布→匹配转化率、匹配时长、纠纷率、执行者 7 日留存。

## MVP（目标：跑通单城市核心闭环，约 3~4 个月）

范围原则：一个城市、少量类目（保洁/跑腿/二手交易担保/简单设计开发）、App + 简化 Web。

**包含（全部 P0）**
- 账户：注册登录、实名认证、基础资料与技能标签、双角色切换（02）
- 任务：结构化发布、状态机、广场+搜索+LBS 地图、报名+AI 推荐 Top-N（简化版规则+特征打分）、执行留痕、验收放款、双向评价（03/07）
- 合约：合约生成与签署、资金托管、放款/退款规则引擎、平台抽佣（05，链下实现）
- AI：对话式需求澄清 + 简单任务直通 + 基础分解（模板驱动，用户可编辑后分发）（04 最小集）
- IM：单聊 + 任务会话 + 推送（09 最小集）
- 纠纷：发起→冻结→证据链→人工仲裁→自动执行（11 最小集）
- 基础：支付通道、通知、机审+人审、举报、管理后台（用户/任务/审核/财务）（12）
- 客服：FAQ 型 AI 客服 + 转人工工单（10 最小集，可后置 2~4 周）

**明确不做**：视频、博客/朋友圈、圈层、群聊、知识库自动入库（用人工模板替代）、链上存证、周期任务、企业认证。

**MVP 退出标准**：周闭环任务 ≥ 500，闭环率 ≥ 60%，纠纷率 ≤ 3%，资金零事故。

## V1（MVP 后 3~6 个月：信任与增长层)

- 内容：朋友圈动态、博客、任务案例卡、关注流/推荐流（08）
- 社交：群聊、好友、圈层（兴趣圈/能力圈/地域圈）+ 圈层任务板（09）
- AI 升级：知识库自动入库与 RAG（06）、分解模板/估价参考、母任务驾驶舱完整版、风险预警（04）
- 匹配升级：个性化任务流、定向邀约、竞价、策略后台调参
- 客服升级：账户上下文感知、主动提醒
- 法律：法律知识 AI、证据导出（11）
- 信用：等级权益、信用展示页
- 多城市开站与地域运营（07）

## V2（规模化与深水区）

- 短视频完整体验与创作者生态（08）
- 智能合约存证上链（SC-011）、电子签章深化
- 企业侧：企业认证、发票、批量发单、API 开放
- 律师入驻与法律服务市场（LAW-003）
- 音视频通话、语义搜索、知识图谱、AI 客服 Action 化
- 保证金体系、周期任务、跨城/跨境探索

## 里程碑依赖关系（关键路径）

```
支付托管通道签约 ──► 合约引擎 ──► 任务闭环 ──► 知识库有数据 ──► AI 分解/估价变准
                                   │
实名认证服务 ──► 接单准入            └──► 信用体系有效 ──► 匹配质量提升
```
