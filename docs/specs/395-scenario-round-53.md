
# 395 第五十三轮场景发掘：宠物家庭寄养、汽车搭电换胎

> 状态：本批实现（V422）。编号 SCN-286（宠物寄养）、SCN-287（搭电换胎）。
> 来源：按 skill `scenario-discovery` 的方法，每轮补一批场景；上一轮是 V420（393 号）。BACKLOG V422。
> 只增不减：新增两个种子文件和两个新类目，都不要资质。已有的包（包括宠物上门照看、宠物接送、上门汽车保养、代驾）、类目、资质规则、发单拦截都不变。

## 0. 找信号

- **宠物家庭寄养**：宠物上门照看（V200）是去主人家喂，宠物接送（V407）管路上；把猫狗接到自己家住几天的家庭寄养没有包。常见纠纷：
  - 和寄养家庭的狗打架；
  - 猫从纱窗跑丢；
  - 几天没有一张照片；
  - 自己喂了人吃的药；
  - 换粮吃坏肚子。
- **汽车搭电换胎**：上门汽车保养（V400）是约好时间上门，代驾管开车；车趴窝时的搭电、换备胎没有包。常见纠纷：
  - 在快速路边作业险些被撞；
  - 搭电线接反烧了电脑板；
  - 换完小备胎没说限速；
  - 半夜到场加价；
  - 顺手卖来路不明的电瓶。

  这一类有明确的安全红线：高速公路上的故障由《道路交通安全法》第六十八条规定怎么办，平台的接单者不该在高速上作业。
