# 07 · 地域能力（LBS 与本地小任务）

模块前缀：`GEO`

## 目标

支撑"附近的小任务"高频场景：一笔线下交易、一次打扫卫生、跑腿代办等，
让任务供需在地理维度高效撮合，并保障线下履约安全。

## A. 基础定位能力

| 编号 | 功能点 | 优先级 | 说明 / AC |
|---|---|---|---|
| GEO-001 | 定位授权与当前城市识别 | P0 | 拒绝授权时降级为手选城市 |
| GEO-002 | 地址簿（常用地址管理） | P0 | 家/公司/常用地点；发布任务快速选址 |
| GEO-003 | 地图选点与 POI 搜索 | P0 | 接入地图服务商（高德/腾讯/Google 按地区）；逆地理编码 |
| GEO-004 | 位置脱敏展示 | P0 | 任务公开页只显示商圈/小区级；精确地址在成交后向执行者披露 |

## B. 地域化任务撮合

| 编号 | 功能点 | 优先级 | 说明 / AC |
|---|---|---|---|
| GEO-010 | 附近任务地图视图 | P0 | 地图撒点 + 聚合气泡；点击进任务卡 |
| GEO-011 | 距离筛选与排序 | P0 | 1/3/5/10km 档位；列表显示直线距离 |
| GEO-012 | 地理围栏推送 | P1 | 执行者设置接单范围，范围内新任务推送（频控） |
| GEO-013 | 同城任务频道 | P1 | 按城市运营的任务广场（含城市热门类目） |
| GEO-014 | 跨城任务标记 | P2 | 线上可远程完成的任务不受地域限制，明确标注 |
| GEO-015 | 距离参与匹配打分 | P0 | 服务型/事件型任务中距离为 MATCH-002 高权重特征 |

## C. 线下履约支撑

| 编号 | 功能点 | 优先级 | 说明 / AC |
|---|---|---|---|
| GEO-020 | 到场打卡 | P0 | 执行者到达任务点 → 定位打卡（误差阈值可配），记入履约留痕 |
| GEO-021 | 行程共享（可选） | P1 | 上门类任务执行者位置临时共享给发布者，任务结束即停止 |
| GEO-022 | 会面码/核销码 | P0 | 线下交易型任务双方扫码确认见面与交付，作为放款依据之一 |
| GEO-023 | 紧急求助 | P1 | 上门/夜间任务一键报警与紧急联系人通知（安全合规重点） |
| GEO-024 | 位置数据保留策略 | P0 | 行程位置数据任务结束后 N 天自动删除（合规） |

## D. 地域运营能力

| 编号 | 功能点 | 优先级 | 说明 / AC |
|---|---|---|---|
| GEO-030 | 城市开通管理 | P1 | 分城市开站/费率/类目配置（管理后台） |
| GEO-031 | 地域参考价 | P1 | 知识库估价按城市维度区分（KB-021） |
| GEO-032 | 本地圈层 | P1 | 基于小区/商圈的邻里圈层（联动 09） |

## 技术要点
- Geo 索引：PostGIS 或 Redis GEO / ES geo_point，支撑"附近 X km"查询 P99 < 200ms。
- 地图服务商抽象层：国内外不同供应商可切换。
- 定位防作弊：Mock 定位识别（打卡场景）。

## 依赖
- 地图/定位服务商、03 匹配、12 推送与风控。
