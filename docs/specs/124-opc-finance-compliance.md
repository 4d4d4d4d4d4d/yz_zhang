
# 124 一人公司服务包：记账底稿、申报日历、合同体检与财税 / 合同 / 政策三位助手专家

> 状态：本批实现（V149）。编号 OPC-100~110。
> 来源：用户 2026-10-13：「对于平台来说需要能够切实服务好每个用户的需求，满足用户的痛点，例如 OPC 用户就需要解决繁琐的财务，
> 政策合规申请，法务等……这些都需要 AI 来帮助实现。」VISION 1.7；BACKLOG V149（打分 覆盖 4 × 频率 4 × 痛感 5 × AI 0.6 × 价值 4 ÷ 成本 3 = 64）。
> 只增不减：场景包引擎（123 号）只**加**三个白名单工具；类目只**加**一个「财税」（已有库启动时补上一次，运营可停用）。
> 这是 123 号引擎的第一个真实场景包：**大部分是数据**（13 条知识、4 份方法、2 个提醒、2 个发单模板、3 位助手），
> 只有引擎缺的三个工具（账本、日历、合同体检）写成代码。

## 0. 要解决的问题

一个人开公司或做个体户：收入散在各处、季度末才对账；不知道这个月要不要申报、截止哪天；
免税标准、减半政策说不清自己适不适用；合同一签几万块，看不出坑又请不起律师逐份审。

## 3. 接口（`/opc/*`，全部只对本人）

| 编号 | 接口 | 说明 |
|---|---|---|
| OPC-101 | `GET/PUT /opc/profile` | 个人不能选纳税人类型（400 `opc_profile_mismatch`） |
| OPC-101 | `GET/POST /opc/entries`、`PATCH/DELETE /opc/entries/{id}` | 税额不能大于金额；平台导入的金额与日期锁定（以流水为准，可补发票号与备注） |
| OPC-102 | `POST /opc/entries/import-platform` | 平台上已到账的报酬（托管放款、纠纷分账、Agent 分成、合作体分配）记进底稿；净额，注明「已扣平台服务费」 |
| OPC-103 | `GET /opc/summary?period=` | 月 / 季 / 年：收支、按类别、平台已代扣个税；小规模纳税人在**对应周期**上给免税标准提示（按含税收入估算，偏保守）；缺票提示；主体适用的减免口径带文号与有效期；免责说明 |
| OPC-103 | `GET /opc/export?period=` | CSV 底稿（交给记账代理或自己报税时对照） |
| OPC-104 | `GET /opc/calendar?days=` | 按主体推算的申报与年报节点；15 日遇周末顺延到周一，法定节假日不猜（写明以电子税务局为准）；两端一键放进工作台（北京时间 18:00 截止、提前 3 天提醒） |
| OPC-105 | `POST /opc/contract-review` | 八类必备条款缺失 + 风险句式（无上限责任、最终解释权、自动续约、限制解除、单方变更、排他）+ 乙方视角的知识产权转移 + 违约金 >30% + 定金 >20%；抽出金额与日期；**原文不落库** |
| OPC-106 | 场景包工具 | `opc.books`、`opc.calendar`、`opc.contract_review` 进白名单：助手专家问到相关的事就用**本人**的数据算一遍，作为「按你的数据推算」的出处 |
| OPC-107 | 场景包 `opc-finance-compliance` | 财税助手、合同审阅助手、政策申报助手（三位都把钱、签署、申报设为人工关口）；月度记账 / 季度申报 / 签约前合同体检 / 政策申报四份清单；每月记账与申报提醒；代理记账、律师审阅两个发单模板 |
| OPC-108 | 上线校验 | 场景包用到的类目（答不了时的去处、发单模板）必须是开着的类目（409 `pack_unknown_category`）；补了「财税」类目 |
| OPC-109 | 注销与导出 | 账本与主体设置随注销删除；数据导出多一节 `opc` |

## 4. 两端

- **Web** `/opc`（入口：服务包详情「打开一人公司工具」、财税助手链接）：账本（期间、导入平台收入、记一笔、缺票标红可补、删手记的、导出 CSV）、
  汇总（免税标准、口径与出处、免责）、申报日历（放进工作台）、合同体检（选甲乙方、分级、请律师）、主体设置。
- **App**「我的 → 一人公司」：导入与记一笔、本季汇总、申报日历放进工作台、合同体检（乙方视角）、主体设置。
- 北京时间的「今天 / 本季度 / 某日 18:00」统一走 `@platform/core` 的 `chinaToday / chinaQuarter / chinaDateAt`（时区闸门不许客户端自己 `new Date(…)`）。

## 5. 边界

- **只出底稿与提醒**：不报税、不开票、不签字、不动钱；每个出口都有免责说明；三位助手的禁止动作写在角色契约里。
- 免税标准按**含税收入**估算（偏保守），明说申报以不含税销售额为准。
- 合同原文、提问原文都不落库。

## 7. 没做的

- **OPC-110 发票识别（OCR）与电子发票导入**：要接供应商与企业授权；现在手记发票号。
- 自动申报、代开发票、对接电子税务局：需要税务机关接口与授权，且属「申报」人工关口，平台不做。
- 地方扶持政策的具体条件与金额：各地每年变，只给「去哪里查、准备什么」；接权威数据源后再做。
- 法定节假日顺延：每年国务院公布，需要日历数据源；现在只顺延周末并写明以电子税务局为准。
