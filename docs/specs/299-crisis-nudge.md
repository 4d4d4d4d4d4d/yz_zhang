
# 299 发单与私聊里出现想伤害自己的说法时也给热线

> 状态：本批实现（V326）。编号 SCN-172。
> 来源：298 号 spec「没做的」——「发单与私聊里出现想伤害自己的说法时，也给发出这句话的人看到热线」；BACKLOG V326。
> 只增不减：发单、私聊、提工单的校验与结果都不变（**不拦**）；私聊响应只在这时多一个 `support` 字段；多一种站内信。

## 0. 要解决的问题

V325 只在助手与法律问答里认这句话。可人最常写下「不想活了」的地方是私聊、发单（「想找人陪我走走」）和客服工单——这些地方平台什么也没说。

## 1. 业界怎么做

社交与内容平台在用户发布或搜索含自伤意图的内容时，向本人展示心理援助资源，而不是拦截或公开；国内统一的热线是 12356。（本批没有另找外部来源，依据同 298 号。）

## 2. 规则

- 共用 298 号的识别规则（`app/core/crisis.py`）。命中时：
  - **私聊**：消息照常发出、对方照常看到；发送的人的响应多 `support`（热线那句话），两端显示在输入框上方；
  - **发单**：单照常走后面的校验与发布；
  - **客服工单**：工单照常建、照常分派；
  - 三处都给写这句话的人发一条站内信「需要的话，有人可以陪你聊聊」（正文是热线），**按人每 24 小时最多一条**。
- 不拦、不告诉对方、不上报、不额外存这句话。
- 发单的站内信放在机审之后写：机审要调外部供应商，之前写库会把事务挂过外部调用（CONC-067，本批首轮就被这道闸门拦下）。

## 3. 数据 / 接口

不新增表与接口。私聊发送响应多可选 `support`；共享 SDK `sendMessage` 的返回类型加上它。

## 4. 两端

- **Web 私聊页**、**App 私聊页**：发送后服务端给了 `support` 就显示在输入框上方（App 的标签是「心理援助热线」）；普通消息不显示。

## 5. 隐私、授权与边界

只给写的人自己看；对方、客服、管理员都看不到这次提示；站内信是写给本人的。
