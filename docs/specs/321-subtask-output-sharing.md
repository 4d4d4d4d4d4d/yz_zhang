
# 321 跨子任务产出共享

> 状态：本批实现（V348）。编号 AI-DEC-024（交付人授权的那一半；原图与发单人决定的共享记为 AI-DEC-024b）。
> 来源：现状台账 AI-DEC-024「跨子任务产出物共享（向后继执行者开放前置产出）」，台账原话：「前一个人的交付物给不给后一个人看，是他的权利，不是流程的便利」；BACKLOG V348（第三十一轮排期，分数 18）。
> 只增不减：任务详情、交付、交付文件、验收与放款都不变。只多一张开放记录表、四个接口、两端各两块。

## 0. 要解决的问题

一个项目拆成几步以后，后一步常常要用前一步的成果：设计稿给开发，测量数据给施工，需求文档给写代码的人。以前平台上没有路，只能私下传，平台既不知道传了什么，也留不下记录。反过来，直接让后一步的人默认看到前一步的交付也不对：交付说明里可能有接单人自己的方法和联系方式，给不给是他的权利。

## 1. 业界怎么做

项目协作工具里，任务之间的「依赖」普遍只表达先后顺序；成果要给下一棒，一般靠手动分享链接或附件，权限由文件的所有者控制。本批没有另找外部来源。

## 2. 规则

- **谁能开**：只有前一步的执行者，也就是交付人。发单人和后一步的人都不能替他开。
- **开给谁**：只能开给依赖这一步的那几步（同一个项目下、`depends_on` 里写了要等这一步的）。别的步骤、这一步自己都不行（400 `share_not_next_step`）。
- **什么时候能开**：交付之后（409 `not_delivered`）。后一步可以还没人接；开放的是「后一步执行者」这个位置，换了人，新的执行者也看得到。交付人在列表里能看到现在是谁在做。
- **开放什么**：
  - 包括：这一步的交付说明，以及交付文件里的预览图。
  - 不包括：原图（放款后按知识产权约定归发单人，交付人开不了）和平时的进度备注。
- **收回**：交付人随时可以收回，收回后立刻看不到，并通知后一步的执行者。收回过的不能再收（404）。再点一次「开放」不会重复开。
- **通知**：开放时通知后一步的执行者（还没人接就不通知，接了以后在任务页能直接看到）。
- **谁看得到**：
  - 开放列表：给这一步的执行者和发单人。
  - 前一步的成果：给后一步的执行者和发单人。
  - 旁人一律 403。

## 3. 数据 / 接口

- 新表 `subtask_shares`：`from_task_id`、`to_task_id`、`granted_by`、`created_at`、`revoked_at`。迁移 c1d220260082，SQLite 与 Postgres 都验过。
- 接口（都登记进对象级授权表）：
  - `GET /tasks/{id}/shares`：返回 `{task_id, delivered, next_steps:[{task_id, title, status, executor_nickname, shared, share_id?}]}`
  - `POST /tasks/{id}/shares`：请求体 `{to_task_id}`，返回同上
  - `DELETE /tasks/{id}/shares/{share_id}`：返回同上
  - `GET /tasks/{id}/inputs`：返回 `[{from_task_id, title, shared_at, deliveries:[{content, images, created_at}], previews:[{id, url}]}]`
- 共享 SDK：
  - 类型：`SubtaskShareView`、`SubtaskNextStep`、`SubtaskInput`
  - 方法：`subtaskShares` / `shareToNextStep` / `revokeSubtaskShare` / `subtaskInputs`
  - 两个新错误码已进 i18n。

## 4. 两端

- **Web 任务详情**（项目里的一步）：
  - 这一步的执行者在交付后看到「把成果开放给下一步」：列出要等这一步的那几步（状态、谁在做、开没开），每一步都有「开放给这一步」或「收回」。还没交付时只说明交了之后能开。
  - 后一步的执行者看到「前一步的成果」：交付说明与预览图，并提醒对方可以收回，需要留底的请和发单人确认。没人开放就没有这一块。
- **App 任务详情**：同样的两块（`app/subtaskShares.tsx`），文案与 Web 相同。

## 5. 隐私、授权与边界

- 默认谁也看不到，只有交付人能开。
- 开放范围只到交付说明与预览图，不含原图和进度备注。
- 随时收回，收回立刻生效。
- 不碰钱、不改任务状态。
