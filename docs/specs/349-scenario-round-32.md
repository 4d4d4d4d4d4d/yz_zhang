
# 349 第三十二轮场景发掘：开荒保洁、二手车陪验

> 状态：本批实现（V376）。编号 SCN-241（开荒保洁）、SCN-242（二手车陪验）。
> 来源：skill `scenario-discovery` 按方法每轮补充；上一轮是 V374（347 号）。BACKLOG V376。
> 只增不减：新增两个种子文件、两个新类目（都不要资质）。已有包、类目、资质规则、发单拦截都不变。

## 0. 找信号

- **开荒保洁**：新房交付、装修完一次性的大活，单价高。风险与纠纷集中在：
  - 为擦高层外窗探身出窗；
  - 强酸洗坏大理石；
  - 地板划痕说不清；
  - 被要求顺带清装修垃圾；
  - 按套报价到了加钱。
  家务包（V167）管的是日常保洁，不管开荒。
- **二手车陪验**：买二手车的人怕被坑，找懂车的朋友或师傅陪看。最大的问题是利益冲突：陪看的人收车商回扣。其他坑：
  - 泡水、火烧、事故车；
  - 调表；
  - 车架号对不上；
  - 报告打包票。
  与代驾（V364）、代办年检（V369）、汽车贴膜（V372）连成车主一条线。

## 1. 场景卡

### SCN-241 开荒保洁

| 项 | 内容 |
|---|---|
| 人群 | 开荒保洁班组；发单的是新房业主 |
| 要办的事 | 外窗只擦室内够得到的，外侧另发高处作业单；清洁剂先试；开工前拍照；装修垃圾另算；按面积分项报价 |
| 现在怎么办 | 家政公司、装修公司介绍 |
| 痛点 | 频率 1；严重度 3（坠落、损坏、加价） |
| AI 能做几成 | 0.4：问清单、报价写法、验收清单 |
| 商业价值 | 2 |
| 交付成本 | 1：只写数据加一个类目 |
| 风险关口 | 高处作业（GB/T 3608；特种作业规定）；建筑垃圾按规定清运 |
| 证据 | 标准与规定；本轮没有引用外部报道链接 |

分数 = 3 × 1 × 3 × 0.4 × 2 ÷ 1 = **7.2**。

### SCN-242 二手车陪验

| 项 | 内容 |
|---|---|
| 人群 | 懂车的师傅、二手车评估从业者；发单的是买二手车的人 |
| 要办的事 | 只替买家看不收回扣；查记录核车架号；看泡水火烧事故与调表；报告只写看到的；买不买买家决定 |
| 现在怎么办 | 找朋友、车商的「免费检测」 |
| 痛点 | 频率 1；严重度 4（买到问题车，损失大） |
| AI 能做几成 | 0.4：查车清单、报告写法 |
| 商业价值 | 3 |
| 交付成本 | 1：只写数据加一个类目 |
| 风险关口 | 卖方如实告知（《二手车流通管理办法》第十四条）；欺诈三倍赔偿（《消费者权益保护法》第五十五条）；钱与签署是人工关口 |
| 证据 | 法规条文；本轮没有引用外部报道链接 |

分数 = 3 × 1 × 4 × 0.4 × 3 ÷ 1 = **14.4**。
