
# 322 第十八轮场景发掘：陪诊、家具安装

## 0. 找信号

- **陪诊**：子女在外地、老人独自就医，是「替爸妈办事」（V200）里最常见、也最难自己办的一件。它的风险不在价格，而在边界：
  - 有号贩子冒充陪诊师倒卖号源；
  - 有人替医生拿主意、替家属做决定。
  平台已经有的几样东西正好接得住：替别人发单（服务对象与现场联系人）、上门回报与发单人确认、发单时拦下「加价倒卖号源」。
- **家具安装**：网购家具上门拼装，是业界零工平台的头号品类。最大的风险是高柜不固定上墙、倾倒伤到孩子，其次是打孔打到管线、配件缺了拿别的凑合。
- 本来想做的「空调安装移机」，第九轮（V313，286 号）已经放进「空调外机拆装（高处作业）」类目（要高处作业证）和家电清洗包，这一轮不重复。

## 1. 场景卡

### SCN-196 陪诊

| 项 | 内容 |
|---|---|
| 人群 | 陪诊师、做陪诊的自由职业者；发单的是在外地的子女、独自就医的人 |
| 要办的事 | 陪着取号、候诊、检查、缴费、取药；原话记下医嘱并回报家属；挂号只走官方渠道；医生要签字、要做决定时打给家属 |
| 现在怎么办 | 熟人介绍、社交平台上找，号贩子混在里面 |
| 痛点 | 频率 2；严重度 4（耽误就医、被倒卖号源、替医生拿主意） |
| AI 能做几成 | 0.4：问清单、当天流程、医嘱回报的写法；陪诊在人 |
| 商业价值 | 3：按半天或全天计，复购高 |
| 交付成本 | 1：只写数据加一个类目 |
| 风险关口 | 不给医疗建议；签字与治疗决定是病人和家属的事（民法典第一千二百一十九条）；挂号只走官方渠道，加价倒卖号源发单即拦；回报里遮住身份证号 |
| 证据 | 近年陪诊机构和从业人员持续增加，纠纷也不时出现；医院提醒分清「陪伴」与「包办」；有号贩子冒充陪诊师倒卖号源；一线城市时薪通常 50~100 元（[新华网 2026-07-06「新华视点｜陪诊师『走红』 如何规范发展」](https://www.news.cn/legal/20260706/792820a2dc284de5b908fa4b838f7592/c.html)） |

分数 = 4 × 2 × 4 × 0.4 × 3 ÷ 1 = **38.4**。

### SCN-197 家具安装

| 项 | 内容 |
|---|---|
| 人群 | 做家具安装的师傅；发单的是网购家具的住户 |
| 要办的事 | 按件报价；对着说明书装；高柜、抽屉柜用防倾倒配件固定上墙；打孔前查暗管暗线；配件缺了拍照告诉客户、不凑合；装完试开合 |
| 现在怎么办 | 商家的安装服务、附近的师傅，现场加价、不上墙常见 |
| 痛点 | 频率 2；严重度 3（倾倒伤人、打穿管线、装完就晃） |
| AI 能做几成 | 0.4：问清单、报价写法、回报写法；装在人 |
| 商业价值 | 2：单价低、频次中 |
| 交付成本 | 1：只写数据加一个类目 |
| 风险关口 | 高柜固定上墙（回报附固定点照片）；钱先托管、加价走变更单 |
| 证据 | 2016 年宜家在中国召回约 166 万件抽屉柜，因为未固定在墙上的抽屉柜可能倒下、造成儿童伤亡，宜家免费提供上墙连接件（[澎湃新闻](https://www.thepaper.cn/newsDetail_forward_1497177)） |

分数 = 4 × 2 × 3 × 0.4 × 2 ÷ 1 = **19.2**。

## 2. 做了什么

- `server/app/modules/packs/seeds/hospital-escort.json`：「陪诊接单顾问」。
  - 两个方法：接单前问清四件事、陪诊当天。
  - 五条知识：挂号只走官方渠道、只陪不替、签字是病人和家属的事、医嘱原话回报、按小时还是按次写清。
  - 一个模板：回报要记医嘱、拍票据。
  - 人工关口多一个「签署」。新类目「陪诊」。
- `server/app/modules/packs/seeds/furniture-assembly.json`：「家具安装接单顾问」。
  - 两个方法：上门前问清三件事、到了现场。
  - 五条知识：高柜固定上墙、打孔前查管线、缺配件不凑合、按件报价、装完试一遍。
  - 一个模板：回报要拍上墙固定点。
  - 新类目「家具安装」。

## 5. 隐私、授权与边界

- 两个助手都只出草稿；钱、发布、分享个人信息都是人工关口，陪诊另加签署。
- 不建议：倒卖号源、走「特殊渠道」加号、给医疗建议、替病人签字或做决定、收医院回扣；高柜不上墙、不查管线就打孔、缺配件凑合、现场以「难装」加价。
- 回报里的处方和票据照片要遮住身份证号。
