# 212 家教、陪练类场景的关口设计

> 状态：本批实现（V240，设计批：只出关口与规则，代码拆进 V241、V242）。编号 SCN-132。
> 来源：191 号 spec 第 1 节「家教陪练涉及未成年人，要先有资质与监护人确认的关口」；209 号第 3 节排序（分数 18）；BACKLOG V240。
> 只增不减：现有规则不变——未满 18 周岁不能实名与接单（LAW-005）、任务画像对「孩子 / 儿童」给出风险提示、上门打卡与回报（GEO / V203）。

## 0. 要解决的问题

家长找人辅导功课、陪练钢琴、接送孩子、周末看护，是高频需求；平台的任务、托管、打卡、回报都能接住「找人」这一半。但它碰的是**未成年人**和**国家明确管住的学科类校外培训**，不先把关口定清楚就上包或开类目，平台自己就在违规、在冒险：

- **学科类有偿家教**：义务教育阶段学科类校外培训受严格管控，以「家政服务」「住家教师」「众筹私教」等名义变相开展的，教育部要求依法查处；不具备教师资格的人员授课也在查处之列。一个众包平台上「发单找人补数学」，正好落在这里。
- **人身安全**：陌生成年人单独接触孩子。法律对「密切接触未成年人」的单位有入职查询性侵害等违法犯罪记录的要求；平台不是用人单位，但不能比这个标准更松。

## 1. 依据（已检索核对）

- 教育部办公厅《关于坚决查处变相违规开展学科类校外培训问题的通知》（教监管厅函〔2021〕8号）：点名借「家政服务」「住家教师」「众筹私教」等名义违规开展学科类培训的，应依法依规查处；包括证照不全的机构或个人开展培训、不具备教师资格的人员违规授课（[中英对照](https://www.chinalawtranslate.com/17154-2/)；[媒体报道](https://www.nbd.com.cn/articles/2021-09-08/1907061.html)）。
- 《未成年人保护法》（2020 年修订）第六十二条：密切接触未成年人的单位招聘工作人员时，应当向有关机关查询应聘者是否有性侵害、虐待、拐卖、暴力伤害等违法犯罪记录，有的不得录用（[高校法学解读](https://fxy.whxy.edu.cn/info/1036/6089.htm)）；最高检、教育部、公安部 2020 年另有教职员工准入查询性侵违法犯罪信息的制度（[中英对照](https://www.chinalawtranslate.com/?p=15513)）。查询渠道在公检机关，平台接不进去（「外」）。

## 2. 关口（规则）

| 编号 | 规则 | 怎么落地 | 批次 |
|---|---|---|---|
| G1 | **不承接义务教育阶段学科类有偿家教**：发单内容像「给孩子补数学 / 英语 / 物理……」「小学 / 初中 家教 / 补课」的，发布时拒绝，写明为什么（国家对学科类校外培训的管控）与能做什么（找有资质的机构；非学科类的陪练、看护可以按 G2 发） | 机器审核规则 + 新错误码；两端发布页原样显示错误；运营在后台可看拦截数（不看内容） | V241（SCN-143） |
| G2 | **服务对象是未成年人的单（陪练、看护、接送），发单人必须声明是监护人本人或经监护人同意，并选「监护人在场」或「公开场所」**；不允许单独相处的安排 | 任务字段 `minor_involved`、`guardian_present` / `public_place`；发布时校验；接单前任务详情写明；上门回报必选（V203） | V242（SCN-144） |
| G3 | **接这类单的人要先交「无犯罪记录证明」，由平台人工审核**（平台查不了公检系统，只审本人交来的证明；有效期一年，过期要重交） | 新类目「陪练看护」带 `required_cert`（沿用律师、电工类目的资质机制，ACC-022），接单时校验 | V242（SCN-144） |
| G4 | 资金、签署照旧：钱托管、验收放款；纠纷时上门回报与打卡是证据 | 不改 | — |

不做：直接查询犯罪记录（要公检渠道，「外」）；未成年人本人注册或接单（已禁止）；面向学生的学科辅导内容（G1 拒绝）。

## 3. 接口（预定，按批次实现时以对应 spec 为准）

- V241：发布 / 编辑任务时新错误码 `k12_subject_tutoring`（中文说明写清原因与可走的路）。
- V242：`TaskIn.minor_involved`、`guardian_mode`（`guardian_present` / `public_place`）、`guardian_consented`；新类目「陪练看护」`required_cert = 无犯罪记录证明`；新错误码 `guardian_required`、`minor_needs_guardian_mode`。

## 4. 两端

本批不改界面（设计批）。V241 两端只是显示服务端的拒绝说明；V242 两端发布页加「服务对象是未成年人」一组选项。

## 5. 隐私与边界

- 不收集孩子的姓名、学校、照片；任务里只写「服务对象是未成年人」与安排方式。
- 无犯罪记录证明只给审核的管理员看，审核后按资质材料的原规则留存与注销处置。
- 平台不判断某个家长、某个接单人「可靠不可靠」，只执行规则；拿不准的单子转人工审核。
