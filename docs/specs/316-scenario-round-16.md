
# 316 第十六轮场景发掘：上门回收废品、电动车上门维修

> 状态：本批实现（V343）。编号 SCN-190（上门回收废品）、SCN-191（电动车上门维修）。
> 来源：skill `scenario-discovery` 按方法每轮补充；上一轮是 V340（313 号）。BACKLOG V343。
> 只增不减：两个种子文件、两个新类目（都不要资质）；已有包、类目、资质规则都不变。

## 0. 找信号

- 上门收废品是居民最常用的上门服务之一，最大的信任问题是秤：遥控能改数的「违规秤」被媒体曝光后，很多人不敢叫人上门。平台能做的是把价格写进单子、当面称、回报写清重量与金额。
- 电动自行车维修上门需求大，而违规改装电池是电动车火灾的主要诱因之一；新国标 2025 年 9 月起实施、对防篡改有要求。一个说清「什么不能改」的维修包，既帮修车的人守住底线，也帮发单的人识别风险。

## 1. 场景卡

### SCN-190 上门回收废品

| 项 | 内容 |
|---|---|
| 人群 | 在小区收废品的师傅；发单的是搬家、换家电、清理杂物的住户 |
| 要办的事 | 单价写进单子；当面称、客户看秤、秤要检定合格；分类称；大件按件报价；来路不明的电缆井盖不收 |
| 现在怎么办 | 楼下喊、电话叫，价格与重量都凭对方说 |
| 痛点 | 频率 2；严重度 3（缺斤短两、上门压价） |
| AI 能做几成 | 0.4：问清单、报价写法、称重回报写法 |
| 商业价值 | 2：单价低、频次中 |
| 交付成本 | 1：只写数据 + 一个类目 |
| 风险关口 | 计量法（以欺骗为目的的计量器具）；收购赃物（刑法第三百一十二条）；钱当场结或走平台 |
| 证据 | 央视财经《财经调查》曝光废品回收、黄金回收领域的「违规秤」：遥控器按键即可让显示重量加减或清零（[澎湃新闻转载](https://m.thepaper.cn/newsDetail_forward_33522796)） |

分数 = 4 × 2 × 3 × 0.4 × 2 ÷ 1 = **19.2**。

### SCN-191 电动车上门维修

| 项 | 内容 |
|---|---|
| 人群 | 上门修电动自行车的师傅；发单的是通勤族、外卖骑手、老人 |
| 要办的事 | 按项报价；换电池只换匹配、有合格证的；不铅酸改锂电、不加容量、不拆限速、不提电压；鼓包先断电、别进楼充电；修完试车 |
| 现在怎么办 | 街边车行，改装与不合格电池常见 |
| 痛点 | 频率 2；严重度 4（火灾） |
| AI 能做几成 | 0.4：问清单、报价写法、风险提醒；修车在人 |
| 商业价值 | 2：单价低 |
| 交付成本 | 1：只写数据 + 一个类目 |
| 风险关口 | 不改装（GB 17761—2024 防篡改要求，有车行因改装被市场监管罚款）；电池合格；鼓包断电、119 |
| 证据 | 新版《电动自行车安全技术规范》（GB 17761—2024）2025 年 9 月 1 日起实施，完善了电池、控制器、限速器的防篡改要求；电动车火灾中电池故障是主因，多与违规改装有关（标准原文与消防部门公开说法；本轮没有引用未核实的链接） |

分数 = 4 × 2 × 4 × 0.4 × 2 ÷ 1 = **25.6**。

## 2. 做了什么

- `server/app/modules/packs/seeds/scrap-recycling.json`：「废品回收接单顾问」，两个方法、五条知识（当面称不用违规秤、价格先说清不压价、分类再称、大件按件报价、来路不明的不收）、一个模板（单价、分类当面称、上门费）。新类目「废品回收」。
- `server/app/modules/packs/seeds/ebike-repair.json`：「电动车维修接单顾问」，两个方法、五条知识（不改装、换电池只换匹配合格的、鼓包先断电、按项报价、修完试车）、一个模板。新类目「电动车维修」。

## 5. 隐私、授权与边界

两个助手都只出草稿；钱、发布、分享个人信息都是人工关口；不建议违规秤、不让看秤、上门压价、收来路不明的公共设施、改装电池或限速、楼道给鼓包电池充电。
