## 0. 找信号

- **文案代写**：创作者人群最大的一块线上活（公众号、详情页、简历）。随之而来的灰色需求很集中：
  - 代写毕业论文、代考；
  - 刷单、编好评；
  - 广告里写「全网第一」。
  前两种是平台不能接的活，应当在发单时就拦下，和 V321 拦代开处方药、倒卖号源是同一类。
- **上门装监控**：家用摄像头、可视门铃、智能门锁摄像头装得越来越多。最常见的纠纷是镜头对着邻居门窗：多地法院判过拆除或调转方向。另一个风险是默认密码导致画面被人远程看到。

## 1. 场景卡

### SCN-208 文案代写

| 项 | 内容 |
|---|---|
| 人群 | 自由写手（创作者人群）；发单的是小店、自媒体、求职者 |
| 要办的事 | 问清读者、平台、字数、改稿轮数；按客户给的真实信息写；不用绝对化用语、不编数据；著作权与署名写清 |
| 现在怎么办 | 社交平台、兼职群接单，灰色需求混在里面 |
| 痛点 | 频率 3；严重度 3（被罚、被卷进作假） |
| AI 能做几成 | 0.6：问清单、报价写法、广告用语自查 |
| 商业价值 | 3 |
| 交付成本 | 2：数据加类目，再加两类发单拦截 |
| 风险关口 | 不代写学位论文、不代考（《学位论文作假行为处理办法》、学位法）；不编好评刷单（《反不正当竞争法》第八条、《电子商务法》第十七条）；广告不用绝对化用语（《广告法》第九条） |
| 证据 | 购买、出售、代写学位论文都是作假行为，组织或参与代写的个人与网站由主管机关查处（[教育部《学位论文作假行为处理办法》](https://mt.ucass.edu.cn/xueweilunwenzuojiaxingweichulibanfa-jiaoyubulingdi34hao.pdf)）；学位法 2025 年 1 月 1 日起施行（[中国社会科学网](https://www.sinoss.net/c/2025-01-03/646443.shtml)） |

分数 = 4 × 3 × 3 × 0.6 × 3 ÷ 2 = **32.4**。

| 项 | 内容 |
|---|---|

| 证据 | 北京密云一案，法院要求把对准邻居院门的摄像头调转方向（[中新网 2022-03-22](https://www.chinanews.com.cn/sh/2022/03-22/9708653.shtml)）；多地还有判令拆除的案例 |

## 2. 做了什么

- `server/app/modules/packs/seeds/copywriting.json`：「文案接单顾问」（创作者人群，人工关口含签署）。
  - 五条知识：不接代写学位论文与代考、不编好评刷单、广告不用绝对化用语、改稿轮数与先交大纲、著作权与署名。
  - 新类目「文案写作」。
- `server/app/modules/packs/seeds/camera-install.json`：「监控安装接单顾问」。
  - 五条知识：只拍自家、锁住角度设遮挡区、改默认密码账号在客户名下、录音默认关、高处作业。
  - 新类目「监控安装」。
- `server/app/modules/task/errand.py` 多两类发单拦截（发布与编辑都过）：
  - **SCN-210 代写学位论文、代考**（`academic_ghostwriting`）：「代写 / 代做 / 枪手」与「论文 / 毕设」挨着出现，或「代考 / 替考」。文案、简历这类普通代写，以及论文润色建议、讲解方法都放行。
  - **SCN-211 刷单、刷好评、虚假评价**（`fake_review`）：写明是合作、按真实体验写的探店、试用放行。
  - **否定说法不算**：命中词前面 4 个字以内是「不 / 不是 / 不要 / 禁止 / 严禁 / 拒绝 / 非」（中间可以夹一个动词），就不拦。比如「不代写学位论文、不写刷单好评」「不是代写，只要润色」「本店不刷单」。
  - 两个新错误码进 i18n，提示写明「什么可以照常发」。

## 5. 隐私、授权与边界

- 两个助手都只出草稿；钱、发布、分享个人信息都是人工关口，文案另加签署。
- 拦截只看文字，不调模型；拿不准的由运营人工复核（与 V321 同一做法）。
