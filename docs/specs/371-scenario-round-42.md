## 0. 找信号

- **老照片扫描修复**：家里的老照片褪色、折痕、霉点，子女想扫成电子版留给下一代。风险在三处：
  - **原件**：寄去扫描的少了几张；
  - **修复**：修完奶奶的脸不像她了，上色和「AI 补全」被当成原样；
  - **隐私**：家人的照片被修图师发到网上当案例。

  这是创作者能接的单，AI 能做的比例高。
- **净水器安装与换滤芯**：几乎家家都有。投诉最多的是：
  - 上门用电解、TDS 笔演示吓唬人，推销整机或高价滤芯；
  - 没到期的滤芯也说要全换；
  - 装完橱柜里漏水；
  - 非原装滤芯说成原装。

## 1. 场景卡

### SCN-263 老照片扫描修复

| 项 | 内容 |
|---|---|
| 人群 | 修图师、会扫描的创作者；发单的是想给老人整理照片的子女 |
| 要办的事 | 原件当面清点拍照；不拆不裁；修复不编造，上色和补全先修一张小样；文件只交主人；原件照清单还，交完删副本 |
| 现在怎么办 | 照相馆、网上修图店（寄原件） |
| 痛点 | 频率 1；严重度 3：原件丢了补不回来，修坏了人不像 |
| AI 能做几成 | 0.6：交接清单、修复说明、交付与删除说明；修图本身也大量用工具 |
| 商业价值 | 3 |
| 交付成本 | 1：只写数据，加一个类目 |
| 风险关口 | 钱、签署（作品授权）、发布、分享个人信息都是人工关口；肖像权（《民法典》第一千零一十八、一千零一十九条）；处理目的达成后删除（《个人信息保护法》第四十七条） |
| 证据 | 法律条文；本轮没有引用外部报道链接 |

分数 = 3 × 1 × 3 × 0.6 × 3 ÷ 1 = **16.2**。

### SCN-264 净水器安装与换滤芯

| 项 | 内容 |
|---|---|
| 人群 | 净水器安装师傅；发单的是住户 |
| 要办的事 | 先看水压管路；不用电解、TDS 演示吓唬人；哪一级到期换哪一级；查漏两遍；滤芯型号、价钱、是否原装说清楚 |
| 现在怎么办 | 品牌售后、电商送装、上门推销 |
| 痛点 | 频率 2：滤芯半年到两年换一次；严重度 3：被骗买、漏水泡橱柜 |
| AI 能做几成 | 0.4：问清单、换哪一级的说法、查漏与保养说明；安装由人 |
| 商业价值 | 2 |
| 交付成本 | 1：数据加一个类目 |
| 风险关口 | 钱和发布是人工关口；不作虚假或引人误解的宣传（《消费者权益保护法》第二十条） |
| 证据 | 法律条文；本轮没有引用外部报道链接 |

分数 = 3 × 2 × 3 × 0.4 × 2 ÷ 1 = **14.4**。

## 5. 隐私、授权与边界

- 两个助手都只出草稿；报价、收款、发布都由人确认。
- 修图包：
  - 家人照片是肖像，也是个人信息；
  - 文件只交下单的主人；
  - 想当案例的，先单独问、写明哪几张，主人同意才用；
  - 交付后删除副本。
- 净水器包：水质好不好不靠演示判断，建议看自来水公司公布的水质信息，或者送有资质的机构检测。
