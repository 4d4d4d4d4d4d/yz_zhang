
# 306 第十三轮场景发掘：小件搬家、母婴护理

> 状态：本批实现（V333）。编号 SCN-179（小件搬家）、SCN-180（母婴护理：月嫂、育儿嫂）。
> 来源：skill `scenario-discovery` 按方法每轮补充；上一轮是 V329（302 号）。BACKLOG V333。
> 只增不减：两个种子文件、两个新类目，「母婴护理」沿用持证类目准入（要审核通过的健康证明，一年一检，274 号已有的有效期规则）；已有包、类目、资质规则都不变。

## 0. 找信号

- 搬家在「家务」「整理收纳」两个包里只被顺带提到，没有类目、没有报价方法；而搬家是生活服务里投诉最集中的一类，套路几乎都是「低价揽客、到现场加价、扣着东西不卸」——正好是平台托管 + 变更单能堵上的。
- 月嫂、育儿嫂单价高、一单几周，雇主最担心的是阿姨身体、真假证书、宝宝异常时的处理；2025 年 3 月起两项国家标准施行，服务内容有了依据。

## 1. 场景卡

### SCN-179 小件搬家

| 项 | 内容 |
|---|---|
| 人群 | 接小件搬家的师傅（带车或不带车）；发单的是租房换房的年轻人、老人搬家的子女 |
| 要办的事 | 报前问清楼层、电梯、距离、大件、拆装，报全包价；多出来的走变更单；搬前搬后拍照；贵重物品客户自己带 |
| 现在怎么办 | 网上搜搬家公司、路边小货车，价格到现场才见分晓 |
| 痛点 | 频率 1（一两年一次）；严重度 4（被加价、被扣物品、磕坏说不清） |
| AI 能做几成 | 0.5：问清单、算全包价、变更单写法；搬运在人 |
| 商业价值 | 3：按单抽佣 |
| 交付成本 | 1：只写数据 + 一个类目 |
| 风险关口 | 钱先托管，加价只能走变更单、对方同意；强迫交易是犯罪（刑法第二百二十六条） |
| 证据 | 搬家类投诉长期位居生活服务类投诉前列，集中在价格不透明、服务不规范、售后无保障（[新华网 2026-06-16](https://www.news.cn/digital/20260616/75dcb58a60574762942fd119b1b99a57/c.html)）；低价揽客后加价并扣押物品的搬家人员以强迫交易罪被判刑（[紫牛新闻 2025-10-27](https://www.yzwb.net/news/sh/202510/t20251027_282236.html)） |

分数 = 4 × 1 × 4 × 0.5 × 3 ÷ 1 = **24**。

### SCN-180 母婴护理：月嫂、育儿嫂

| 项 | 内容 |
|---|---|
| 人群 | 接月嫂、育儿嫂单的人；发单的是新手爸妈、替女儿请月嫂的父母 |
| 要办的事 | 健康证明在有效期内；按规范做喂养与生活照料；异常马上就医；不喂药不用偏方；工作范围与监控事先说清；按周托管 |
| 现在怎么办 | 家政公司（中介费高）或熟人介绍，常一次付整月 |
| 痛点 | 频率 3（一单几周、每天）；严重度 5（新生儿与产妇健康） |
| AI 能做几成 | 0.3：上户前清单、每天的记录、就医信号提醒；照护在人 |
| 商业价值 | 4：单价高 |
| 交付成本 | 1：数据 + 一个持证类目（健康证明的有效期规则已有） |
| 风险关口 | 不做医疗：异常就医、紧急 120；健康证明一年一检；钱按周托管 |
| 证据 | 修订后的《家政服务 母婴护理服务质量规范》与《0~3岁婴幼儿居家照护服务规范》（GB/T 45089-2024）2025 年 3 月 1 日起施行（[新华社 2024-12-27](https://www.news.cn/fortune/20241227/6e4fd34794a34f19ad811ba6faccf14d/c.html)；[证券时报网](https://stcn.com/article/detail/1471149.html)） |

分数 = 3 × 3 × 5 × 0.3 × 4 ÷ 1 = **54**。

## 2. 做了什么

- `server/app/modules/packs/seeds/small-moving.json`：「搬家接单顾问」，两个方法、五条知识（全包价怎么算、多出来的走变更单不坐地起价、搬前拍照、贵重物品客户自己带、拆装带工具）、一个模板（全包价、搬前搬后拍照的回报清单）。新类目「搬家」。
- `server/app/modules/packs/seeds/infant-care.json`：「母婴护理接单顾问」，两个方法、五条知识（马上就医的信号、健康证明一年一检、不喂药不用偏方、按周托管换人按天结、工作范围与监控）、一个模板（按周回报四次）。新类目「母婴护理」，要审核通过的「健康证明」（一年一检；没有证报不了名）。

## 3. 数据 / 接口

## 4. 两端

## 5. 隐私、授权与边界

两个助手都只出草稿；钱、发布、分享个人信息都是人工关口；不建议现场加价、扣物品、给宝宝喂药、异常时不就医、没有健康证明上户；不做医疗诊断。
