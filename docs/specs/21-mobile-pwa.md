# 21 · 移动端与 PWA（MOB）

> 现状：Web 是桌面布局的 React+Vite；App 是复用 SDK 的 Expo 骨架。
> 手机用户今天只能用浏览器打开桌面站——这是最大的到达率损失。
> 本 spec 定义**先把 Web 做成手机可用的 PWA**（零发版成本、当天可上），
> 再把 Expo 骨架补成可提审的应用。

## 21.A 响应式与移动交互（P0）

- **MOB-001** 全站响应式断点（≤640 手机 / ≤1024 平板 / >1024 桌面）：
  列表单列、表格转卡片、表单单列、按钮满宽。
- **MOB-002** 底部 Tab 导航（手机可见）：广场 / 发布 / 消息 / 我的；
  未读数角标复用 `IM-未读位点` 接口。
- **MOB-003** 触控目标 ≥44px，输入框 `font-size ≥16px`（防 iOS 自动缩放），
  安全区（刘海/手势条）内边距。
- **MOB-004** 关键页面移动优先重排：广场（筛选收进抽屉）、任务详情
  （合约/进度/评价折叠）、钱包（金额大字优先）。

## 21.B PWA 能力（P0）

- **MOB-010** `manifest.webmanifest`：名称、图标（192/512/maskable）、
  `display: standalone`、主题色、启动 URL。
- **MOB-011** Service Worker：应用外壳预缓存 + 静态资源
  stale-while-revalidate；**API 请求一律不缓存**（资金/状态数据不能陈旧）。
- **MOB-012** 离线兜底页：断网时显示「离线」页而非浏览器错误页。
- **MOB-013** 新版本检测：SW 更新后提示「有新版本，点击刷新」，避免旧壳打新接口。
- **MOB-014** 安装引导：满足条件时展示「添加到主屏幕」提示，可关闭且记忆选择。

## 21.C 移动端专属能力（P1）

- **MOB-020** 定位授权与「附近任务」：调用浏览器地理位置，复用 LBS 检索接口，
  拒绝授权时降级为手动选城市。
- **MOB-021** 拍照/相册直传（交付凭证、打卡照）：`capture` 属性 + 客户端压缩。
- **MOB-022** Web Push 通知（可选授权）：复用通知中心事件，
  用户可在设置里分类开关。

## 21.D App（Expo）（P1）

- **MOB-030** App 补齐主闭环页面（广场/详情/合约/钱包/消息），
  与 Web 共用 `packages/core` SDK，**不重复实现业务逻辑**。
- **MOB-031** `app.json` 配齐 bundle id、版本号、权限说明文案
  （定位/相机/相册，中英文），EAS 构建配置。
- **MOB-032** 深链：`taskplat://task/{id}` 与 Universal Link，
  分享出去的链接能唤起 App、未安装则落 Web。
- **MOB-033** 审核合规清单：账号注销入口、内容举报入口、隐私政策与用户协议链接、
  测试账号说明（应用商店必查项）。

## 21.E 验证（P0）

- **MOB-040** 视口测试：375×667 下无横向滚动、底部 Tab 可见、主按钮可点。
- **MOB-041** manifest / SW 注册测试：产物包含 manifest 与 SW，
  API 路径不在预缓存清单内。
- **MOB-042** SDK 复用测试：App 与 Web 引用同一 SDK 版本，接口签名一致。

## 验收标准

- 手机浏览器打开可完成「注册→报名→聊天→查看合约」全流程，无需缩放；
- 可添加到主屏幕并以独立窗口启动；断网有兜底页；
- 资金与状态数据永不来自缓存。
