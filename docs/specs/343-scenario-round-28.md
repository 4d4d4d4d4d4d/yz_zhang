
# 343 第二十八轮场景发掘：配音、私房烘焙

> 状态：本批实现（V370）。编号 SCN-232（配音）、SCN-233（私房烘焙与定制蛋糕）。
> 来源：skill `scenario-discovery` 按方法每轮补充；上一轮是 V369（342 号）。BACKLOG V370。
> 只增不减：新增两个种子文件、两个新类目、一个资质名（「食品经营许可证或小作坊登记证」）。已有包、类目、资质规则、发单拦截都不变。

## 0. 找信号

- **配音**：创作者人群里门槛低、单量大的一块（短视频、广告、有声书、课件）。纠纷集中在：
  - 用途与授权没说清；
  - 被要求模仿某个明星；
  - 录音被拿去训练 AI；
  - 改文案反复重录。
  2024 年北京互联网法院判了全国首例 AI 生成声音人格权侵权案。
- **私房烘焙与定制蛋糕**：生日、纪念日，单价不高、频率中等。最大的坑：
  - 没证在朋友圈卖，被举报罚款（货值不足一万元也要罚五万以上）；
  - 过敏原没说；
  - 夏天奶油变质；
  - 色素超量。
  这一类要证，平台在准入上把住：经营许可（或小作坊登记）加健康证明，两样都审核。

## 1. 场景卡

### SCN-232 配音

| 项 | 内容 |
|---|---|
| 人群 | 配音员（创作者人群）；发单的是自媒体、小店、出版与培训机构 |
| 要办的事 | 按用途报价、授权写清；不克隆不模仿具体的人；AI 训练单独谈；先试音；念错免费、改文案另算 |
| 现在怎么办 | 配音平台、社交平台接单 |
| 痛点 | 频率 2；严重度 3（被超范围使用、声音被 AI 化） |
| AI 能做几成 | 0.5：问清单、授权与报价写法 |
| 商业价值 | 3 |
| 交付成本 | 1：只写数据加一个类目 |
| 风险关口 | 声音参照肖像权保护（《民法典》第一千零二十三条）；签署与收钱是人工关口 |
| 证据 | 全国首例 AI 生成声音人格权侵权案（[人民日报 2024-10-10](https://paper.people.com.cn/rmrbwap/html/2024-10/10/nw.D110000renmrb_20241010_3-19.htm)，本轮从搜索摘要取得，没有逐字核对） |

分数 = 3 × 2 × 3 × 0.5 × 3 ÷ 1 = **27**。

### SCN-233 私房烘焙与定制蛋糕

| 项 | 内容 |
|---|---|
| 人群 | 私房烘焙师、小烘焙工作室；发单的是过生日、纪念日的人 |
| 要办的事 | 有证经营与健康证明；过敏原写清；冷藏配送；添加剂不超量；取消按进度 |
| 现在怎么办 | 朋友圈、社群接单，很多没证 |
| 痛点 | 频率 2；严重度 4（过敏、变质、被罚） |
| AI 能做几成 | 0.4：问清单、配料卡写法、取消规则 |
| 商业价值 | 2 |
| 交付成本 | 1：数据加一个类目与一个资质名 |
| 风险关口 | 食品经营许可（《食品安全法》第三十五条）、健康证明（第四十五条）、未经许可处罚（第一百二十二条） |
| 证据 | 法律条文；本轮没有引用外部报道链接 |

分数 = 3 × 2 × 4 × 0.4 × 2 ÷ 1 = **19.2**。

## 2. 做了什么

- `server/app/modules/packs/seeds/voice-over.json`：「配音接单顾问」（创作者人群，人工关口含签署）。
  - 五条知识：用途与授权、不克隆不模仿具体的人、AI 训练单独谈、先试音、重录规则。
  - 新类目「配音」，不要资质。
- `server/app/modules/packs/seeds/home-bakery.json`：「私房烘焙接单顾问」。
  - 五条知识：有证经营加健康证明、过敏原、冷藏配送、添加剂与原料来源、取消按进度。
  - 新类目「私房烘焙」：`required_cert` 是「食品经营许可证或小作坊登记证」（`BAKERY_CERT`），`extra_certs` 是「健康证明」。两样都审核通过才能接（V334 的多资质类目）。
