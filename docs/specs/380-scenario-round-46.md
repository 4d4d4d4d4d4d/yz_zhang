
# 380 第四十六轮场景发掘：装修过程监理、宠物接送

> 状态：本批实现（V407）。编号 SCN-272（装修监理）、SCN-273（宠物接送）。
> 来源：按 skill `scenario-discovery` 的方法，每轮补一批场景；上一轮是 V404（378 号）。BACKLOG V407。
> 只增不减：新增两个种子文件和两个新类目，都不要资质。已有的包（包括验房、宠物上门照看）、类目、资质规则、发单拦截都不变。

## 0. 找信号

- **装修过程监理**：验房包（V387）管收房那一天，装修期间没人帮业主盯。常见问题：
  - 水管走线没拍照就封了墙，后来漏水找不到位置；
  - 闭水只泡半天，楼下照样渗；
  - 监理收了施工队的好处；
  - 监理替业主签验收单，后面说不清。

  客单价高、要上门好几次，适合平台的多次上门回报。
- **宠物接送**：宠物上门照看（V200）、宠物善终（V396）都不管路上这一段：送医院、送美容、送寄养、送机场。常见问题：
  - 猫在车里跑出航空箱；
  - 夏天留在车里中暑；
  - 接错狗；
  - 司机自己喂药；
  - 疫苗本没带被拒收。

## 1. 场景卡

### SCN-272 装修过程监理

| 项 | 内容 |
|---|---|
| 人群 | 有经验的家装监理、工程师；发单的是正在装修、不懂施工的业主 |
| 要办的事 | 开工前拿合同图纸；按节点巡检（水电、封板前、防水、贴砖、完工）；隐蔽工程封板前验并拍照存档；闭水泡满；问题写清依据与建议；只对业主负责、不收施工方的钱、不代签、不直接指挥返工 |
| 现在怎么办 | 装修公司自带的监理（不独立）、找懂行的朋友 |
| 痛点 | 频率 1；严重度 4：漏水、返工，动辄几万 |
| AI 能做几成 | 0.5：巡检计划、问题清单草稿、整改建议；看现场由人 |
| 商业价值 | 3：单价高、多次上门 |
| 交付成本 | 1：只写数据，加一个类目 |
| 风险关口 | 钱、发布、签署是人工关口；隐蔽工程在隐蔽以前应通知发包人检查（《民法典》第七百九十八条）；防水蓄水试验（JGJ 298） |
| 证据 | 法律与行业规范条文；本轮没有引用外部报道链接 |

分数 = 3 × 1 × 4 × 0.5 × 3 ÷ 1 = **18**。

### SCN-273 宠物接送

| 项 | 内容 |
|---|---|
| 人群 | 有车的接单者；发单的是要送宠物去医院、美容、寄养、机场的主人 |
| 要办的事 | 装箱系绳；不单独留在车里；问清脾气身体、带疫苗本；两头当面交接、拍照回报；路上急病先送最近的宠物医院、不自己喂药 |
| 现在怎么办 | 宠物店接送、网约车（很多不让带宠物） |
| 痛点 | 频率 2；严重度 3 |
| AI 能做几成 | 0.4 |
| 商业价值 | 2 |
| 交付成本 | 1 |
| 风险关口 | 钱、发布、分享个人信息是人工关口；携犬出户系犬绳（《动物防疫法》第三十条）；不判断病情 |
| 证据 | 法律条文；本轮没有引用外部报道链接 |

分数 = 3 × 2 × 3 × 0.4 × 2 ÷ 1 = **14.4**。

## 2. 做了什么

- `server/app/modules/packs/seeds/renovation-supervision.json`：「装修监理接单顾问」。
  - 五条知识：拿合同图纸、隐蔽工程封板前验、闭水泡满、问题拍照写依据、只对业主负责。
  - 人工关口：钱、发布、签署。
  - 模板按 5 次上门、每次有清单。
  - 新类目「装修监理」。
- `server/app/modules/packs/seeds/pet-transport.json`：「宠物接送接单顾问」。
  - 五条知识：装箱系绳、不单独留车里、问清脾气身体、交接拍照、急病先送医。
  - 新类目「宠物接送」。
