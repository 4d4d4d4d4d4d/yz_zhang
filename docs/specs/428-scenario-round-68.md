## 0. 找信号

- **太阳能热水器清洗维修**：家电维修和燃气具安装包里的「热水器」都是燃气、电热水器。太阳能热水器装在屋顶，县城和农村很多，清洗、换管、修电辅热要上屋顶。常见问题：
  - 雨后上屋顶滑倒；
  - 强酸除垢腐蚀漏水；
  - 碎真空管玻璃渣留在屋顶；
  - 电辅热没断电就拆；
  - 清洗变成换一套控制器。

  一楼院子里的不用证，六楼坡顶要高处作业证，接电辅热要电工证。正好用上 407 号的「发单人加选资质」。
- **老录像带转数字**：老照片修复包管的是照片。家里的婚礼、孩子成长录像带、磁带要转成数字文件，常见问题：
  - 二十盒交出去回来十八盒；
  - 发霉的带子直接上机绞断；
  - 婚礼录像被放到网上；
  - 一个文件三小时找不到想看的；
  - 说好高清拿到很糊。

### SCN-317 老录像带转数字

| 项 | 内容 |
|---|---|
| 人群 | 转录服务的人；发单的是想保存家庭录像的家庭 |
| 要办的事 | 原件清点逐盒交回；受损先说风险；文件只交客户、删工作副本；只转家庭自录；交付格式与分段写清 |
| 现在怎么办 | 照相馆、网店寄送转录 |
| 痛点 | 频率 1；严重度 4：原件丢了就再也没有，家庭隐私外泄 |
| AI 能做几成 | 0.4：交接清单、风险告知、交付清单的草稿；转录由人 |
| 商业价值 | 2 |
| 交付成本 | 1 |
| 风险关口 | 钱、发布、分享个人信息是人工关口；录像里的个人信息按目的最小使用（《个人信息保护法》第六条）；不复制他人作品（《著作权法》） |
| 证据 | 法律条文；本轮没有引用外部报道链接 |

分数 = 2 × 1 × 4 × 0.4 × 2 ÷ 1 = **6.4**。频率低，但原件丢了就再也找不回来，私下交易最容易出事，交付成本又只是一个文件，所以仍做。
