## 0. 找信号

- **钢琴调律**：家里有琴的，一般一年调一到两次。发单人最常遇到的问题：
  - 听不出调得好不好，没法验收；
  - 被说「琴槌要全换」，不知道真假；
  - 多年没调的琴一次拉回标准音，断了弦；
  - 琴贴外墙、对着空调吹，调完很快又走音。
- **闲置代卖**：搬家、换房、老人家清东西时，常托人把闲置拍照、上架、卖掉。风险集中在东西、钱、隐私三处：
  - 交接没清点，少了一件说不清；
  - 照片拍到门牌、快递单；
  - 代卖人压价卖给熟人；
  - 买家把钱转给代卖人个人账户；
  - 旧手机没清数据就卖了。

  这一类单在平台上成交，还能带来抽佣。

### SCN-260 闲置代卖

| 项 | 内容 |
|---|---|
| 人群 | 帮人卖闲置的代卖人；发单的是搬家、清东西的住户，替爸妈清东西的子女 |
| 要办的事 | 交接时清点拍照写交接单；照片不露隐私；定价与最低价由主人定、改价先问；货款走平台；手机电脑先清数据；不能卖的东西不接；卖不掉的原样退回 |
| 现在怎么办 | 自己上二手平台、托熟人、找寄卖店 |
| 痛点 | 频率 2；严重度 3：东西丢、钱不清、隐私外泄 |
| AI 能做几成 | 0.5：交接清单、照实写的描述草稿、对账草稿；收款转账由人 |
| 商业价值 | 3：成交抽佣 |
| 交付成本 | 1：数据加一个类目 |
| 风险关口 | 钱、发布、分享个人信息都是人工关口；受托人按委托人指示处理、所得财产转交委托人（《民法典》第九百二十二条、第九百二十七条） |
| 证据 | 法律条文；本轮没有引用外部报道链接 |

分数 = 3 × 2 × 3 × 0.5 × 3 ÷ 1 = **27**。

## 2. 做了什么

- `server/app/modules/packs/seeds/piano-tuning.json`：「钢琴调律接单顾问」。
  - 五条知识：上门前问清琴况、调前调后当面弹、换件先说清、多年没调的分两次拉、调完讲清湿度与摆放。
  - 人工关口：钱、发布。
  - 新类目「钢琴调律」，不要资质。
- `server/app/modules/packs/seeds/secondhand-resale.json`：「闲置代卖接单顾问」。
  - 五条知识：交接清点拍照、照片不露隐私、价格由主人定、货款走平台、手机先清数据与不能卖的不接。
  - 人工关口：钱、发布、分享个人信息。
  - 新类目「闲置代卖」，不要资质；模板按两次上门：一次交接，一次退回与对账。

## 5. 隐私、授权与边界

- 两个助手都只出草稿；报价、收款、转账、发布都由人确认。
- 代卖包：
  - 照片不露门牌、快递单、证件和人脸；
  - 手机电脑由主人自己清数据，代卖人不碰；
  - 药品、烟草、管制刀具这类不能卖的东西不接。
