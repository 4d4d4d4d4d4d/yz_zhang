
# 409 第五十九轮场景发掘：居家适老化改造、社区团购分拣配送

> 状态：本批实现（V436）。编号 SCN-298（居家适老化改造）、SCN-299（社区团购分拣配送）。
> 来源：按 skill `scenario-discovery` 的方法，每轮补一批场景；上一轮是 V433（406 号）。BACKLOG V436。
> 只增不减：只新增两个种子文件和两个新类目。已有的包（包括给爸妈办事、老人助浴、网店代发货打包、小店临时帮手）、类目、资质规则和发单拦截都不变。

## 0. 找信号

- **居家适老化改造**：「给爸妈办事」包从家属一侧写了适老化改造要查当地补贴，但没有装扶手、改门槛的师傅这一侧。常见问题：
  - 评估一圈推销整套；
  - 扶手装在空心隔墙上一撑就松；
  - 防滑地胶翘边反而绊人；
  - 补贴报了没装的项目；
  - 装完老人不会用。
- **社区团购分拣配送**：团长每天要人帮着分拣、送货，是高频小活。网店代发货包（V427）管的是网店打包寄快递，不管小区里分拣自提。常见问题：
  - 分反了；
  - 冻品化了；
  - 取货名单贴出完整手机号和门牌；
  - 坏果没登记说不清；
  - 帮忙的人私卖自制食品。

## 2. 做了什么

- `server/app/modules/packs/seeds/elder-home-mod.json`：「适老化改造接单顾问」。五条知识：
  - 先评估不推销全套；
  - 扶手进实墙试拉；
  - 防滑铺平、高差改坡；
  - 补贴按清单如实申报；
  - 带老人走一遍并回访。
- `server/app/modules/packs/seeds/group-buy-helper.json`：「团购分拣接单顾问」。五条知识：
  - 按单核对分拣；
  - 冻品先进冷柜；
  - 名单只写尾号；
  - 缺货坏果如实登记；
  - 只发平台上架商品。
- 新类目「居家适老化改造」「社区团购分拣配送」，都不要资质。
