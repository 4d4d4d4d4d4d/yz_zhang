
# 403 第五十七轮场景发掘：无人机航拍、电脑组装与重装

> 状态：本批实现（V430）。编号 SCN-294（无人机航拍）、SCN-295（电脑组装与重装）。
> 来源：按 skill `scenario-discovery` 的方法，每轮补一批场景；上一轮是 V427（400 号）。BACKLOG V430。
> 只增不减：只新增两个种子文件和两个新类目。已有的包（包括活动摄影、数码维修与旧机回收、监控安装）、类目、资质规则和发单拦截都不变。

## 0. 找信号

- **无人机航拍**：活动摄影包管地面拍摄，航拍没有人管；无人机是有专门管理规定的。
  - 常见问题：
    - 没登记就飞；
    - 飞进禁飞区；
    - 在婚礼宾客头顶飞；
    - 楼盘航拍拍进住户窗户；
    - 风大硬飞炸机；
    - 成片规格没说清。
- **电脑组装与重装**：数码维修包管修和回收，不管「装一台新电脑」和「重装系统」。常见问题：
  - 配置单上的大牌电源换成杂牌；
  - 矿卡当新卡卖；
  - 装一堆捆绑软件；
  - 重装把别的盘也格了；
  - 不测试就交付。

## 1. 场景卡

### SCN-294 无人机航拍

| 项 | 内容 |
|---|---|
| 人群 | 航拍飞手；发单的是婚礼、活动、楼盘、景区、短视频创作者 |
| 要办的事 | 实名登记并买第三者责任险；起飞前查空域；不过人群、不拍私密空间；看风力电量；成片规格写清 |
| 现在怎么办 | 婚庆公司打包、熟人介绍、短视频平台私信 |
| 痛点 | 频率 2；严重度 4：坠机伤人、违规飞行被处罚、侵犯隐私 |
| AI 能做几成 | 0.4：检查清单、空域要点、成片约定的草稿；飞行与判断由人 |
| 商业价值 | 3 |
| 交付成本 | 1：只写数据、加一个类目 |
| 风险关口 | 钱、发布、签署、分享个人信息是人工关口；实名登记、空域、操控员执照按《无人驾驶航空器飞行管理暂行条例》；不拍他人私密空间（《民法典》第一千零三十三条）。<br>本轮不把执照设成报名门槛：消费级的轻型机多数不要执照，按机型要执照的，知识里提醒持证再飞 |
| 证据 | 行政法规与法律条文；本轮没有引用外部报道链接 |

分数 = 2 × 2 × 4 × 0.4 × 3 ÷ 1 = **19.2**。

### SCN-295 电脑组装与重装

| 项 | 内容 |
|---|---|
| 人群 | 装机、修电脑的师傅；发单的是学生、游戏玩家、小工作室、家里老人的电脑 |

| 现在怎么办 | 电脑城、网店整机、找懂行的朋友 |
| 痛点 | 频率 2；严重度 3：以次充好、数据丢失 |
| AI 能做几成 | 0.4：配置单与核对清单、备份清单、测试记录的草稿；组装与排障由人 |
| 商业价值 | 2 |
| 交付成本 | 1 |
| 风险关口 | 钱、发布、分享个人信息是人工关口；信息真实全面（《消费者权益保护法》第二十条），欺诈三倍赔偿（第五十五条）；正版软件（《计算机软件保护条例》） |
| 证据 | 法律与行政法规；本轮没有引用外部报道链接 |

分数 = 3 × 2 × 3 × 0.4 × 2 ÷ 1 = **14.4**。

## 2. 做了什么

- `server/app/modules/packs/seeds/drone-aerial.json`：「航拍接单顾问」，属于创作者人群，带 `sign` 关口。五条知识：
  - 实名登记与保险；
  - 起飞前查空域；
  - 不过人群、不拍私密空间；
  - 风力电量与试飞；
  - 成片规格与素材用途。
- `server/app/modules/packs/seeds/pc-build.json`：「装机接单顾问」。五条知识：
  - 配置单核对；
  - 二手翻新件说明；
  - 正版系统不捆绑；
  - 先备份再格式化；
  - 压力测试后交付。
- 新类目「无人机航拍」「电脑组装与重装」，都不要资质。

## 5. 隐私、授权与边界

- 两个助手都只出草稿；报价、收款、发布、签字都由人确认。
- 航拍助手：不出黑飞、闯管制空域、在人群上方飞、偷拍的建议。
- 装机助手：
  - 不翻看客户硬盘里的资料；
  - 备份由客户确认。
