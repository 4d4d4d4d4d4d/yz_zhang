# 08 · 内容：知识分享 / 视频 / 博客 / 朋友圈

模块前缀：`CNT`

## 目标

内容是信任与流量的放大器：执行者靠内容证明能力获得订单，
用户靠内容学习经验，平台靠内容提升留存并沉淀知识库素材。

## A. 内容形态

| 形态 | 说明 | 优先级 |
|---|---|---|
| 短视频 | 竖屏流消费，技能展示/案例复盘/生活记录 | P1 |
| 博客/长文 | 知识分享、图文教程、经验帖 | P1 |
| 朋友圈/动态 | 轻量图文动态，好友与关注者可见 | P1 |
| 任务案例卡 | 闭环任务一键生成"作品案例"（脱敏，双方授权） | P1 |

## E. 内容与主业务打通（关键设计）

- 用户主页 = 名片：内容 + 案例 + 信用分 + 服务报价，一页承接"看到→信任→下单"。
- 内容互动行为进入匹配特征（活跃度、专业度信号）。
- 优质经验帖经作者授权后进入知识库公共检索（KB-003）。
