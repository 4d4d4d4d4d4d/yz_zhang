
# 105 写操作必须在响应发出之前提交（CONC-070）

> 状态：本批实现（V131）
> 依赖：14 号（事务边界整体回滚）、18 号（CONC-020 NullPool）、104 号（V130 在 Postgres 上撞见）

## 0. 怎么撞见的

V130 在本地 Postgres 16 上连跑全链路验收，六轮里有一轮红在「注销后登录态失效」：
**注销返回 200 之后，紧接着的 `GET /users/me` 仍然是 200**。鉴权直接读库、没有缓存——
那一刻库里确实还没有「已注销」。

病因：FastAPI 0.142 里 `yield` 依赖不写 `scope` 时按 `"request"` 处理，**收尾代码在响应
送达客户端之后才执行**（FastAPI 自己的文档原话：end after the response is sent back to
the client）。`get_db` 的 `commit()` 就在收尾代码里。

## 1. 后果

| 场景 | 后果 |
|---|---|
| 客户端拿到 200 立刻发下一个请求 | 读到提交之前的数据。注销后登录态在那一瞬间仍然有效；刚发的任务刷新列表看不到 |
| 提交失败（唯一约束、序列化冲突、连接断开） | **客户端已经被告知成功了**。「充值成功」「提现已受理」先于入账提交送达，而入账可能根本没发生 |

后一种比前一种严重得多，而它在日志里只是一条响应之后的异常，没有任何东西会告诉用户。

## 2. 确定性的探针

`TestClient` 看不见这个窗口：它等整个 ASGI 调用结束（包括响应之后的收尾）才返回。
所以测试直接驱动 ASGI 应用，**在响应体被发出的那一刻**用一个独立会话去库里看：

```
注销：  客户端收到 200 的那一刻，is_deleted = False、未吊销会话 = 1     ← 修之前
充值：  客户端收到「succeeded」的那一刻，余额 = 0（应为 1234）          ← 修之前
```

这条在 SQLite 与 Postgres 上都是确定性的红——不靠撞时机。

## 3. 修法

所有 `Depends(get_db)` 改成 `Depends(get_db, scope="function")`：收尾（提交或回滚）在
端点函数结束之后、**响应发出之前**执行。336 处 `get_db` 与 23 处 job 锁守卫（`job_slot`，
它也是 `yield` 依赖、并且依赖 `get_db`）一起改。

**必须一起改**，有两个原因：

- 作用域是 FastAPI 依赖缓存键的一部分。同一个请求里 `Depends(get_db)` 与
  `Depends(get_db, scope="function")` 混用，会建出**两个会话**——鉴权读到的 user 在一个
  会话里，业务写入在另一个里。红验里只把钱包路由改回去，充值那条探针就红了。
- `scope="request"` 的 `yield` 依赖不许依赖 `scope="function"` 的（FastAPI 启动即报错）。

没有后台任务、流式响应在响应之后还要用这个会话（查过：全仓零处）。

## 4. 闸门

| 闸门 | 内容 |
|---|---|
| CONC-070a | 注销：收到 200 的那一刻，库里已注销、会话已吊销 |
| CONC-070b | 充值：收到 succeeded 的那一刻，余额已入账 |
| CONC-070c | 遍历路由树，**每一个** `yield` 依赖都是 function 作用域（不只 `get_db`——下一个加 `yield` 依赖的人也被管到） |
| CONC-070d | 源码里没有不写 scope 的 `Depends(get_db)` / `Depends(job_slot(...))` |
| Postgres | 这组测试进了 CI 的 Postgres job（V130 建的那一步）；本地 Postgres 上全链路验收六轮全绿 |

红验：只把钱包路由改回 `Depends(get_db)` → 充值探针、路由树扫描、源码扫描三条红。
整体退回 → 四条都红（修之前的状态）。

## 5. 这一批没做的

- 六轮全绿**不是**证据（原来就是六轮一次）；证据是第 2 节那条确定性探针。
- 18 号 spec 当年把同一个症状归因于 SQLite 连接池的过期读快照，改成了 NullPool。
  NullPool 留着无害；但那次的诊断至少不完整——这个窗口在 Postgres 上同样存在。
  已在 `get_db` 的 docstring 里写明，不改 18 号的原文（那是当时的实况）。
