# 06 · AI 知识库（闭环任务经验积累）

模块前缀：`KB`

## 目标

把每一个闭环任务沉淀为结构化、可检索、可复用的经验资产，反哺四个场景：
1. AI 任务分解（模板与依赖结构）
2. 估价估时（真实成交数据）
3. 推荐匹配（谁擅长做什么）
4. 智能客服与用户自助（怎么做/多少钱/多久/有什么坑）

## A. 经验采集（写入侧）

| 编号 | 功能点 | 优先级 | 说明 / AC |
|---|---|---|---|
| KB-001 | 闭环任务自动摘要 | P1 | 任务终结后，AI 从任务描述、沟通记录（脱敏）、交付物、变更单、评价中提炼结构化经验卡：类目、范围、实际价格、实际工期、分解结构、返工原因、纠纷原因 |
| KB-002 | 脱敏与授权 | P0 | 默认仅提取统计与模式信息；引用具体案例需双方授权；个人身份/联系方式/精确位置强制脱敏 |
| KB-003 | 执行者经验笔记 | P1 | 执行者可为闭环任务补充"经验帖"（可选公开，计入创作者内容，联动 08） |
| KB-004 | 失败/纠纷案例入库 | P1 | 流拍、违约、纠纷案例同样入库，标注失败原因，用于风险预警（AI-DEC-022） |
| KB-005 | 平台运营知识（FAQ/规则/流程） | P0 | 客服知识库来源，运营后台可维护（联动 10） |

## D. 质量与治理

- **冷启动**：初期知识库空 → 用人工整理的类目模板 + 外部公开参考价兜底；明确标注数据来源与置信度。
- **反馈回路**：AI 估价与实际成交差异自动回流为训练/校准信号。
- **防污染**：刷单/异常任务的数据不入库（依赖 12 风控标记）。
- **可解释**：所有对用户展示的参考价/建议必须附样本量与区间，不给单点"确定值"。
