
# 273 排班复制到其他几天

> 状态：本批实现（V301）。编号 ESCA-071。
> 来源：263 号 spec「没做的」——「把一天的排班复制到其他几天」；BACKLOG V301。
> 只增不减：逐段编辑、加一段、工作日 9–18 都不变；只多一个复制控件。服务端不变。

## 0. 要解决的问题

V290 能按天设多段了，可周一到周五都是「早 8–12、晚 18–22」两班的人，要填十段。

## 1. 业界怎么做

排班编辑器普遍有「复制到其他日期 / 应用到工作日」。（本批没有另找外部来源。）

## 2. 规则

- 「把 周X 的几段复制到 ☐周一 ☐周二 …」：勾了几天才能点「复制」。
- 目标那几天原有的段先清掉，换成来源那天的几段（同样的时间）；来源那天不动；结果按周几、开始时间排好。来源那天没有排班时什么都不改（不会把目标几天清空）。
- 复制只改编辑器里的草稿，按「保存排班」才提交（服务端照旧校验重叠）。

## 3. 数据 / 接口

不涉及。共享 SDK 新增纯函数 `copyScheduleDay(rows, from, to)`。

## 4. 两端

- **App**：后台只在 Web，不涉及。
