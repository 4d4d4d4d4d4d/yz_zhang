
# 337 第二十四轮场景发掘：插画约稿、代驾

> 状态：本批实现（V364）。编号 SCN-222（插画约稿）、SCN-223（代驾）、SCN-224（代驾责任险，外）。
> 来源：skill `scenario-discovery` 按方法每轮补充；上一轮是 V362（335 号）。BACKLOG V364。
> 只增不减：新增两个种子文件、两个新类目；「代驾」复用「陪驾」的资质名「驾驶证（三年以上驾龄）」，没有新的资质名。已有包、类目、资质规则、发单拦截都不变。

## 0. 找信号

- **先排除已覆盖的**：本轮先查了空调拆装。家电清洗包（V313）已经把出窗、2 米以上的外机拆装单独放进要高处作业证的类目，并引用了人民日报 2024-07-08《高空拆装空调 严防无证上岗》，所以不再重复做。
- **插画约稿**：创作者人群里单价高、纠纷多的一块。纠纷集中在：
  - 用途与授权没说清（自用价拿去商用）；
  - 交稿后被怀疑是 AI 生成、要求退款；
  - 改稿没完没了；
  - 画到一半取消。
  平台的分期托管、每期挂交付附件、放款前原图锁定、交付附授权清单正好接得住。
- **代驾**：夜间高频的零工。纠纷集中在：
  - 车况（多了划痕）；
  - 准驾车型不符；
  - 醉酒客户到地方自己开走；
  - 代驾期间的违章；
  - 车辆保险过期。
  事故责任的顺序是先交强险、再商业险、不足再由侵权人赔。

## 1. 场景卡

### SCN-222 插画约稿

| 项 | 内容 |
|---|---|
| 人群 | 画师（创作者人群）；发单的是个人、小店、出版方 |
| 要办的事 | 问清用途与授权范围；说清用没用 AI；草图、线稿、上色分阶段确认，改稿轮数写清；不描图不照抄；按阶段写清取消规则 |
| 现在怎么办 | 社交平台约稿、熟人介绍 |
| 痛点 | 频率 2；严重度 3（白画、被退款、侵权） |
| AI 能做几成 | 0.5：问清单、授权与报价写法、分阶段确认写法 |
| 商业价值 | 3 |
| 交付成本 | 1：只写数据加一个类目 |
| 风险关口 | 著作权许可与转让合同应约定权利种类、范围、期间（《著作权法》第二十六、二十七条）；AI 生成合成内容标识；签署与收钱是人工关口 |
| 证据 | 画风难受版权保护、画师担心 AI 学画风（[爱范儿](https://www.ifanr.com/1559586)，本轮从搜索摘要取得，没有逐字核对） |

分数 = 3 × 2 × 3 × 0.5 × 3 ÷ 1 = **27**。

### SCN-223 代驾

| 项 | 内容 |
|---|---|
| 人群 | 代驾司机；发单的是车主 |
| 要办的事 | 驾龄与准驾车型对得上；出发前确认保险年检、绕车拍车况、记里程油量；按约定路线开；钥匙交给清醒的人；代驾期间违章自己处理 |
| 现在怎么办 | 代驾 App、饭店门口揽客 |
| 痛点 | 频率 3；严重度 4（事故、车损争议、醉驾风险） |
| AI 能做几成 | 0.3：问清单、车况记录写法、计价写法 |
| 商业价值 | 3 |
| 交付成本 | 1：只写数据加一个类目（资质复用陪驾的） |
| 风险关口 | 驾驶证与准驾车型（《道路交通安全法》第十九条）；事故赔偿顺序（《民法典》第一千二百一十三条）；醉驾（《刑法》第一百三十三条之一） |
| 证据 | 代驾事故责任划分的报道（[扬子晚报网 2025-08](https://www.yzwb.net/news/sh/202508/t20250818_251803.html)、[扬子晚报网 2026-10](https://www.yzwb.net/news/sh/202610/t20261016_403290.html)；本轮从搜索摘要取得，没有逐字核对） |

分数 = 3 × 3 × 4 × 0.3 × 3 ÷ 1 = **32.4**。

## 2. 做了什么

- `server/app/modules/packs/seeds/illustration-commission.json`：「插画约稿顾问」（创作者人群，人工关口含签署）。
  - 五条知识：先问用途与授权范围、用没用 AI 说清、分阶段确认与改稿轮数、不描图不照抄、按阶段写清取消规则。
  - 新类目「插画约稿」，不要资质。
- `server/app/modules/packs/seeds/designated-driver.json`：「代驾接单顾问」。
  - 五条知识：驾龄与准驾车型、保险与年检、出发前拍车况、钥匙交给清醒的人、路线与违章。
  - 模板回报清单含出发前与到达后拍车况。
  - 新类目「代驾」，要审核通过的「驾驶证（三年以上驾龄）」（与陪驾同一个资质名，持一张两个类目都能接）。

## 5. 隐私、授权与边界

- 两个助手都只出草稿；钱、发布、分享个人信息都是人工关口，插画另加签署。
- 平台不提供代驾责任险，知识条目里写明；车辆保险过期的，说明风险，客户坚持的不接。
