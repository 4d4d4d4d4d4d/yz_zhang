
# 328 第二十轮场景发掘：上门跟妆、小店网站与小程序搭建

> 状态：本批实现（V355）。编号 SCN-203（上门跟妆）、SCN-204（小店网站与小程序搭建）。
> 来源：skill `scenario-discovery` 按方法每轮补充；上一轮是 V352（325 号）。BACKLOG V355。
> 只增不减：新增两个种子文件、两个新类目（都不要资质）；已有包、类目、资质规则都不变。

## 0. 找信号

- **上门跟妆**：婚礼、拍照、毕业照的上门化妆，单价不低、时间点要紧。纠纷集中在三处：
  - 临时换人；
  - 来路不明的化妆品、几个人共用不干净的刷具导致过敏；
  - 定金、取消、超时事后扯皮。
  这些都能用「写进单子 + 当天清单」接住。
- **小店网站与小程序搭建**：小店开业、转线上最常外包的活，属于工作室人群（之前几轮多是接单者人群）。常见的坑：
  - 「简单商城」越做越大；
  - 付了全款拿不到源码：委托开发没约定的，著作权默认归开发方；
  - 域名和小程序注册在开发方名下；
  - 上线前才知道要备案。
  平台的分期合约、变更单、交付文件托管正好接得住。

## 1. 场景卡

### SCN-203 上门跟妆

| 项 | 内容 |
|---|---|
| 人群 | 化妆师、跟妆师；发单的是新娘、拍照的人、活动主办方 |
| 要办的事 | 问清场合、人数、时间、跟多久；正规产品；工具一人一清洁；易过敏的先试敏；定金、取消、超时写清；不临时换人 |
| 现在怎么办 | 社交平台、婚庆公司介绍 |
| 痛点 | 频率 2；严重度 3（过敏、婚礼当天出岔子） |
| AI 能做几成 | 0.4：问清单、定金与取消写法、当天卫生与试敏清单 |
| 商业价值 | 3 |
| 交付成本 | 1：只写数据加一个类目 |
| 风险关口 | 不给医疗建议（过敏就停用、建议就医、保留产品）；钱走托管 |
| 证据 | 选有「妆字号」的正规产品、过敏时停用并带产品就医、刷具定期清洁（[澎湃号 2025-09](https://m.thepaper.cn/newsDetail_forward_31612627)，本轮从搜索摘要取得，原文页面在本环境打不开、没有逐字核对）；化妆服务合同常约定定金、取消、过敏时配合处理（[法大大法律科普](https://www.fadada.com/article/Basics-020887)） |

分数 = 3 × 2 × 3 × 0.4 × 3 ÷ 1 = **21.6**。

### SCN-204 小店网站与小程序搭建

| 项 | 内容 |
|---|---|
| 人群 | 建站工作室、独立开发者（工作室人群）；发单的是小店店主、小公司 |
| 要办的事 | 需求写成清单并按里程碑分期；源码与著作权归属写进合同；账号用客户主体注册；上线前备案；模板、字体、图片要有授权；维护期写清 |
| 现在怎么办 | 熟人介绍、模板建站服务商 |
| 痛点 | 频率 1；严重度 4（钱付了拿不到源码、账号被卡住、上不了线） |
| AI 能做几成 | 0.5：需求清单、合同条款提示清单、上线前检查清单 |
| 商业价值 | 4：单价高 |
| 交付成本 | 1：只写数据加一个类目 |
| 风险关口 | 签合同与收钱是人工关口；不把客户账号注册在开发方名下；不留后门 |
| 证据 | 委托开发的软件，著作权归属由书面合同约定，没有约定的归受托人（《计算机软件保护条例》第十一条、《著作权法》第十九条）；在境内提供服务的网站、App、小程序要备案（《互联网信息服务管理办法》、工业和信息化部 2023 年移动互联网应用程序备案通知）。本轮找到的公开材料多为服务商推广文章，不引用链接。 |

分数 = 3 × 1 × 4 × 0.5 × 4 ÷ 1 = **24**。

## 2. 做了什么

- `server/app/modules/packs/seeds/makeup-artist.json`：「上门跟妆接单顾问」。
  - 两个方法：接单前问清四件事、当天。
  - 五条知识：正规化妆品、工具一人一清洁、先试敏且过敏马上停用、定金取消超时、不临时换人。
  - 一个模板：当天清单含试敏。
  - 新类目「上门跟妆」。
- `server/app/modules/packs/seeds/small-site-builder.json`：「小店建站接单顾问」（工作室人群，人工关口含签署）。
  - 两个方法：需求写成清单、上线与交付。
  - 五条知识：需求清单与变更、源码与著作权写进合同、账号在客户名下、上线前备案、模板字体图片授权。
  - 一个模板。
  - 新类目「网站小程序搭建」。

## 5. 隐私、授权与边界

- 两个助手都只出草稿；钱、发布、分享个人信息都是人工关口，建站另加签署。
- 不建议：用三无化妆品、共用不清洁的工具、不试敏、临时换人、给医疗建议；把客户账号注册在开发方名下、源码归属不写、用没授权的模板、不备案上线、留后门。
