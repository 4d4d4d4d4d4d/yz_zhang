
# 274 第八轮场景发掘：整理收纳、上门做饭

> 状态：本批实现（V298）。编号 SCN-153（整理收纳）、SCN-154（上门做饭）。
> 来源：skill `scenario-discovery` 按方法每轮补充；上一轮是 V286（259 号），之后九批都在做平台能力。BACKLOG V298。
> 只增不减：交付物是两个种子文件、两个新类目，外加「健康证明」的有效期规则（与 214 号的无犯罪记录证明同一套写法）；已有类目、包、资质规则都不变。

## 0. 找信号

- 愿景 1.7 的人群表里，接单者（gig）这一列已经有家务、宠物、助老、代看房、小店帮手；家里「整理」和「做饭」两类高频需求还没有包。
- 已有的「家庭事务」包只有保洁、小修、搬家、陪诊；整理收纳常被当成保洁，范围和验收最容易扯皮。
- 上门做饭碰到入口食品，平台已有的持证类目准入（资质审核）正好接得住。

## 1. 场景卡

### SCN-153 整理收纳

| 项 | 内容 |
|---|---|
| 人群 | 接整理收纳单的人（多为兼职、转行的家政从业者）；发单的是搬家后、换季、有孩子的家庭 |
| 要办的事 | 上门前问清量与效果、报价不亏本；现场不丢客户东西、不惹隐私麻烦 |
| 现在怎么办 | 社交平台接私单，口头报价；前后对比照直接发作品集 |
| 痛点 | 频率 2（换季、搬家时）；严重度 3（量估错亏本、东西说不清、照片隐私） |
| AI 能做几成 | 0.5：问清单、报价写法、常识；去留、拍照、钱都要人定 |
| 商业价值 | 3：抽佣；与保洁、搬家互相转化 |
| 交付成本 | 1：只写数据 + 一个类目 |
| 风险关口 | 处置他人物品（民法典侵权责任）、拍摄与公开家中照片（隐私权、个人信息） |
| 证据 | 人社部 2021 年在「家政服务员」下新增「整理收纳师」工种，整理收纳不等于保洁（[人民日报 2021-11-24](https://paper.people.com.cn/rmrbwap/html/2021-11/24/nw.D110000renmrb_20211124_2-11.htm)）；至今没有国家职业标准，四川 2025 年起纳入专项职业能力考核（[四川在线](https://cbgc.scol.com.cn/news/7956773)）；另见 [人民政协网 2021-05-07](https://www.rmzxw.com.cn/c/2021-05-07/2847932.shtml) |

分数 = 3 × 2 × 3 × 0.5 × 3 ÷ 1 = **27**。

### SCN-154 上门做饭

| 项 | 内容 |
|---|---|
| 人群 | 会做家常菜、想接上门做饭的人；发单的是上班族、带娃家庭、独居者 |
| 要办的事 | 有健康证明再接单；问清人数口味与过敏；食材与服务费说清；厨房安全 |
| 现在怎么办 | 社交平台私下约，健康证有没有全凭自觉；食材报销口头说 |
| 痛点 | 频率 4（每周固定几次的不少）；严重度 3（过敏、食品安全、燃气） |
| AI 能做几成 | 0.4：问清单、计价写法、常识；做菜、验收、钱都在人 |
| 商业价值 | 3：抽佣；按周的固定单 |
| 交付成本 | 2：数据 + 类目 + 健康证明有效期规则（几行代码） |
| 风险关口 | 接触直接入口食品要健康证明（食品安全法第四十五条）；对外加工售卖要许可（第三十五条）；不替代医嘱 |
| 证据 | 上门做饭需求来自上班族、带娃家庭与独居者，业内建议通过有认证的平台下单（[中国新闻网 2022-10-31](https://www.chinanews.com/sh/2022/10-31/9883187.shtml)）；2026 年报道指出食品安全与责任界定最突出，建议持证上岗、厨师具备健康证（[中国新闻网 2026-02-14](https://www.chinanews.com.cn/sh/2026/02-14/10572213.shtml)） |

分数 = 4 × 4 × 3 × 0.4 × 3 ÷ 2 = **28.8**。

## 2. 做了什么

- `server/app/modules/packs/seeds/home-organizing.json`：「整理收纳接单顾问」，两个方法（上门前问清五件事、上门整理的规矩）、五条知识（工种与证书、旧物去留、贵重物品、拍照同意、不等于保洁）、两个模板（衣橱整理带按次回报清单、搬家后归位）。
- `server/app/modules/packs/seeds/home-cooking.json`：「上门做饭接单顾问」，两个方法、五条知识（健康证明、过敏原、食材费、厨房安全、不对外售卖）、两个模板（一顿家常菜、每周固定几次，都带按次回报清单与过敏一栏）。
- 新类目「整理收纳」「上门做饭」；「上门做饭」要审核通过的「健康证明」（沿用持证类目准入：没有证明报不了名）。
- 「健康证明」提交资质时有效期必填、最长一年（`certificate_expiry_required` / `certificate_expiry_too_far`，沿用 214 号的错误码）。

## 3. 数据 / 接口

不新增表与接口。类目随启动时的类目补种进库。

## 4. 两端

服务包两端已接（V148）：运营在后台导入种子、四眼上线后，用户在两端的服务包里启用、问助手、按模板发单。资质上传沿用两端已有的资质页。

## 5. 隐私、授权与边界

两个助手都只出草稿；钱、发布、分享个人信息都是人工关口；不碰客户物品的处置、不拍客户家、不替代医嘱、不建议对外售卖。
