# 03 · 任务核心：发布 / 推荐人选 / 执行 / 完成

模块前缀：`TASK`（任务）/ `MATCH`（匹配推荐）

## A. 任务模型

任务类型（首期枚举，可扩展）：
- **服务型**：打扫卫生、跑腿、维修、家教等，通常 LBS 强相关。
- **交易型**：一笔二手/闲置交易的委托与担保。
- **项目型**：设计、开发、文案等可远程交付，常需 AI 分解为子任务。
- **事件型**：一次性小事件（帮忙排队、代取件等）。

任务状态机（P0，必须严格约束流转）：

```
草稿 → 待审核 → 已发布（招募中）→ 已匹配（合约生成）→ 执行中
   → 待验收 → 已完成
其中任意节点可进入：已取消 / 纠纷中 / 已关闭
执行中可含：里程碑1..n（对应合约分期）
```

## B. 任务发布

| 编号 | 功能点 | 优先级 | 说明 / AC |
|---|---|---|---|
| TASK-001 | 结构化任务发布表单 | P0 | 字段：标题、类型、描述、预算（一口价/竞价/时薪）、截止时间、地点（线上/线下+坐标）、附件、所需技能标签、人数 |
| TASK-002 | AI 辅助发布（对话式补全） | P1 | 用户一句话描述 → AI 追问补全要素 → 生成结构化草稿（依赖 04/06） |
| TASK-003 | 任务模板库 | P1 | 高频类目（保洁/跑腿/设计…）预置模板与参考价 |
| TASK-004 | 发布前内容审核 | P0 | 机审（违禁词/违法类目）+ 抽样人审；违规类目清单可配置 |
| TASK-005 | 任务编辑与撤回 | P0 | 已匹配后关键字段（价格/验收条件）不可单方修改，需双方确认变更单 |
| TASK-006 | 定时/周期任务 | P2 | 如每周保洁；自动按周期重新发布 |
| TASK-007 | 多人任务（招募 N 人） | P1 | 如活动地推；每人独立子合约 |
| TASK-008 | 任务可见范围 | P1 | 公开 / 仅圈层 / 仅指定人（定向邀约） |

## C. 推荐人选（匹配引擎）

| 编号 | 功能点 | 优先级 | 说明 / AC |
|---|---|---|---|
| MATCH-001 | 执行者主动报名/报价 | P0 | 报名列表按信用分/报价/距离排序供发布者选择 |
| MATCH-002 | AI 推荐人选 Top-N | P0 | 特征：技能标签匹配度、历史同类任务完成率、评价、距离、报价区间、响应速度、在线状态；输出推荐理由（可解释） |
| MATCH-003 | 推送触达候选人 | P0 | 向匹配的执行者推送新任务（推送频控、可订阅类目） |
| MATCH-004 | 定向邀约 | P1 | 发布者向指定执行者发出邀约，24h 未响应自动失效 |
| MATCH-005 | 圈层内优先曝光 | P1 | 任务带圈层标签时优先在对应圈层信息流曝光（依赖 09） |
| MATCH-006 | LBS 附近任务/附近的人 | P0 | 地图与列表双视图（依赖 07） |
| MATCH-007 | 竞价模式 | P1 | 执行者出价 + 方案，发布者比选 |
| MATCH-008 | 匹配策略后台可配 | P1 | 权重、召回源、冷启动策略可在管理后台调参 |
| MATCH-009 | 冷启动兜底 | P0 | 新执行者扶持流量；无匹配时降级为广场曝光 + 人工运营派单 |

## D. 执行与协作

| 编号 | 功能点 | 优先级 | 说明 / AC |
|---|---|---|---|
| TASK-020 | 双方确认成交 → 触发合约生成 | P0 | 成交即冻结/托管资金（依赖 05） |
| TASK-021 | 任务详情页（双方视图） | P0 | 状态、合约摘要、里程碑、沟通入口、操作按钮按角色/状态渲染 |
| TASK-022 | 进度更新与打卡 | P0 | 文字/图片/视频进度汇报；线下任务支持到场定位打卡 |
| TASK-023 | 任务内 IM 会话 | P0 | 每个任务自动建会话，聊天记录作为纠纷证据链（依赖 09） |
| TASK-024 | 交付物上传 | P0 | 文件/链接/照片；带版本记录 |
| TASK-025 | 变更单（改价/改期/改范围） | P1 | 双方确认后合约同步变更 |
| TASK-026 | 取消与违约处理 | P0 | 按状态阶段计算责任与退款比例（规则引擎，见 05） |
| TASK-027 | 执行超时提醒与自动升级 | P1 | 超时提醒 → 客服介入 → 可发起纠纷 |

## E. 验收与完成

| 编号 | 功能点 | 优先级 | 说明 / AC |
|---|---|---|---|
| TASK-030 | 提交验收 | P0 | 执行者提交 → 发布者确认/驳回（驳回需理由 + 整改期） |

| TASK-036 | 母任务进度聚合 | P0 | 子任务完成度实时聚合到母任务，全部关键子任务闭环 → 母任务可整体验收（依赖 04） |
