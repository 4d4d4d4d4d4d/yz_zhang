
# 286 第九轮场景发掘：教老人用手机、家电清洗

> 状态：本批实现（V313）。编号 SCN-159（教老人用手机）、SCN-160（家电清洗）。
> 来源：skill `scenario-discovery` 按方法每轮补充；上一轮是 V298（274 号），之后十四批都在做平台能力。BACKLOG V313。
> 只增不减：交付物是两个种子文件、两个新类目，外加「高处作业操作证」的有效期规则（与 214、274 号同一套写法）；已有类目、包、资质规则都不变。

## 0. 找信号

- 愿景 1.7 的人群表里，「替爸妈发单」（V202）与「助老陪伴」已经有了，但子女最常替老人找的「教用手机」还没有包：助老陪伴的模板只有陪诊、陪聊。
- 接单者这一列有保洁、小修、搬家，季节性最强的「空调清洗」没有包；空调外机在窗外，是平台目前碰到的第一种**特种作业**。
- 平台已有的持证类目准入（资质审核）、按次回报清单、变更单正好接得住这两个场景，只要写数据和几行规则。

## 1. 场景卡

### SCN-159 教老人用手机

| 项 | 内容 |
|---|---|
| 人群 | 想接「上门教老人用手机」单的人（大学生、退休教师、社区志愿者转兼职）；发单的多是不在身边的子女 |
| 要办的事 | 问清老人想学什么、手机型号、眼睛耳朵怎样；一次教一两样，让老人自己点；每次课后给子女回报 |
| 现在怎么办 | 社区公益课（集体讲、名额少），子女回家时教一次就走 |
| 痛点 | 频率 3（一个老人要上好几次课）；严重度 4（学不会就被挡在挂号、缴费、打车外面；更怕被骗） |
| AI 能做几成 | 0.6：问清单、教学步骤、防诈骗要点；上课与老人的钱都在人 |
| 商业价值 | 2：单价低，但能带出陪诊、助老的复购 |
| 交付成本 | 1：只写数据 |
| 风险关口 | 老人的密码、验证码、付款、借贷只能老人本人操作；不替老人装来路不明的软件；子女付款要本人确认 |
| 证据 | 2025 年各地社区开展老年人智能手机培训，「集体讲解 + 一对一辅导」，从通话、视频、线上缴费、打车讲起，并讲防诈骗（[扬子晚报网 2025-08-27](https://www.yzwb.net/news/jiangsu/202508/t20250827_255817.html)、[扬子晚报网 2025-05-24](https://www.yzwb.net/news/jiangsu/suzhou/202505/t20250524_211847.html)）；公益项目「我来教您用手机」在多地社区定期开课（[北京商报 2022-09-02](https://www.bbtnews.com.cn/2022/0902/450474.shtml)） |

分数 = 4 × 3 × 4 × 0.6 × 2 ÷ 1 = **57.6**。

### SCN-160 家电清洗

| 项 | 内容 |
|---|---|
| 人群 | 接家电（空调、油烟机、洗衣机）清洗单的师傅；发单的是入夏前的家庭 |
| 要办的事 | 问清机型、台数、装在哪；判断要不要出窗；断电再拆、洗前试机拍照；加氟、换配件先说清 |
| 现在怎么办 | 品牌售后排不上队，找小区里的散户师傅，口头报价 |
| 痛点 | 频率 3（每年一两次、旺季集中）；严重度 3（外机坠落、洗坏扯皮、现场加价） |
| AI 能做几成 | 0.4：问清单、报价写法、安全常识；干活、验收、钱都在人 |
| 商业价值 | 3：抽佣；与保洁、小修互相转化 |
| 交付成本 | 1：数据 + 类目 + 证书有效期规则（几行代码） |
| 风险关口 | 2 米以上、出窗的外机拆装清洗属高处作业（特种作业，持证上岗）；加价与换配件走变更单、客户本人确认 |
| 证据 | 空调清洗季节性需求高，旺季上门服务供给紧张（[中国日报中文网 2022-04-26](https://cn.chinadaily.com.cn/a/202204/26/WS62676928a3101c3ee7ad27ec.html)）；距坠落基准面 2 米及以上的高处作业属于特种作业，拆装空调须持高处作业证，不少零工无证作业、安全绳使用不规范（[人民日报 2024-07-08《高空拆装空调 严防无证上岗》](https://paper.people.com.cn/rmrbwap/html/2024-07/08/nw.D110000renmrb_20240708_5-07.htm)） |

分数 = 4 × 3 × 3 × 0.4 × 3 ÷ 1 = **43.2**。

## 2. 做了什么

- `server/app/modules/packs/seeds/elder-phone-teaching.json`：「教老人用手机顾问」，五条知识（密码验证码付款只让老人自己输、防诈骗三句话（含 96110）、先调大字和声音、一次只教一两样、课后回报子女）、一个模板（分几次上课，带按次回报清单）。落在已有类目「助老陪伴」。
- `server/app/modules/packs/seeds/home-appliance-cleaning.json`：「家电清洗接单顾问」，五条知识（外机高处作业要证、断电再拆、洗前试机拍照、清洗剂说清、加氟换配件走变更单）、两个模板（室内机清洗不出窗；窗外外机清洗或拆装）。
- 新类目「家电清洗」（不要证书）、「空调外机拆装（高处作业）」（要审核通过的「高处作业操作证」，沿用持证类目准入：没有证报不了名）。
- 「高处作业操作证」提交资质时有效期必填、最长 6 年（特种作业操作证有效期 6 年、每 3 年复审；沿用 `certificate_expiry_required` / `certificate_expiry_too_far`）。
- 种子文件名起作 `home-appliance-cleaning` 而不是 `appliance-cleaning`：后台服务包列表按 key 排序，排在 `collab-basics` 前面会让 `test_packs.py` 里「第一行就是 collab-basics」的旧用例拿错包。不改旧用例，换名字。

## 3. 数据 / 接口

不新增表与接口。类目随启动时的类目补种进库。

## 4. 两端

服务包两端已接（V148）：运营在后台导入种子、四眼上线后，用户在两端的服务包里启用、问助手、按模板发单。资质上传沿用两端已有的资质页；子女替老人发单沿用 V202 的「替别人发单」。

## 5. 隐私、授权与边界

两个助手都只出草稿；钱、发布、分享个人信息都是人工关口。教手机的助手不碰老人的密码、验证码、付款、借贷，不建议装来路不明的软件；家电清洗的助手不建议无证出窗、不系安全绳、带电拆机，不替客户决定加氟换件。
