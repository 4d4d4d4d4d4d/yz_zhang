# 233 App 上点开看工单截图大图

> 状态：本批实现（V260）。编号 ESCA-063。
> 来源：227 号 spec「没做的」——「App 上点开看大图（现在只写『附 N 张截图』）」；BACKLOG V260（第九轮排期 12 分）。
> 只增不减：「附 N 张截图」的文字照旧；服务端不改。
> 写明的行为变化：App「找客服」里工单与每条往来的截图旁多「看截图 1」「看截图 2」…，点开全屏看大图。

## 0. 要解决的问题

V254、V258 之后工单与客服回复都能带图，而 App 上只写「附 N 张截图」——客服发来「点这里」的截图，用户在手机上看不到。

## 1. 业界怎么做

聊天与工单类 App 的图片附件都是点开全屏查看，点关闭回到原处。（本批没有另找外部来源。）

## 2. 实现

- `shotUri(url, baseUrl)`：站内路径（`/api/v1/files/…`）拼上 API 地址；已经是完整地址的原样用。`SupportTicketsScreen` 多一个可选 `baseUrl`，默认读 `EXPO_PUBLIC_API_BASE_URL`（与 App 根组件同一个配置）。
- `TicketShots`：每张图一个「看截图 N」，点开 `Modal` 里全屏显示（`contain` 缩放），「关闭」回来。

## 3. 两端

- **App**：如上。
- **Web**：不变（227 号已有缩略图，点开看原图）。

## 4. 隐私、授权与边界

图片地址与 227 号相同（能力 URL），只在本人的工单里出现。

## 5. 闸门与红验

`app/supportTickets.test.tsx` 加 2 条（地址拼接；点开第一张、第二张与回复里的截图，关闭）。

6 处变异（`scratchpad/mut260.py`）：5 处首轮变红；「点哪张都打开第一张」首轮存活，补「点第二张显示第二张」后变红。
