# 10 · 智能客服

模块前缀：`CS`

## 目标

7×24 AI 客服解决 80% 常见问题（平台规则、任务流程、资金状态、操作指引），
复杂问题无缝转人工，交易/纠纷类问题精准路由到对应流程。

## A. AI 客服核心

| 编号 | 功能点 | 优先级 | 说明 / AC |
|---|---|---|---|
| CS-001 | 对话式 AI 客服入口 | P1 | App/Web 全局入口 + 任务详情页情境入口 |
| CS-002 | RAG 知识问答 | P1 | 基于平台知识库（KB-005 FAQ/规则/流程）回答；答案附来源；无把握时不编造，引导转人工 |
| CS-003 | 账户上下文感知 | P1 | 授权后可查用户自身订单/合约/钱包状态回答"我的钱到哪了""任务为什么被驳回"类问题 |
| CS-004 | 引导式操作（Action） | P2 | 客服对话内直接发起：催验收、申请退款、提交纠纷等动作（需用户确认） |
| CS-005 | 多轮澄清与情绪识别 | P2 | 识别投诉激烈程度，升级优先级 |
| CS-006 | 转人工 | P1 | 触发条件：用户主动要求 / AI 置信度低 / 涉资金争议 / 高情绪；转接时携带完整对话摘要 |
| CS-007 | 服务评价 | P1 | 会话结束满意度评分，回流优化知识库 |

## B. 人工客服工作台（管理后台内）

| 编号 | 功能点 | 优先级 | 说明 / AC |
|---|---|---|---|
| CS-010 | 会话队列与分配 | P1 | 按技能组路由（资金/账号/纠纷）；SLA 计时 |
| CS-011 | 用户 360 视图 | P1 | 客服侧可见：用户资料、任务、合约、历史工单（权限分级、敏感字段脱敏） |
| CS-012 | AI 辅助人工 | P2 | 回复建议、自动总结、工单自动填写 |
| CS-013 | 工单系统 | P1 | 无法即时解决转工单：分类、指派、状态、时限、升级 |
| CS-014 | 知识库维护入口 | P1 | 客服可标注"AI 答错的问题"→ 运营修订 FAQ（闭环） |

## C. 主动服务

| 编号 | 功能点 | 优先级 | 说明 / AC |
|---|---|---|---|
| CS-020 | 关键节点主动提醒 | P1 | 待验收超时、合约即将到期、提现失败等场景机器人主动私信提醒 |
| CS-021 | 新手引导助手 | P2 | 首次发布/接单的分步引导 |

## 指标
- AI 自助解决率 ≥ 60%（MVP）→ 80%（V1）；转人工平均等待 < 2 分钟；答案幻觉率通过抽检 < 2%。

## 依赖
- 06 知识库（RAG API）、LLM 网关、09 IM（会话通道复用）、12 管理后台。
