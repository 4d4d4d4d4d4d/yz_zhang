# 415 第六十一轮场景发掘：庭院绿化养护、高空外窗外墙清洗

> 状态：本批实现（V442）。编号 SCN-302（庭院绿化养护）、SCN-303（高空外窗外墙清洗）。
> 来源：按 skill `scenario-discovery` 的方法，每轮补一批场景；上一轮是 V439（412 号）。BACKLOG V442。
> 只增不减：只新增两个种子文件和两个新类目。已有的包（包括阳台绿植养护、家务保洁、装修后开荒保洁、空调外机拆装）、类目、资质规则和发单拦截都不变。

## 0. 找信号

- **庭院绿化养护**：阳台绿植养护包（`plant-care`）管的是室内和阳台的花草，没有一个包提到草坪、庭院和修树。打理别墅、一楼带院、露台花园是按月复购的活，常见问题：
  - 说好一个月四次，来两次就说下雨不来；
  - 打完药孩子在草坪上玩，起了一身疹子；
  - 修树枝碰到电线，整栋楼跳闸；
  - 枝叶在院子里烧，被邻居投诉；
  - 顺手把小区绿地的树也砍了。
- **高空外窗外墙清洗**：保洁类的包只管室内擦玻璃。高层外窗、商铺外墙要吊绳作业，是高处作业里事故最重的一类，常见问题：
  - 便宜请的人没有证，挂一根绳就下去；
  - 绳子在楼顶边沿磨；
  - 楼下没拦，清洁剂滴到路人身上；
  - 大风天还在作业；
  - 清洁剂腐蚀窗框。

## 1. 场景卡

### SCN-302 庭院绿化养护

| 项 | 内容 |
|---|---|
| 人群 | 做庭院养护的园丁；发单的是带院住户、露台花园的主人 |
| 要办的事 | 报价按面积次数写清；打药按标签、说清药名、避开孩子宠物；电锯修剪戴护具，不碰电线；枝叶清走不焚烧；只打理自家院子 |
| 现在怎么办 | 物业绿化工私活、熟人介绍 |
| 痛点 | 频率 3（按月）；严重度 3：打药伤人、触电、邻里纠纷 |
| AI 能做几成 | 0.4：养护计划、报价明细、打药告知的草稿；养护由人 |
| 商业价值 | 3：按月复购 |
| 交付成本 | 1 |
| 风险关口 | 钱、发布、分享个人信息是人工关口；农药按标签使用（《农药管理条例》）；不得擅自砍伐城市树木（《城市绿化条例》）；不露天焚烧（《大气污染防治法》） |
| 证据 | 法规名称；本轮没有引用外部报道链接 |

分数 = 2 × 3 × 3 × 0.4 × 3 ÷ 1 = **21.6**。

### SCN-303 高空外窗外墙清洗

| 项 | 内容 |
|---|---|
| 人群 | 做高空清洗的师傅；发单的是高层住户、商铺、小物业 |
| 要办的事 | 持证上岗；工作绳安全绳分开挂并检查；楼下拉警戒区，大风雨雪雾停工；清洁剂不腐蚀、控制滴水；按面积报价，买意外险 |
| 现在怎么办 | 物业找的清洗公司、路边小广告 |
| 痛点 | 频率 2（一年一两次）；严重度 5：坠落是人命 |
| AI 能做几成 | 0.3：开工前检查单、报价明细、警戒与停工规则的草稿；作业由持证的人 |
| 商业价值 | 3 |
| 交付成本 | 1：写数据、加一个要资质的类目 |
| 风险关口 | 钱、发布、分享个人信息是人工关口；特种作业持证上岗（《安全生产法》第三十条）：类目要求审核通过的高处作业操作证（与空调外机拆装同一张，有效期必填、最长 6 年）；六级以上强风不得悬空高处作业（JGJ 80） |
| 证据 | 法律条文与行业规范；本轮没有引用外部报道链接 |

分数 = 2 × 2 × 5 × 0.3 × 3 ÷ 1 = **18**。

## 2. 做了什么

- `server/app/modules/packs/seeds/garden-care.json`：「庭院养护接单顾问」。五条知识：
  - 按面积和次数报价；
  - 打药按标签、避开孩子宠物；
  - 修剪戴护具、不碰电线；
  - 枝叶清走不焚烧；
  - 只打理自家院子。
- `server/app/modules/packs/seeds/high-rise-cleaning.json`：「高空清洗接单顾问」。五条知识：
  - 持证上岗；
  - 两根绳分开挂、开工前检查；
  - 楼下警戒、大风停工；
  - 清洁剂不腐蚀、控制滴水；
  - 按面积报价、买意外险。
- 新类目：
  - 「庭院绿化养护」，不要资质；
  - 「高空外窗外墙清洗」，要审核通过的高处作业操作证（`HEIGHT_WORK_CERT`）。

## 5. 隐私、授权与边界

- 两个助手都只出草稿；报价、收款、发布都由人确认。
- 高空清洗：没有审核通过的高处作业操作证报不了名；没证的帮手只在地面看护，不下绳。
- 庭院养护：靠近电线的树、公共绿地的树，请主人找物业、供电或园林部门，不自己动手。
