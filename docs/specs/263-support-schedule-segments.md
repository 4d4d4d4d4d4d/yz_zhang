
# 263 排班按天分别设、每天多段

> 状态：本批实现（V290）。编号 ESCA-069。
> 来源：260 号 spec「没做的」——「界面一次只能给勾选的几天设同一段时间（接口支持每天多段、各不相同）」；BACKLOG V290。
> 只增不减：`PUT /admin/support/my-schedule` 的请求与响应不变；只多一条校验：同一天的几段不能重叠（V287 尚未对外发布，此前没有人存过重叠的排班）。

## 0. 要解决的问题

V287 的界面只能勾几天、填一段时间，早晚两班、周六只上半天这些常见排法都填不了，只能去调接口。

## 1. 业界怎么做

客服系统的排班编辑器一般是「按天列出时段，每天可加多段」，再提供「工作日 9–18」之类的一键模板。（本批没有另找外部来源。）

## 2. 规则

- 编辑器逐段列出：周几（下拉）、开始、结束、「删掉这段」；「加一段」默认接在最后一段那天的 19:00–22:00；「工作日 9–18」一键换成周一到周五各一段。
- 改排班时带出已经存的；没设过的默认填工作日 9–18。
- 同一天的几段不能重叠（首尾相接可以）：400 `support_schedule_overlap`，并写明是哪两段。
- 存的时候按周几、开始时间排好（沿用 V287）。

## 3. 数据

不新增表与字段。

## 4. 接口

无新接口；`PUT /admin/support/my-schedule` 多一条校验。i18n 新增 `support_schedule_overlap`。

## 5. 两端

- **Web 后台工单台「我的排班」**：如上的逐段编辑器。
- **App**：后台只在 Web，不涉及。

## 6. 隐私、授权与边界

同 260 号：只能设自己的排班。
