# 424 第六十五轮场景发掘：上门取送洗衣、老人助餐送餐

> 状态：本批实现（V451）。编号 SCN-310（上门取送洗衣）、SCN-311（老人助餐送餐）。
> 来源：按 skill `scenario-discovery` 的方法，每轮补一批场景；上一轮是 V448（421 号）。BACKLOG V451。
> 只增不减：只新增两个种子文件和两个新类目。已有的包（包括鞋包护理、沙发床垫清洗、给爸妈办事、老人助浴、跑腿）、类目、资质规则和发单拦截都不变。

## 0. 找信号

- **上门取送洗衣**：鞋包护理包只管鞋和包，「洗衣」在已有包里只出现在洗衣机维修、清洗里。上门取衣、送洗、送回是高频小活，常见问题：
  - 送回来少一件；
  - 羊毛大衣水洗缩水；
  - 说好三天拖成一周；
  - 洗不掉推说本来就这样；
  - 口袋里的钱没了。
- **老人助餐送餐**：「给爸妈办事」包从家属一侧写了日常照应，没有每天送饭的人这一侧。独居、行动不便的老人每天要吃饭，常见问题：
  - 糖尿病老人送来红烧肉配甜汤；
  - 送餐的人自己在家做，吃坏肚子；
  - 饭放门口就走，放凉一下午；
  - 老人摔倒第二天才发现；
  - 顺便推销保健品。

## 1. 场景卡

### SCN-310 上门取送洗衣

| 项 | 内容 |
|---|---|
| 人群 | 取送洗衣的人（自己洗或交给洗衣店）；发单的是上班族、家庭 |
| 要办的事 | 取件当面清点拍照；按洗涤标识选洗法；按件报价写清时间；洗坏丢失按约定赔；口袋物品当面交回 |
| 现在怎么办 | 楼下洗衣店、洗衣 App |
| 痛点 | 频率 3（每周）；严重度 3：丢件、洗坏、扯皮 |
| AI 能做几成 | 0.4：清点单、报价、赔付约定的草稿；取送与洗涤由人 |
| 商业价值 | 2 |
| 交付成本 | 1 |
| 风险关口 | 钱、发布、分享个人信息是人工关口；服务不合约定可重作或退款（《消费者权益保护法》第五十二条）；拾得物返还（《民法典》第三百一十四条） |
| 证据 | 法律条文；本轮没有引用外部报道链接 |

分数 = 3 × 3 × 3 × 0.4 × 2 ÷ 1 = **21.6**。

### SCN-311 老人助餐送餐

| 项 | 内容 |
|---|---|
| 人群 | 给老人送饭的人；发单的是在外地的子女、社区 |
| 要办的事 | 问清忌口过敏慢病饮食；只送有许可的餐；保温按时当面交；留意状况告诉家属；不收额外的钱不推销 |
| 现在怎么办 | 社区助餐点、外卖、托邻居 |
| 痛点 | 频率 5（每天）；严重度 4：吃错东西、食品安全、独居老人出事没人发现 |
| AI 能做几成 | 0.4：饮食卡、送餐路线、异常告知的草稿；送餐与观察由人 |
| 商业价值 | 2 |
| 交付成本 | 1 |
| 风险关口 | 钱、发布、分享个人信息是人工关口；餐饮服务要许可，不私做私卖（《食品安全法》第三十五条）；看着不好打 120，不判断病情 |
| 证据 | 法律条文；本轮没有引用外部报道链接 |

分数 = 3 × 5 × 4 × 0.4 × 2 ÷ 1 = **48**。是这几轮里分最高的：每天都要吃饭，独居老人出事没人发现的风险也是每天都有。

## 2. 做了什么

- `server/app/modules/packs/seeds/laundry-pickup.json`：「取送洗衣接单顾问」。五条知识：
  - 当面清点拍照；
  - 按洗涤标识；
  - 按件报价写时间；
  - 按约定赔；
  - 口袋物品交回。
- `server/app/modules/packs/seeds/elder-meal-delivery.json`：「助餐送餐接单顾问」。五条知识：
  - 饮食卡；
  - 只送有许可的餐；
  - 保温当面交；
  - 留意状况告诉家属；
  - 不收额外的钱不推销。
- 新类目「上门取送洗衣」「老人助餐送餐」，都不要资质。

## 4. 两端

## 5. 隐私、授权与边界

- 两个助手都只出草稿；报价、收款、发布都由人确认。
- 助餐助手：
  - 老人的慢病信息只用于选餐；
  - 异常时告诉家属或社区，看着不好打 120，不替代医生。
- 洗衣助手：衣服只用来洗，不外借、不转卖。
