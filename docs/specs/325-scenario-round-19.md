
# 325 第十九轮场景发掘：水电小修、短视频剪辑

> 状态：本批实现（V352）。编号 SCN-199（水电小修）、SCN-200（短视频剪辑）。
> 来源：skill `scenario-discovery` 按方法每轮补充；上一轮是 V349（322 号）。BACKLOG V352。
> 只增不减：
> - 新增两个种子文件和两个新类目；「水电维修」沿用持证类目准入，新资质名是「低压电工作业操作证」。
> - 资质有效期规则从「高处作业操作证」扩到「低压电工作业操作证」：同属特种作业操作证，必填、最长 6 年。高处作业证的提示文字一字不变。
> - 已有包、类目、资质规则都不变。

## 0. 找信号

- **水电小修**：换开关插座、修跳闸、换水龙头角阀，是频率最高的上门小修。最大的风险是不懂电的人带电作业、私拉乱接、换大空开「解决」跳闸。电工作业属特种作业，持证上岗是法定要求，平台的持证类目准入可以直接接住。
- **短视频剪辑**：小店、自媒体最常外包的线上活（V237 的小店直播帮手包管的是话术，不管剪辑）。最大的风险在版权：拿客户参考视频里的歌直接用，或者相信「几秒以内不算侵权」。平台的交付文件托管（预览先看、原片放款后解锁）和分期合约正好接得住交付环节。

## 1. 场景卡

### SCN-199 水电小修

| 项 | 内容 |
|---|---|
| 人群 | 持证的水电师傅；发单的是住户、房东 |
| 要办的事 | 先断电验电再动手；按原线路恢复不私接；跳闸找原因、不换大空开了事；燃气不碰；按项报价；修完试一遍 |
| 现在怎么办 | 小区广告、物业介绍，持证与否看不出来 |
| 痛点 | 频率 2；严重度 4（触电、火灾） |

| 商业价值 | 3：频次高 |
| 交付成本 | 2：数据加一个持证类目，再加资质有效期规则扩一个名字 |
| 风险关口 | 低压电工作业操作证（平台审核，有效期必填、最长 6 年）；断电验电；燃气设施不碰（《城镇燃气管理条例》） |
| 证据 | 电工作业属特种作业，须取得操作证上岗、按期复审，过期即失效；湖南一则案例中，企业让操作证过期的电工继续作业，依《安全生产法》被处罚（[华声在线 2026-02](https://m.voc.com.cn/xhn/news/202602/31561760.html)；本轮从搜索摘要取得，原文页面在本环境打不开，没有逐字核对） |

分数 = 5 × 2 × 4 × 0.3 × 3 ÷ 2 = **18**。

### SCN-200 短视频剪辑

| 项 | 内容 |
|---|---|
| 人群 | 自由剪辑师；发单的是小店、自媒体、企业宣传 |
| 要办的事 | 问清平台与商用与否、时长条数、素材来源、改稿轮数；音乐、素材、字体只用有授权的；交付附授权清单；源工程给不给事先说好 |
| 现在怎么办 | 社交平台接单，版权全凭自觉 |
| 痛点 | 频率 3；严重度 3（侵权索赔、无限改稿） |
| AI 能做几成 | 0.5：问清单、报价与轮数写法、授权清单草稿 |
| 商业价值 | 3：复购高 |
| 交付成本 | 1：只写数据加一个类目 |
| 风险关口 | 版权（《著作权法》第十条信息网络传播权、第二十四条合理使用）；人工关口加「签署」（创作者人群必须） |
| 证据 | 未经授权在短视频里用背景音乐，多地法院判过侵权，时长短、非盈利都不当然免责。本轮找到的公开材料多为律师与版权服务商的文章，相关页面在本环境打不开、没法核实原文，所以不引用链接，只写法律依据。 |

分数 = 4 × 3 × 3 × 0.5 × 3 ÷ 1 = **54**。

## 2. 做了什么

- `server/app/modules/packs/seeds/home-electrical-plumbing.json`：「水电小修接单顾问」。
  - 两个方法：上门前问清三件事、到了现场。
  - 五条知识：持证、先断电验电、不私拉乱接不加大空开、燃气不碰、按项报价。
  - 一个模板：回报清单含断电验电。
  - 新类目「水电维修」，要审核通过的「低压电工作业操作证」。
- `server/app/modules/packs/seeds/video-editing.json`：「短视频剪辑接单顾问」（创作者人群）。
  - 两个方法：接单前问清四件事、交付。
  - 五条知识：音乐授权（平台曲库只限本平台）、「几秒不算侵权」没有依据、字体授权、改稿轮数、源工程。
  - 一个模板：交付附授权清单。
  - 新类目「短视频剪辑」。
- `cert_service`：「低压电工作业操作证」和「高处作业操作证」走同一条有效期规则。

## 5. 隐私、授权与边界

- 两个助手都只出草稿；钱、发布、分享个人信息都是人工关口，剪辑另加签署。
- 不建议：带电作业、没证接电工活、私拉乱接或加大空开、碰燃气；用没有授权的音乐、素材、字体，去水印，「几秒不算侵权」的说法。
