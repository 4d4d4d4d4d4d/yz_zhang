
# 272 大额更正说明要超级管理员批准

> 状态：本批实现（V300）。编号 FIN-069。
> 来源：265 号 spec「没做的」——「更正说明按金额分级要超级管理员批准（同 155 号的结算）」；BACKLOG V300。
> 只增不减：差额在线以下、写的人与批准人都是财务时，规则与 V292 完全一样；更正说明的行只多一个 `needs_super_second` 字段。

## 0. 要解决的问题

一条更正说明不动钱，但它说「这个月报给税务的数差了 ¥30 万」，分量和一笔 ¥30 万的结算差不多。V292 只要另一位财务批准，没有和大额结算（155 号）一样的分级。

## 1. 业界怎么做

审批按金额分级是内控的常规做法；平台已有的大额结算（SEC-061f）就是这样。（本批没有另找外部来源。）

## 2. 规则

- 差额的**绝对值**（正负都算）达到 `PLATFORM_SUPER_SECOND_APPROVAL_CENTS`（默认 ¥10 万，与大额结算同一条线）：批准人必须是超级管理员，否则 403 `correction_needs_super`，写明请转交超级管理员。
- 任何金额下，批准人的级别都不能低于写的人（超级管理员写的，要另一位超级管理员批准）：403 `second_approver_rank`（沿用 155 号的错误码）。
- 更正说明的行多 `needs_super_second`，后台待批准列表标「要超级管理员批准」。

## 3. 数据 / 接口

不新增表与接口。`FinanceCorrectionRow.needs_super_second`；i18n `correction_needs_super`。

## 4. 两端

- **Web 后台「更正说明」待批准列表**：达到线的标出来。
- **App**：后台只在 Web，不涉及。
