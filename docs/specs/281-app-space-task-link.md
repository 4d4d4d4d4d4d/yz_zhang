> 状态：本批实现（V307）。编号 SCN-157。

## 0. 要解决的问题

V305 只在 Web 的空间编辑里能给作品关联平台上的单；接单的人多在手机上，App 上关联不了，公开页也看不出哪件作品来自平台上的单。

## 1. 规则

- App 空间编辑每条作品多一个「来自平台上的哪一单」输入（数字键盘）；只有整数编号才带进请求，其他（空、字母、小数）不带。
- 关联要发单人授权（服务端 278 号的检查不变，没授权时原样显示服务端那句话）。
- App 公开空间页：关联了任务的作品标「平台上做过的单 · 委托方已同意展示」（撤回授权的服务端不会给出来）。
