
# 341 第二十六轮场景发掘：住院护工、家电上门维修

> 状态：本批实现（V368）。编号 SCN-227（住院护工）、SCN-228（家电上门维修）。
> 来源：skill `scenario-discovery` 按方法每轮补充；上一轮是 V366（339 号）。BACKLOG V368。
> 只增不减：新增两个种子文件、两个新类目、一个资质名（「医疗护理员培训合格证明」）。已有包、类目、资质规则、发单拦截都不变。

## 0. 找信号

- **住院护工**：老人和术后病人家庭的刚需。陪诊包（V349）只管就诊当天，不管住院期间的 24 小时陪护。纠纷集中在：
  - 私下涨价、收红包；
  - 夜里跌倒、长期卧床生压疮；
  - 护工越界做医疗护理（调输液）；
  - 交班说不清。
  国家对医疗护理员有培训与职责边界的规定。
- **家电上门维修**：频率不低、单价中等。「小病大修」、配件高价、以旧充新被 3·15 反复曝光。接单的人需要几条把信任立起来的规矩：
  - 先报价后修；
  - 旧件交客户；
  - 配件写清；
  - 保修写清。
  平台的上门回报拍照、变更单正好接得住。家电清洗（V313）、数码维修（V329）不覆盖大家电维修。

## 1. 场景卡

### SCN-227 住院护工

| 项 | 内容 |
|---|---|
| 人群 | 医院陪护的护工（医疗护理员）；发单的是住院病人的家属 |
| 要办的事 | 持培训合格证明上岗；只做生活照护；防跌倒防压疮；每班记录、异常叫护士；价钱写清不私下加价；不经手病人钱财、不外传病情 |
| 现在怎么办 | 医院里的护工公司、熟人介绍，价格不透明 |
| 痛点 | 频率 2；严重度 4（跌倒、压疮、被要红包） |
| AI 能做几成 | 0.3：问清单、计价写法、交班记录写法 |
| 商业价值 | 3 |
| 交付成本 | 1：数据加一个类目与一个资质名 |
| 风险关口 | 医疗护理员不得从事医疗护理专业技术性工作（2019 年五部门通知）；医疗健康信息是敏感个人信息（《个人信息保护法》第二十八条）；助手不给医疗建议 |
| 证据 | 国家卫生健康委等 2019 年通知与培训大纲（[新京报 2019-08](https://www.bjnews.com.cn/detail/156688385514452.html)，本轮从搜索摘要取得，没有逐字核对） |

分数 = 4 × 2 × 4 × 0.3 × 3 ÷ 1 = **28.8**。

### SCN-228 家电上门维修

| 项 | 内容 |
|---|---|
| 人群 | 家电维修师傅；发单的是住户 |
| 要办的事 | 上门费检测费事先说清；当面演示故障、先报价后修；旧件交客户；配件写清原厂 / 通用 / 拆机；保修与收据 |
| 现在怎么办 | 品牌售后、搜索出来的维修平台、小区贴的小广告 |
| 痛点 | 频率 2；严重度 3（被多收钱、修不好） |
| AI 能做几成 | 0.4：问清单、分项报价写法、保修写法 |
| 商业价值 | 3 |
| 交付成本 | 1：只写数据加一个类目 |
| 风险关口 | 明码标价（《价格法》第十三条）；欺诈三倍赔偿（《消费者权益保护法》第五十五条） |
| 证据 | 家电维修乱收费被 3·15 曝光（[中新网 2025-03-18](https://www.chinanews.com.cn/sh/2025/03-18/10384772.shtml)，本轮从搜索摘要取得，没有逐字核对） |

分数 = 4 × 2 × 3 × 0.4 × 3 ÷ 1 = **28.8**。

## 2. 做了什么

- `server/app/modules/packs/seeds/inpatient-caregiver.json`：「住院护工接单顾问」。
  - 五条知识：只做生活照护、防跌倒防压疮、每班记录与异常叫护士、价钱写清不私下加价、不经手钱财不外传病情。
  - 模板回报清单含「床栏拉好」。
  - 新类目「住院护工」，要审核通过的「医疗护理员培训合格证明」（`CAREGIVER_CERT`）。
- `server/app/modules/packs/seeds/appliance-repair.json`：「家电维修接单顾问」。
  - 五条知识：上门费检测费事先说清、当面演示故障先报价、旧件交客户、配件写清、保修与收据。
  - 模板回报清单含「旧件交给客户并拍照」。
  - 新类目「家电维修」，不要资质。
