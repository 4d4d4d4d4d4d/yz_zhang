
# 293 每年 11 月前后提醒主管导入放假通知

> 状态：本批实现（V320）。编号 ESCA-074。
> 来源：288 号 spec「没做的」——「每年 11 月前后国务院发通知时提醒主管导入」；BACKLOG V320。
> 只增不减：节假日日历、按通知导入都不变；多一个提醒 job。

## 0. 要解决的问题

V315 能贴通知一次导入全年放假安排，可没人记得每年去导。下一年的日历一天没录，元旦那天排了班的客服照样被派单。

## 1. 业界怎么做

国务院办公厅一般在每年 11 月前后发布下一年的部分节假日安排通知；排班与考勤系统常在年底提醒管理员更新节假日。（本批没有另找外部来源。）

## 2. 规则

- 新 job `POST /admin/jobs/remind-holiday-import`（调度表 `holiday_import_reminders`，每天一次，只认 job 密钥）：
  - 只在**北京时间** 11 月、12 月、1 月里提醒；11、12 月看下一年，1 月看当年；
  - 目标年份已经录过任何一天 → 不提醒；
  - 没有任何客服设排班 → 不提醒（节假日只影响设了排班的客服，见 276 号）；
  - 一周最多提醒一次；
  - 发给全部超级管理员（客服主管），写明哪一年、为什么要录、去哪里导入。
- 响应写明没提醒的原因（`reason`），方便运维看 job 日志。

## 3. 数据 / 接口

不新增表与字段（一周一次按站内信判断）；新 job 进调度表，运营端点可达表里写明「由调度器执行，不该由界面触发」。

## 4. 两端

站内通知，两端的通知中心都能看到；不改界面。

## 5. 隐私、授权与边界

不涉及用户数据；只通知超级管理员。
