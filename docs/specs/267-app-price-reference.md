
# 267 App 发单页查参考价

> 状态：本批实现（V294）。编号 KB-095。
> 来源：266 号 spec「没做的」——「App 发单页的『查参考价』」；BACKLOG V294。
> 只增不减：Web 发布页的那句话一字不变（改成调用共享的 `priceReferenceLine`）；App 发单页只多一个按钮和一行字。

## 0. 要解决的问题

Web 发布页一直有「查参考价」，App 发单页没有：在手机上发单的人只能凭感觉填预算，V293 的「一家刷屏拉低中位价」提示在 App 上也看不到。

## 1. 业界怎么做

服务撮合平台的发单流程普遍在填预算处给出同类成交的参考区间，两端一致。（本批没有另找外部来源。）

## 2. 规则

- App 发单页「预算」下面多一个「查参考价」：点了才按当前类目查（不每次打开都请求）。
- 说的话与 Web 完全一样，由共享 SDK 的 `priceReferenceLine` 生成：有样本是「同类闭环任务 N 单：中位价 ¥X（¥min ~ ¥max）」，一位发布方占了大半样本时接上去重说明；没有样本是服务端的那句话；形状不对给空串（App 上显示「暂时查不到参考价」）。

## 3. 数据 / 接口

不新增；沿用 `GET /knowledge/price-reference`（SDK `priceReference`）。

## 4. 两端

- **App 发单页**：如上。
- **Web 发布页**：改用 `priceReferenceLine`，显示不变。

## 5. 隐私、授权与边界

同 266 号：只出聚合数。
