## C. 圈层（Circle）—— 核心差异化

圈层 = 兴趣或能力聚合的半开放社区，含：成员、群聊、内容流、圈内任务板。

| 编号 | 功能点 | 优先级 | 说明 / AC |
|---|---|---|---|
| CIR-001 | 创建圈层 | P1 | 类型：兴趣圈 / 能力圈（技能标签绑定）/ 地域圈（小区/商圈，联动 GEO-032）；公开/申请制/邀请制 |
| CIR-002 | 圈层发现与推荐 | P1 | 按用户兴趣标签、技能标签、地理位置推荐圈层 |
| CIR-003 | 加入审核与门槛 | P1 | 能力圈可设门槛：认证/信用分/作品审核，保证圈层质量 |
| CIR-004 | 圈层内容流 | P1 | 圈内动态/帖子（联动 CNT-012） |
| CIR-005 | 圈层任务板 | P1 | 任务可定向发布到圈层（TASK-008/MATCH-005），圈内优先接单 |
| CIR-006 | 圈层群聊 | P1 | 圈层自带大群 + 可开子群 |
| CIR-007 | 圈层管理 | P1 | 管理员/协管：成员管理、内容置顶删除、圈规、封禁 |
| CIR-008 | 圈层等级与活跃度 | P2 | 活跃圈层获得更多曝光；僵尸圈回收机制 |
| CIR-009 | 圈层数据面板 | P2 | 管理员可见：成员增长、任务成交额、活跃度 |
| CIR-010 | 圈内信任加成 | P2 | 同圈成员合作时匹配加权 + 展示"同圈"标识（信任线索） |

## D. 治理

- 群/圈内容同样过内容安全（12）；举报→审核→处置（警告/禁言/解散）。
- 圈层不允许成为绕过平台交易的通道：圈内任务同样走合约与托管（防资损）。

## 技术要点
- IM 自研 vs 云服务（如声网/融云/腾讯 IM）：MVP 建议云服务加速，抽象 `MessageProvider` 接口保留自研可能。
- 消息存储与证据链：任务会话消息独立留存策略（合规保留期限）。
