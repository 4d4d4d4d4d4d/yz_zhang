
# 379 发单拦截：偷看、定位他人（SCN-271）

> 状态：本批实现（V406）。编号 SCN-271。
> 来源：378 号第 5 节发现的缺口。数据恢复包上线时试了几句，「帮我恢复老公手机里删掉的聊天记录」「查一下前任的微信聊天记录」「定位老婆的手机」一条都不拦。BACKLOG V406。
> 只增不减：发单拦截多一类 `covert_spying`。已有九类的规则、文案、人工复核都不变；全部种子包的任务模板都不触发。

## 0. 要解决的问题

偷看伴侣、前任的聊天记录，偷偷定位、跟踪别人，是数据恢复、手机维修、上门安装这几类服务里最常见的越界请求：
- 行踪轨迹、通信内容都是个人信息；
- 未经同意获取、出售或提供，属于侵犯个人信息（《个人信息保护法》第十条），情节严重的触犯刑法（《刑法》第二百五十三条之一，侵犯公民个人信息罪）。

平台不该替人接这类单。接单的人也会被卷进去。

## 1. 规则

只看文字、纯规则、不调模型，和已有九类一样。按句子切开（句号、分号、问号、叹号、换行），一句里同时满足才算：

| 条件 | 说法 |
|---|---|
| 对象是另一个人 | 老公、老婆、丈夫、妻子、男 / 女朋友、前任、前夫、前妻、对象、另一半、情人、别人、他人、同事、老板、员工、邻居、他的、她的 |
| 拿通信记录 | 「恢复 / 查看 / 查 / 偷看 / 翻看 / 导出 / 调取 / 获取 / 拿到 / 监控 / 截取」加上对象，再加上「聊天记录 / 微信记录 / 通话记录 / 短信 / 开房记录 / 浏览记录 / 行程记录 / 消费记录」；对象和记录在前、动作在后也算 |
| 定位跟踪 | 「定位 / 追踪 / 跟踪 / 监控 / 监听 / 偷拍」加上对象；「查 / 看 / 知道 / 掌握」加上对象再加上「行踪 / 位置 / 在哪」；「定位器 / 跟踪器 / 追踪器 / 窃听器」和对象在一起 |

放行：
- 自己的设备、自己的数据：「恢复我自己手机里误删的聊天记录」。对象表里没有「我」。
- 自己是被定位、被监控的一方，请人排查、拆除：
  - 「被……定位 / 跟踪 / 装」「怀疑……在我 / 给我 / 我被」「排查」「拆掉」「检查……有没有」；
  - 「怀疑老公出轨，查他的聊天记录」不算：「怀疑」后面不是自己被监控。
- 和隐私无关的：「帮老婆的手机恢复出厂设置」「给他的手机贴膜」「帮他寄快递」。只认带「的」的「他的 / 她的」，免得「帮他寄快递」误伤。
- 否定说法：「不查老公聊天记录」。

误拦的走 V363 的人工复核。比如「老公本人同意并会到场」，运营通过后同一段文字可以发单。

## 2. 拦下时说什么

> 平台不承接偷看、调取别人的聊天记录、通话记录，或定位、跟踪别人：未经同意获取他人的通信内容、行踪轨迹属于侵犯个人信息，情节严重的触犯刑法。恢复你自己设备上的数据，可以发「数据恢复」单；怀疑自己被定位、被装了跟踪器，可以发单请人帮你排查。

后面照例附上人工复核的出路。错误码 `covert_spying`，复核类别名「偷看定位他人」。
