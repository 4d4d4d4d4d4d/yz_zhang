
# 377 场景包「只靠标签」提问的静态闸门（PACK-090）

> 状态：本批实现（V405）。编号 PACK-090。
> 来源：375 号的经验。V402 逐条变异时，六条「只有标签里的口语才接得住」的提问去掉标签照样答得上。
> 只增不减：
> - 新增一个测试文件，不改检索；
> - 场景包里只加了一个标签（燃气具安装的「接头松了」）；
> - 改了 11 条存量提问的问法，命中的知识与断言不变。

## 0. 要解决的问题

每轮场景发掘都给几条口语提问，说它们「只有标签里的口语才接得住」，用来证明标签有用、钉住标签。

检索按两个字一组切词算分（`notebook.terms` / `score`）。提问里任何两个字和正文或标题撞上，就会命中：
- 「皮沙发能洗吗」里的「沙发」在正文里；
- 「多久能睡」里的「多久」在标题里。

这样的提问去掉标签照样答得上，标签删了测试也不红。它说自己钉住了标签，其实没钉住。

原来只有逐个变异才能发现。变异只在当批做、只改当批的标签，存量的没人回头看。

## 1. 做法

`server/tests/test_pack_tag_only_questions.py`：
- 用 AST 读所有场景包测试的参数表，取注释「只有标签里的口语才接得住」之后的每一行，得到「包、提问、应命中的知识」。
- 把这条知识的标签全部拿掉，用同一套检索算分（`expand_query` → `terms` → `score`）。得分还够得上「相关」门槛（`MIN_RELATED`）就红，并逐条写出哪个文件、哪条提问、不靠标签得了几分。
- 自检：至少扫到 100 条，并且包含最近两轮的文件。
