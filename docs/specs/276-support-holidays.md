
# 276 排班用的节假日与调休日历

> 状态：本批实现（V302）。编号 ESCA-070。
> 来源：260、263 号 spec「没做的」——「节假日 / 调休日历（法定节假日自动不在岗）」；BACKLOG V302。
> 只增不减：没设排班的客服一切照旧；日历为空时，排班的判断与 V287/V290 完全一样。

## 0. 要解决的问题

排班按「每周几」算。国庆、春节放假那几天，设了排班的客服照样被算作在岗、照样被自动派单；调休要上班的周六，又被算作不在岗。

## 1. 业界怎么做

客服系统的工作时间一般带一份节假日日历，节假日按休息处理，调休日按指定的工作日处理；日历由管理员每年按官方通知维护。（本批没有另找外部来源；放假安排以国务院办公厅当年的通知为准，平台不写死日期。）

## 2. 规则

- 一天（北京时间的日期）一条：`off` 放假 / `workday` 调休上班（必须写按周几的排班算，否则 400 `holiday_weekday_required`）；同一天不能录两次（409 `holiday_exists`）。
- 放假：设了排班的客服整天不在岗（自动分配跳过、超时提醒先叫别人，与排班以外同一套）。
- 调休上班：这天按指定那天（如周五）的排班判断。
- 没设排班的客服不受日历影响（一直在岗，与以前一样）。
- 主管（超级管理员）录入与删除，进审计；客服都能看。

## 3. 数据

新表 `support_holidays`（迁移 `c1d220260069`）：日期（唯一）、类型、按周几、说明、录入人、时间。后台配置，不属于任何用户。

## 4. 接口

| 接口 | 说明 |
|---|---|
| `GET /admin/support/holidays` | 客服角色 |
| `POST /admin/support/holidays` | 超级管理员；`{day, kind, as_weekday?, label}` |
| `DELETE /admin/support/holidays/{id}` | 超级管理员 |

`off_duty(scope, now, holidays)` 多一个日历参数；`my-categories`、`my-schedule`、`agents` 看板、自动分配、超时提醒都带上日历。SDK：`supportHolidays` / `addSupportHoliday` / `deleteSupportHoliday`，类型 `SupportHoliday`；i18n 两个错误码；登记后台角色表、覆盖表、DYNAMIC_BODY、功能面清单。

## 5. 两端

- **Web 后台「客服状态」（主管）**：下面多「节假日日历」：列出已录的天、删掉；录入日期、放假 / 调休上班（调休时选按周几）、说明。
- **App**：后台只在 Web，不涉及。

## 6. 隐私、授权与边界

只有超级管理员能改；按北京时间的日期查日历（UTC 跨日时也对）。
