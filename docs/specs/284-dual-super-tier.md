
# 284 四眼分级的第二档：两位超级管理员

> 状态：本批实现（V311）。编号 SEC-061g。
> 来源：155 号 spec「没做的」——「分级可配置成多档：现在只有一条超管确认线；需要时做成金额档位表（例如 ¥50 万以上要两位超级管理员）」；BACKLOG V311。
> 只增不减：第一档（`PLATFORM_SUPER_SECOND_APPROVAL_CENTS`，默认 ¥10 万，第二位必须是超级管理员）与级别规则不变；没有记录第一位的老调用照旧只看第二位。

## 0. 要解决的问题

155 号之后，¥10 万以上的提现与平台结算第二位要超级管理员；但 ¥10 万和 ¥500 万是同一条规矩：普通财务发起或先批、一位超级管理员确认就出去了。

## 1. 规则

- 新增第二档 `PLATFORM_DUAL_SUPER_APPROVAL_CENTS`（默认 ¥50 万）：达到它时，第一位（结算的发起人 / 提现的第一次复核人）与第二位都必须是超级管理员；第一位不是 → 403 `dual_super_required`，写明请驳回后由超级管理员重新发起或复核。
- 适用于提现的第二次复核与平台结算的确认（两处都经 `check_second_approver`）。
- 档位从环境变量读，可按机构的内控要求调整。

## 2. 数据 / 接口 / 两端

不新增；i18n 一个错误码。两端照旧显示服务端那句话。
