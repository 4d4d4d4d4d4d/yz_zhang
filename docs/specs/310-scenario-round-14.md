
# 310 第十四轮场景发掘：管道疏通、求职辅导

> 状态：本批实现（V337）。编号 SCN-183（管道疏通）、SCN-184（求职辅导：改简历、模拟面试）。
> 来源：skill `scenario-discovery` 按方法每轮补充；上一轮是 V333（306 号）。BACKLOG V337。
> 只增不减：两个种子文件、两个新类目（都不要资质）；已有包、类目、资质规则都不变。顺带修了 `test_packs` 一处按位置取行的写法（改成按 key 取，断言一条没少），这是第二次被「新包的 key 排在 collab-basics 前面」绊倒。

## 0. 找信号

- 疏通下水道是「低价揽客、到了翻倍、推销疏通剂」最典型的一行，和 V333 的搬家是同一个病：价格在动手之后才出现。平台的总价托管 + 变更单正好对症。
- 应届生求职焦虑催生了「保 offer」套餐，几万块、承诺落空、退款扯皮；而真正有用的服务（改简历、练面试）是可以按次交付、按次验收的。

## 1. 场景卡

### SCN-183 管道疏通

| 项 | 内容 |
|---|---|
| 人群 | 接疏通单的水电师傅；发单的是住户、房东、小店 |
| 要办的事 | 先看后报总价、同意再动手；加工具 / 换管 / 砸开走变更单；不推销疏通剂；放水验收、约质保 |
| 现在怎么办 | 楼道小广告、搜索广告 |
| 痛点 | 频率 1；严重度 4（被翻倍收费、被推销、砸开后说不清） |
| AI 能做几成 | 0.5：问清单、报价写法、变更单与质保写法；疏通在人 |
| 商业价值 | 2：单价低 |
| 交付成本 | 1：只写数据 + 一个类目 |
| 风险关口 | 钱先托管、加价只能走变更单；消费者知情权与自主选择权 |
| 证据 | 上海警方破获假借疏通推销高价疏通剂的诈骗团伙，涉案超过 600 万元，最多一单 19000 元（[澎湃新闻](https://m.thepaper.cn/newsDetail_forward_20849209)） |

分数 = 4 × 1 × 4 × 0.5 × 2 ÷ 1 = **16**。

### SCN-184 求职辅导：改简历、模拟面试

| 项 | 内容 |
|---|---|
| 人群 | 做过招聘或资深从业者，兼职接简历修改与模拟面试；发单的是应届生、转行的人 |
| 要办的事 | 按真实经历改简历、按岗位练面试；约定轮数；不保 offer、不编经历、不收内推费、不代考代面；资料只用于这一单 |
| 现在怎么办 | 社交平台引流到「求职机构」，签几万块的套餐 |
| 痛点 | 频率 2；严重度 4（钱、简历造假被解约、个人信息） |
| AI 能做几成 | 0.6：接单清单、报价写法、交付清单都能出草稿；判断与反馈在人 |
| 商业价值 | 3：按次抽佣，线上、可跨城 |
| 交付成本 | 1：只写数据 + 一个类目 |
| 风险关口 | 不作结果承诺（虚假宣传）；不造假（劳动合同法第二十六条、刑法第二百八十条）；个人信息保护法（目的、最小必要、删除）；助手的人工关口含签署 |
| 证据 | 应届生被引流签下约 5.78 万元的「保全职 Offer」套餐，承诺落空后维权（[虎嗅 2025-06-19](https://www.huxiu.com/article/4484504.html)） |

分数 = 3 × 2 × 4 × 0.6 × 3 ÷ 1 = **43.2**。

## 2. 做了什么

- `server/app/modules/packs/seeds/drain-unblocking.json`：「管道疏通接单顾问」，两个方法、五条知识（先看后报价、不推销疏通剂、加活走变更单、放水验收与质保、砸开前拍照说清恢复）、一个模板（先看后报价、看了不做的上门费、质保天数）。新类目「管道疏通」。
- `server/app/modules/packs/seeds/job-seeker-coaching.json`（key 起名避开排在 collab-basics 前面）：「求职辅导接单顾问」，两个方法、五条知识（不承诺保 offer、简历照真实经历写、不收内推费不代考、资料只用于这一单、轮数写进单子）、一个模板（简历修改 + 模拟面试，按次）。新类目「求职辅导」。

## 5. 隐私、授权与边界

两个助手都只出草稿；钱、发布、分享个人信息都是人工关口（求职辅导再加签署）；不建议翻倍收费、推销、砸开不说、编造经历、保 offer、收内推费、代考代面、挪用求职者资料。
