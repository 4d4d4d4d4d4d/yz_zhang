
# 294 第十轮场景发掘：跑腿代办的规矩、活动跟拍

> 状态：本批实现（V321）。编号 SCN-164（跑腿代办的规矩）、SCN-165（活动跟拍）。
> 来源：skill `scenario-discovery` 按方法每轮补充；上一轮是 V313（286 号）。BACKLOG V321。
> 只增不减：两个种子文件、一个新类目「活动跟拍」、发单时多拦两类跑腿活（与 213 号拦中小学学科类家教同一种写法）；已有的「跑腿」类目、模板、其他包都不变。

## 0. 找信号

- 「跑腿」是平台最早的类目之一，模板与顺路单都有（gig-nearby、household-chores），但**没有一处说清哪些跑腿活不能接**。代买、代开药与代排队里藏着两条刑事与治安红线，跑腿的人往往不知道。
- 社区活动组织者包（V167）里有「活动摄影」帮手单，但没有给接单的摄影师的包：交付、版权、肖像权、放鸽子，都是这一行最常见的纠纷。

## 1. 场景卡

### SCN-164 跑腿代办的规矩

| 项 | 内容 |
|---|---|
| 人群 | 接同城跑腿单的人（骑手兼职、学生、自由职业者）；发单的是上班族、老人家属、行动不便的人 |
| 要办的事 | 代买、代取、代送、代排队；垫付说清、小票留证、面单不外传；知道哪些活不能接 |
| 现在怎么办 | 社交平台私下接，「代取、代送、代买、代排队」什么都接，风险全凭自觉 |
| 痛点 | 频率 4（每天都有）；严重度 3（垫付扯皮、隐私泄露，最严重的是代开精神类药品被判刑） |
| AI 能做几成 | 0.5：问清单、垫付写法、哪些不能接；跑腿本身与钱都在人 |
| 商业价值 | 3：抽佣，高频 |
| 交付成本 | 1：数据 + 一段文本规则（几行代码） |
| 风险关口 | 处方药凭处方、精神类药品只能本人面诊凭处方购买（药品管理法、麻醉药品和精神药品管理条例）；倒卖号源与门票（治安管理处罚法关于倒卖票证的规定）；面单是个人信息（个人信息保护法） |
| 证据 | 以同城取送、代买、帮办事为主的跑腿经济，2021 年市场规模 131 亿元，预计 2025 年 664 亿元（[人民日报 2023-05-12](https://paper.people.com.cn/rmrb/html/2023-05/12/nw.D110000renmrb_20230512_1-07.htm)）；受托代开安眠药等第二类精神药品曾有跑腿与驿站人员被以贩卖毒品罪判刑（媒体 2026 年报道，本批没有引用具体链接，规则依据写的是法规名） |

分数 = 5 × 4 × 3 × 0.5 × 3 ÷ 1 = **90**。

### SCN-165 活动跟拍

| 项 | 内容 |
|---|---|
| 人群 | 接婚礼、生日会、聚会跟拍的摄影师（多为兼职）；发单的是新人、家长、活动组织者 |
| 要办的事 | 把时长、地点、交付张数与日期写进单里；版权与使用说清；作品集要客户授权；孩子的照片不公开；当天有变立刻说 |
| 现在怎么办 | 社交平台约，收线下定金，交付全凭口头 |
| 痛点 | 频率 2（旺季集中）；严重度 4（活动只有一次，放鸽子补不回来；版权与肖像权纠纷） |
| AI 能做几成 | 0.4：问清单、交付与版权写法；拍摄与钱在人 |
| 商业价值 | 3：抽佣，客单价较高 |
| 交付成本 | 1：只写数据 + 一个类目 |
| 风险关口 | 肖像权（民法典第一千零一十九条）；委托作品著作权按约定、未约定归受托人（著作权法第十九条）；未成年人个人信息（未成年人保护法）；钱走托管，不收线下定金 |
| 证据 | 湖南约 40 对新人在结婚当天被同一位跟拍摄影师放鸽子，定金 600 到 1800 元不等（[香港01](https://global.hk01.com/大国小事/60282497/结婚当天40对新人被同个摄影师放鸽子-受害者-他前晚还承诺会来)） |

分数 = 3 × 2 × 4 × 0.4 × 3 ÷ 1 = **28.8**。

## 2. 做了什么

- `server/app/modules/packs/seeds/errand-runner.json`：「跑腿接单顾问」，两个方法（接单前问清四件事、跑腿路上的规矩）、五条知识（处方药与安眠药不代开不代买、代排队不加价转让、代买先报价留小票多退少补、面单打码、不明包裹不送）、两个模板（代买、代排队 / 代取号），落在已有的「跑腿」类目。
- `server/app/modules/packs/seeds/event-photography.json`：「活动跟拍接单顾问」，两个方法、五条知识（交付写进单里、作品集要客户授权、版权按单里写、当天去不了怎么办、孩子的照片不公开）、一个模板（带按次回报清单）。新类目「活动跟拍」（不要证书）。
- `server/app/modules/task/errand.py`：发布与草稿时拦下两类跑腿活（错误码 `errand_restricted`，说清为什么、能走什么路）：
  - 「代开 / 代买 / 帮我开……」后 12 个字以内出现处方药、安眠药、精神类药或常见的精神类药名（阿普唑仑、佐匹克隆……）；代买感冒药、退烧药不拦；
  - 同时出现号源 / 门票类的词与加价 / 倒卖 / 转卖类的词；正常代排队、代取号、转卖闲置物品不拦。
  - 纯文本规则，不调模型；草稿改成这类内容后也发布不了。
- 仓库里所有发单模板都过了一遍这条规则（自己的「代排队」模板起初写了「不加价转让号源」被拦，已改写）。

## 3. 数据 / 接口

不新增表与接口。i18n `errand_restricted`。

## 4. 两端

服务包两端已接（V148）。发单被拦时，两端照旧显示服务端的说明（错误码已进共享 SDK 的文案表）。

## 5. 隐私、授权与边界

两个助手都只出草稿；钱、发布、分享个人信息都是人工关口；不教人代开药、倒卖号源；不建议收线下定金、不经同意公开照片、公开孩子的照片。
