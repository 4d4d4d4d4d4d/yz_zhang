# 240 客服暂停接单

> 状态：本批实现（V267）。编号 ESCA-065。
> 来源：237 号 spec「没做的」——「客服『暂停接单』（下班 / 请假时自动分配跳过他，不用取消勾选）」；BACKLOG V267（第十一轮排期 18 分）。
> 只增不减：没人暂停时，自动分配与超时提醒和 V264 完全一样；`GET /admin/support/my-categories` 没暂停时响应不多字段。
> 写明的行为变化：`support_agent_scopes.paused_until`（迁移 c1d220260058）；新增 `POST / DELETE /admin/support/my-pause`。

## 0. 要解决的问题

V264 让新工单自动分给打开了「新工单自动分给我」的客服。下班、请假时只能把勾去掉，回来还得记得勾回去；忘了去掉，新工单就分给了不在的人，超时提醒也只叫他，用户干等。

## 1. 业界怎么做

客服系统里坐席有「在线 / 离开」这类状态，离开的坐席不进自动分配，回来切回在线；也常见「离开到几点」自动恢复。（本批没有另找外部来源。）

## 2. 规则

- 客服在工单台「我负责」一行选时长（2 小时 / 8 小时 / 1 天 / 3 天 / 7 天，接口允许 1 小时到 30 天），按「暂停接单」。
- 暂停中：
  - 新工单自动分配跳过他（打开了自动分配的人里只剩他时就不分，进公共队列）；
  - 没人接手的工单超时，一级提醒先叫没暂停的人；负责这一类的人都暂停了就照旧叫（不让工单没人管）。
- 到点自动恢复，不需要定时任务；也可以按「恢复接单」提前恢复（没暂停时点也返回成功）。
- 手上已经接的工单不动：要转给别人请用主管改派（157 号）。
- 「新工单自动分给我」的勾和负责类别不受暂停影响，恢复后照旧。
- 没声明过负责类别的客服也能暂停：补一行「什么都管」，行为与没声明一样。
- 暂停、恢复都记审计。

## 3. 数据

`support_agent_scopes.paused_until`（可空）。迁移在 SQLite 与 Postgres 上 `upgrade head` + `check` 通过。

## 4. 接口

| 接口 | 说明 |
|---|---|
| `POST /admin/support/my-pause` | `{hours}`（1~720），返回 `{paused_until}`；客服角色 |
| `DELETE /admin/support/my-pause` | 提前恢复，返回 `{paused_until: null}` |
| `GET /admin/support/my-categories` | 暂停中多 `paused_until` |

SDK：`pauseMySupport(hours)`、`resumeMySupport()`、`SupportPause`、`SupportScope.paused_until?`。登记：后台角色表、后台端点覆盖表（`pauseMySupport`）、功能面清单。

## 5. 两端

- **Web 后台工单台**「我负责」一行：没暂停时是「暂停多久」下拉 +「暂停接单」；暂停中写明「暂停接单到 X」+「恢复接单」；暂停后的提示写明手上的工单不动。
- **App**：后台只在 Web，不涉及。

## 6. 隐私、授权与边界

只能暂停自己；只有客服角色（及超级管理员）可用，财务等其他角色 403。
