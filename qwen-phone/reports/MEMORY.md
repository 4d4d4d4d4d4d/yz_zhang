# 本地记忆第一版

2026-10-12。新增当前任务和有证据的候选偏好，手机本地处理，无外部嵌入或检索服务。

## 使用

解锁后，在“当前任务记忆”填写目标、约束与决定、下一步，保存后用于本会话；每项最多 240 字符。可从会话列表重新打开，新对话不继承。

勾选“从本次输入收集候选偏好”，发送明确表达，例如“以后请先结论后细节”。回答成功后显示候选及原话、来源会话、时间。第一版仅识别严格限定的简洁回答、详细解释、先结论后细节、简体中文四类句式，不是泛化的隐含意图推断。未勾选不收集；否定、转述和其他句式不匹配。候选不会进入模型上下文，需点击确认后参与后续回答。

候选 30 天过期，访问时清理；确认后持续有效直到删除。同一会话同一句原话不重复计数，每项最多三个证据。显示的是单次/重复表达的证据等级，不是统计校准的置信概率。删除来源会话会删除对应证据，无剩余证据的偏好一起移除（包括已确认项）。删除记忆不会改写仍保留的历史消息；彻底停止历史信息影响还需要删除相关会话或开启新对话。

## 上下文与保护

本次明确要求优先，其次本会话任务，再参考长期资料与已确认偏好。候选证据不注入模型，模型无法通过工具直接确认画像。规则提示不能保证模型绝不误解偏好；尚未做个性化效果的大规模评测。

所有任务、候选原话和来源元数据都通过现有 Vault 加密记录保存，未新增明文索引；只在解锁后读取。沿用 AES-256-GCM、PBKDF2、认证和自动锁定。当前仍是 ADB shell 开发服务，保护边界见 PRIVACY.md。没有向量数据库或自动跨会话任务检索；目前按会话选择任务，四类已确认风格全量加入上下文，手动画像仍沿用原有注入方式。
