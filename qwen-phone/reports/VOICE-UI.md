# UI 与语音第一版

2026-10-13。新版小千界面已部署：对话主区、语音控制区、折叠任务/候选偏好/画像、手机窄屏布局、键盘快捷发送。

## 使用

打开 http://127.0.0.1:18090/（Mac）或手机 http://127.0.0.1:8090/，创建自己的资料库口令或解锁。未代用户初始化资料库。

页面检查浏览器本地中文识别能力；支持但缺语言包时显示“下载本地中文语音包”。下载完成再开启唤醒并允许麦克风。说“小千，……”会自动发送识别出的本次问题；单说“小千”后可在 12 秒内说问题。语音输入按钮只填草稿，不自动发送。工具的联网确认仍需手动操作。

勾选自动朗读或点击朗读回答，会选系统标记 localService 的中文声音。没有本地中文声音时提示安装，不使用远程声音。浏览器位于 Mac 时用 Mac 的麦克风与语音能力，手机浏览器才使用手机能力；模型推理仍在手机。

## 边界

这是前台网页语音，必须先手动开启；并非 Android 系统级或熄屏常驻唤醒。切后台、锁定、切会话、点击停止都会取消监听与朗读。推理和朗读时暂停识别，减少扬声器自触发。识别无有效结果连续结束多次会停止，需要手动重开。

识别只采用 processLocally=true 且语言包已可用的引擎；不支持时禁用，不自动上传音频。应用未实现录音存储。唤醒前也需持续运行本地识别；不是低功耗硬件关键词引擎，识别准确率与功耗尚未评估。转写后的问题按普通聊天进入现有加密会话。

## 已验证与待验证

- Node 语音控制测试通过：不支持时禁用、仅本地 ASR/TTS、唤醒路由、草稿听写、朗读暂停监听、隐藏/锁定保护。
- JavaScript 语法检查通过；实际正式页面可加载。
- 无资料库静态预览验证桌面布局；390px 视口下文档宽度 390px，无横向溢出。
- 当前 Codex 内置浏览器报告本地中文语音包可下载，但未安装。未代用户授权麦克风，未实测真实声音的唤醒、转写和扬声器播放。
- 手机系统查询到腾讯应用提供的 RecognitionService；未验证其离线性，没有接入该服务。不能把 Mac 浏览器能力当作手机浏览器能力。

测试：`node tests/voice.test.cjs`。界面与控制器统一位于 agent/index.html，build-agent.sh 部署。

接口参考：[MDN Web Speech API](https://developer.mozilla.org/en-US/docs/Web/API/Web_Speech_API/Using_the_Web_Speech_API)、[本地识别可用性](https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition/available_static)。
