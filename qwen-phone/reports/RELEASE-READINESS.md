# 小千：产品与隐私上线评估

2026-10-13，基于当前本地源码和已有真机测试的工程评估；不是安全审计或合规认证。

## 结论与定位

可以发展成“默认离线、可选择联网、记忆由用户掌控”的手机本地助手。当前适合受控技术验证，不适合向普通用户公开发布并宣称全面隐私保护。已具备本地 Qwen 文本推理、受限工具、加密记录和可管理记忆；仍依赖 Mac/ADB 启动，浏览器语音依赖宿主能力。

先聚焦本地问答、笔记与任务记忆、用户确认后的网页搜索。不要承诺读懂隐藏意图、任意手机控制、系统级语音助手或所有推理均由 NPU 完成。

## 隐私事实

- 已有：手机本地模型推理；SQLite 记录值 AES-256-GCM 加密、HMAC 记录标识、口令派生；私有 API bearer 与同源检查；锁定撤销任务；画像确认与候选证据管理；逐次搜索查询授权。
- 未解决：共享 ADB shell UID；运行时明文及模型缓存不能保证即时擦除；未接入独立应用沙箱与 Keystore；loopback HTTP 不等于进程隔离；查询去隐私主要依赖提示和用户审阅。
- 本地是数据流属性，加密是存储属性，二者都不能单独证明设备被入侵或解锁时的安全。硬件 Keystore 也不能使被攻陷的应用进程无法调用已授权密钥。
- 搜索经批准的 query 会离开设备发往 Bing。它不是绝对不联网的产品。应提供清晰的离线模式和统一的网络出口控制。
- 语音仅请求浏览器本地识别及本地声音；当前内置浏览器需下载中文包，手机端和真实音频链路尚未验证。Mac 打开的页面用的是 Mac 麦克风，不是手机麦克风。
- 删除数据库条目不等于闪存或备份的取证级擦除，不能宣传“绝对无法恢复”。

## 上线门槛

| 优先级 | 必须补齐 | 当前证据 / 验收要求 |
|---|---|---|
| P0 | 独立签名 APK、应用 UID 与私有目录 | 目前 app_process 在 shell UID 执行；量产运行不应依赖 ADB 或宿主机 |
| P0 | 密钥生命周期 | 当前口令派生密钥；需硬件支持检测、Keystore 封装、设备认证、重设口令策略与迁移失败恢复测试 |
| P0 | 工具权限与提示注入隔离 | write_note 的“明确要求”由模型提示决定，localTool 没有逐次写入确认；将授权、覆盖确认和联网出口约束放到执行器，不能让模型自我授权 |
| P0 | 安全测试与数据流审计 | 已有隔离单项测试不等于渗透测试；覆盖存储、认证、WebView/IPC、网络、日志、备份、锁定竞态和恶意工具结果；以 MASVS 为清单 |
| P0 | 稳定的运行时发布 | 全层 NPU shim 绑定 ABI、无长时压力结论；预览优先用已验证的 28 层或 CPU 路径，加入故障恢复、取消、超时与降级 |
| P0 | 可安装更新与首次运行 | 模型下载空间/校验/断点续传、签名更新、版本回滚、系统回收恢复、权限拒绝流程 |
| P0 | 数据管理与发行材料 | 加密导出/恢复、删除全部数据、存储配额、版本迁移、明确隐私声明和模型/依赖分发许可核查 |
| P1 | 真正端侧语音链路 | 本地 ASR、VAD/唤醒、TTS 实机集成；误唤醒率、延迟、耗电、噪声和麦克风权限回归；熄屏监听单独设计可见前台服务 |
| P1 | 对话产品完整性 | 当前只展示本次回答，切换会话未回显全部消息；需消息列表、发送/失败/重试/取消、搜索来源呈现、键盘/无障碍验证 |
| P1 | 有边界的长期记忆 | 当前仅四类规则候选和手动任务；需冲突/衰减/撤回与删除后影响验证，再评估相关检索，不能把概率猜测当画像事实 |
| P1 | 质量与性能基线 | 真实中文任务、工具成功率、错误恢复、首 token 延迟、长对话、热稳态/耗电/峰值内存测试；不能用短 bench 代表日常体验 |

P0 作为公开测试前的基本门槛；闭源发行、商店提交及特定地区的要求还需依据具体渠道另行核对。以上没有给出未经验证的完成百分比或排期。

## UI 重构

先前问题是首页把会话操作、推理设置、语音说明和画像编辑当作同等重要的卡片。此次调整为暖白底色、低饱和绿、明显的输入主入口；桌面侧栏管理会话和记忆；手机窄屏重排；语音、对话选项和隐私说明按需展开。保留现有控件 ID 和权限流程，不把 UI 更新说成安全边界升级。

参考原则：[Material 自适应布局](https://m3.material.io/foundations/layout/canonical-examples/overview)；[Claude 对话与工作内容分区](https://support.claude.com/en/articles/17153992-what-are-artifacts-and-how-do-i-use-them)。只借鉴主次分离，不复制品牌界面。

安全基线：[OWASP MASVS](https://mas.owasp.org/MASVS/)、[Android Keystore](https://developer.android.com/privacy-and-security/keystore)。
