# 0.3.0 内测候选验收记录

2026-10-14；目标：Android APK 小范围封闭测试。以下区分已测试的开发后端与尚待实机验证的独立 APK。

## 本轮完成

- 新增独立 APK 工程、可重复构建脚本、专用签名材料、非 debuggable 候选包；签名校验通过。原生运行库随包提供，模型由用户导入并严格校验固定 SHA-256。
- 原生服务：可见通知、启动/停止、独立私有目录、CPU 推理路径、模型与 agent 就绪检查。
- 应用安全实现：Keystore HMAC 绑定口令派生结果；禁备份、FLAG_SECURE、退后台锁定；WebView 外部导航/文件访问限制与应用实例 HTTP 凭证。
- 执行器笔记确认：名称、具体内容、覆盖标志；拒绝、过期和取消不能写入；确认凭证只用一次。
- 新增任务取消接口与按钮、加密聊天消息回显（最多最近 100 轮）、会话读取认证。
- 网页开发版已更新，正式用户资料库未被初始化。

## 尚未通过 / 阻塞

- APK 真机安装未完成：系统 PackageInstaller 报告用户未解锁，已取消本轮旧 debug 安装会话，解锁后需安装最新构建。没有关闭系统安装验证或绕过锁屏。
- 原生独立 UID 下的模型加载、前台服务停止/重启、Keystore 硬件级别、WebView 操作流程、升级保留数据尚未得到实机通过结果。
- debug-only BetaInstrumentation 已编写，但尚未在 APK 进程执行。
- 未实现 APK 原生语音、图片理解、无障碍手机操作、加密备份恢复、口令轮换、模型下载器、商店上架或自动更新。
- 未完成长时热稳态/功耗/低内存/低存储、不同机型、WebView 版本、恶意输入和独立渗透测试。

因此本包只能称为工程内测候选，不能标记“商业上线通过”或直接对外承诺全面隐私保护。

## 恢复真机验收

解锁手机并批准本次安装后：重新构建/安装最新 debug 包，运行隔离 instrumentation；导入并验证公共模型，测试本地问答、笔记拒绝/允许、取消、历史、锁屏和服务停止；最后用相同签名的非 debuggable 包覆盖安装并验证升级与 run-as 拒绝。不要给测试流程预设正式用户资料库密码。

构建与安装说明见 ../android/README.md；交付包和哈希清单位于 build/。

## 2026-10-15 复验

- ADB 在线，用户 0 为 RUNNING_UNLOCKED。安装仍失败：OPPO 日志先记录 allowInterceptAdbInstallInInstallStage，约 60 秒后 OPLUS_ADB_INSTALL_CANCEL，安装返回 -99；包未安装。当前阻塞是系统安装确认/拦截，不能再归因为用户未解锁。
- 修复 cancelled 任务不被视为终态导致会话不能删除及任务列表不能回收；SafetyTest 在手机隔离进程通过，包含取消任务后的会话删除。
- 修复历史消息渲染后手动朗读读不到回答；本地语音 mock 回归通过，含历史回答朗读。
- APK 隐私说明改为应用私有目录和 Keystore 绑定的实际边界，不承诺硬件级别；重新构建非调试包并通过签名校验，哈希清单已更新。
- APK 实际模型推理、Keystore 与升级验收仍未完成；没有初始化用户正式资料库。
